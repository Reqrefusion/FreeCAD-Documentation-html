Основне

У багатьох дистрибутивах Linux встановлення FreeCAD підтримується громадськістю, а сам FreeCAD доступний у менеджері пакунків на тому чи іншому дистрибутиві. Команда FreeCAD також випускає:

  • "Офіційні" пакети на Snap packages, AppImages, Flatpaks, а також PPA
  • Експериментальні (розробницькі) збірки на щоденнім репозиторії PPA, AppImages, Ubuntu Snaps

Ubuntu та дочірні

Багацько Linux дистрибутивів базуються на Ubuntu та поділяють з нею репозиторії. Окрім офіційних дочірніх дистрибутивів(Kubuntu, Lubuntu та Xubuntu), також є багацько не офіційних, до прикладу: Mint, Voyager тощо. Наведені далі опції (натисніть "розгорнути"), ймовірно, будуть сумісними з такими дистрибутивами.

Офіційний варіянт

FreeCAD наявний у репозиторії Ubuntu Universe і може бути встановленим через Менеджер застосунків або через термінал: 

sudo snap install freecad

Примітка: версія пакунка з репозиторію Ubuntu Universe може відставати від останнього стабільного коду. У цьому випадку рекомендується встановити пакет із описаної нижче PPA -stable. Крім того, можна (але не бажано) встановити пакет з експериментальної гілки PPA -daily.

Стабільна версія PPA

УВАГА: FreeCAD PPA наразі не підтримується і у пошуці небайдужих. Будь ласка, використовуйте альтернативи(snap, appimage) доки це питання не буде вирішено!

Архів Персональних Пакетів (PPA) для стабільних випусків FreeCAD підтримує спільнота на Launchpad. Репозиторій Launchpad зветься Стабільні випуски FreeCAD.

GUI

Примітка: деякі назви можуть відрізнятися, до прикладу синонімічними є "Пакунок", "ПЗ", "Застосунок" та "Програма".

Встановлення стабільного PPA через Графічний Інтерфейс Користувача (GUI):

1. Перейдіть до Центр Застосунків → Застосунки та Оновлення → Джерела Застосунків → Інші застосунки.
2. Тисніть на Додати, а опісля скопіюйте та вставте наступний рядок: 
ppa:freecad-maintainers/freecad-stable
3. Додайте джерело, закрийте діалог та перезавантажте ваші джерела застосунків.

Після цих кроків FreeCAD буде доступним у Менеджері Застосунків Ubuntu.

CLI

Встановлення стабільного PPA через Командний Інтерфейс Користувача (Термінал/Емулятор термінала/CLI):

1. Додайте PPA до ваших джерел застосунків: 
sudo add-apt-repository ppa:freecad-maintainers/freecad-stable
2. Оновіть список пакунків: 
sudo apt update
3. Опісля встановіть FreeCAD та його документацію: 
sudo apt install freecad freecad-doc

Примітка: у деяких версіях Ubuntu пакунок документації freecad-doc конфліктує з FreeCAD або з однією з його залежностей; якщо так трапилося, то приберіть з команди згадку freecad-doc, встановлюйте лише пакунок freecad. Або якщо ви отримали помилку Не можу знайти пакунок freecad-doc, просто проігноруйте це повідомлення.

Перевірка Встановлення

4. Після того як ви додасте стабільний PPA до своїх джерел одним із наведених вище способів, пакунок freecad встановлюватиметься з цього PPA, а не з репозиторію Ubuntu Universe. Переглянути доступні версії можна за допомогою такої команди apt-cache:
apt-cache policy freecad
Вивід буде подібним до такого:
freecad:
  Installed: (none)
  Candidate: 2:0.18.4+dfsg1~201911060029~ubuntu18.04.1
  Version table:
     2:0.18.4+dfsg1~201911060029~ubuntu18.04.1 500
        500 http://ppa.launchpad.net/freecad-maintainers/freecad-stable/ubuntu bionic/main amd64 Packages
     0.16.6712+dfsg1-1ubuntu2 500
        500 http://archive.ubuntu.com/ubuntu bionic/universe amd64 Packages
ubuntu@ubuntu:~$ apt-cache policy freecad-doc
5. Запустить стабільну (PPA) версію FreeCAD із GUI, або CLI. Щодо останнього, виконайте команду:
./freecad

Розробницький PPA (Щоденний)

Оскільки FreeCAD постійно розвивається, вам може знадобитися встановити пакет daily, щоб отримати останні покращення та виправлення помилок. Репозиторій також розміщений на Launchpad і називається freecad-daily.

Ця версія компілюється щодня з офіційного репозиторію. Будь ласка, зверніть увагу, що окрім нових функцій та виправлень старих помилок, така версія може містити нові помилки та бути нестабільною.

Додайте щоденну PPA до ваших джерел застосунків, оновіть список пакунків та встановіть щоденну версію пакунка: 

sudo add-apt-repository ppa:freecad-maintainers/freecad-daily
sudo apt update
sudo apt install freecad-daily

Кожного божого дня ви можете оновитися до найновішої версії: 

sudo apt update
sudo apt install freecad-daily

Примітка: частенько новий код або залежності, додані у FreeCAD можуть викликати помилки; якщо так трапилося, розробники можуть затримати вихід наступної версії, доки вони власноруч не виправлять проблеми. Якщо ви бажаєте все ж протестувати оновлення, то можете встановити сирці та власноруч скомпілювати FreeCAD.

Запуск щоденної (PPA) версії FreeCAD: 

freecad-daily

примітка: пакунки -stable та -daily можливо мати одначосно на одному пристрої. Це корисно, якщо хочеться мати стабільну версію, а також тестувати нововведення, що ще у розробці. Зверніть увагу, що назва щоденної версії застосунку це freecad-daily, а стабільна версія то є просто freecad.

Debian та дочірні

Починаючи з версії Debian 5(Lenny), FreeCAD доступний безпосередньо з репозиторіїв Debian і його можна встановити у Synaptic або командою: 

sudo apt install freecad

OpenSUSE

FreeCAD можна встановити з Myrlyn(що замінив YAST у вересні 2025), або у терміналі/консолі (необхідно мати root права): 

zypper install FreeCAD

Примітка: Ця інструкція стосується лише встановлення офіційно випущених стабільних версій програми FreeCAD. Залежно від встановлених посилань на репозиторії вашої версії ОС. Пакет для openSUSE може бути застарілим. У цьому випадку рекомендується встановити пакет вручну з вказаних нижче (натисніть Розгорнути) репозиторіїв сирців.

Існує багацько збірок FreeCAD. Будь ласка, ознайомтеся з ними:

Перелік репозиторіїв для openSUSE

Щоб переглянути доступні версії FreeCAD для вашої версії openSUSE, потрібно натиснути кнопку Огляд; якщо під назвою вашої версії дистрибутиву не буде офіційного випуску, натисніть "показати пакунки спільноти", або "показати експериментальні пакунки" (вони можуть містити додаткові помилки!).

Стабільна версія

Стабільна версія пакунка: Стабільний репозиторій на openSUSE. У нижній частині вебсторінки необхідно вибрати правильну версію дистрибутиву openSUSE.

Примітка: у openSUSE є кілька варіантів для завантаження FreeCAD. Щоб ознайомитися з цими варіантами, перейдіть за посиланням Список стабільних репозиторіїв для openSUSE.

Розробницька версія

Останні версії для розробників, також відомі як нестабільні: список нестабільних репозиторіїв для openSUSE

Рекомендується натиснути "Отримати безпосередньо двійкові пакунки", після цього виберіть версію для вашого дистрибутиву зі списку (якщо є).

Gentoo

FreeCAD можна зібрати/встановити, просто виконавши таку команду: 

emerge freecad

Fedora

Пакунок FreeCAD існує поміж версіями ОС F20 та F38. Наразі офіційних пакунків для Fedora немає починаючи із F39 через всілякі проблеми із залежностями.

Наразі встановлення можливе завдяки:

  • AppImage - завантаживши із Сторінки випусків FreeCAD на Github
  • Flatpak - org.freecad.FreeCAD
  • @freecad/nightly COPR

Останні версії можна отримати, завантаживши один із випусків у форматі .AppImage із репозиторію GitHub. Вони без проблем працюють у Fedora.

Якщо ви хочете залишатися на щоденних збірках, FreeCAD також доступний на copr. Щоб встановити збірку звідси, введіть до термінала: 

sudo dnf copr enable @freecad/nightly
sudo dnf install freecad

Це залишає репозиторій copr активним, тож 

sudo dnf upgrade

або рівня їй оновить збірку FreeCAD, а також встановить оновлення з інших активних репозиторіїв. Якщо бажаєте щось стабільніше, то можете вимкнути @freecad/nightly після початкового встановлення. Репозиторій copr зберігає збірки лише впродовж 2 тижнів. Це погано, якщо вам хочеться якоїсь старенької версії.

Також є інструкція як FreeCAD власноруч із скриптом для Fedora. З невеликою зміною, для отримання конкретного комміту, будь-яка версія FreeCAD, починаючи з 0.15, може бути скомпільованої для Fedora 21 та новіших.

Arch

Встановлення FreeCAD на Arch та дочірні дистрибутиви (Manjaro тощо): 

sudo pacman -S freecad

Інші

Якщо на вашому дистрибутиві підтримується FreeCAD, але цей ця стаття не містить згадки про нього, то просимо повідомити про це на форумі!

У мережі Інтернет доступно багато альтернативних, неофіційних пакунків FreeCAD, наприклад, для таких ОС, як Slackware чи Fedora. Пошук у цій мережі допоможе їх знайти.

Установка на інші Linux/Unix системи

Багато відомих дистрибутивів Linux ниньки мають вже скомпільований FreeCAD у пакетному менеджері. Ця версія часто буває застарілою, але не велика біда. Перевірте який менеджер пакетів у вашій ОС. За допомогою однієї з команд із наведеного нижче (й близько неповного) списку ви зможете встановити офіційну версію FreeCAD на ваш дистрибутив з термінала. Для цього, скоріш за все, знадобляться права адміністратора(root). 

apt install freecad
dnf install freecad
emerge freecad
slackpkg install freecad
yum install freecad
zypper install freecad
pacman -Sy freecad

Деколи менеджери чутливі до розміру букв чи пробілів, тож десь може бути необхідним написати `FreeCAD`, а десь `freecad`. Якщо це тобі не допомогло, то ймовірно, що ваш менеджер пакетів не має скомпільованої версії FreeCAD, або буває так, що доступна версія стара як мамонт, а хочеться нової, тоді спробуйте пакунки Flatpak або Snap (вони працюють на більшості x86_64 дистрибутивів Linux) або спробуйте просто завантажити файл .AppImage releases from the github repository. These also tend to work on most x86_64 Linux distributions, without any special installation. Just make sure the downloaded file is marked as executable, then run it.

If that still is not good enough, and you cannot locate another source of a precompiled package for your situation, you will need to compile FreeCAD yourself.
