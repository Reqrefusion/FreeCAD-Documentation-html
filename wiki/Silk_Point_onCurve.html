Description

The Silk Point_onCurve command creates a point, a Point_onCurve object, on a CubicCurve_4 or CubicCurve_6 (also works on some curves outside of Silk).

Point_onCurve markers placed along two curves, showing the u parameter

Usage

  1. Indicate a point by clicking on the curve in the 3D View
  2. There are several ways to invoke the tool.
    • Press the Point onCurve button.
    • Select the Silk → Point onCurve option from the menu.
  3. A point on the curve, a Point_onCurve object, is created.

Properties

See also: Property View.

A Point_onCurve is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional property:

Data

C1 - Inputs

  • DataNL_Curve (Link): Reference curve.
  • Datareverse (Bool): Default is False. Reverses the parameter direction.
  • Datau (FloatConstraint): Parameter along curve.

C2 - Outputs

  • DataPosition (Vector): Position vector.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is Point_onCurve. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
