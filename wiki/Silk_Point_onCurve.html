Description

The Silk Point_onCurve command creates a point, a Point_onCurve object, on a CubicCurve_4 or a CubicCurve_6 (also works on some curves outside of Silk).

Point_onCurve markers placed along two curves, showing the u parameter

These points are used to define start and end points of curve segments on a primary curve. To be easily recognizable, the direction of a curve is indicated by differently colored start and end points.

A primary curve → 4 points roughly placed on the curve → Color coded points with u parameters adjusted

Usage

  1. Indicate a point by clicking on the curve in the 3D View
  2. There are several ways to invoke the tool.
    • Press the Point onCurve button.
    • Select the Silk → Point onCurve option from the menu.
  3. A point on the curve, a Point_onCurve object, is created.
  4. Optionally adjust the Datau property in the Property View.

Notes

  • This tool works on curves outside of Silk, as long as they are parametrized from 0 to 1. Allowing any range would, in principle, work, but Silk would then suffer every time a user typed in "100" by greatly distorting the model — so Silk curves are prioritized over others.
  • The position of the point can be adjusted along the curve (0.0 to 1.0) using the u parameter found under the Data tab of the property view, allowing precise positioning anywhere along the curve. It is often not obvious which side is 0 and which is 1 — try to place the point clearly towards one end, so it is obvious whether it is closer to 0 or 1. To match the endpoints exactly, type in 0 or 1. Try to keep u values generally consistent (0.25, 0.5, 0.75, etc., or 0.1, 0.2, 0.3, 0.4, etc.), since cut values across different curves/surfaces often need to match up, and recognizing your typical values pays off.
  • Often, two curves to be split "in the same manner" have opposite orientation to each other. In those cases, set u of the "next" curve to 1 − u (e.g., 0.90 and 0.10) of the "previous" curve, in order to cut them in the "same" place.
  • FreeCAD's expression engine allows one cut value to be easily linked to another existing cut value, so that only one needs to be edited, with the rest following automatically. Given curve1 and curve2, with point1 and point2 on them:
    • Set u of point2 = point1.u
      (typing "=" into a data field in the property view opens the expression editor). Any change to point1.u will then automatically propagate to point2.u.
    If the points appear on the wrong side of the curve, instead set:
    • u of point2 = 1 - point1.u
  • Automatic matching is not strictly optional on large models, though it is not something to worry about until the model grows large. The process requires little typing: select the source point in the tree, press F2 (edit label mode), press Ctrl+C (copy the label), go to the property Data view of the point to apply the match to, click into the u field, press "=" to open the expression editor, press Ctrl+V to paste, type ".u", confirm by selecting u from the drop-down, and press Enter. This technique works throughout FreeCAD.

Properties

See also: Property View.

A Point_onCurve is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional properties:

Data

C1 - Inputs

  • DataNL_Curve (Link): Reference curve.
  • Datareverse (Bool): Default is False. Reverses the parameter direction.
  • Datau (FloatConstraint): Parameter along curve.

C2 - Outputs

  • DataPosition (Vector): Position vector.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is Point_onCurve. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
