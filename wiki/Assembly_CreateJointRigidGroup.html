Description

The Assembly CreateJointRigidGroup tool creates a rigid group that permanently locks the selected components together.

Usage

  1. Make sure that an assembly is active.
  2. Select components to be grouped.
  3. There are several ways to invoke the tool:
    • Press the Create Rigid Group button.
    • Select the Assembly → Create Rigid Group option from the menu.
    • Use the keyboard shortcut: O.
  4. A RigidGroupJoint object is added to the Joints container.

Notes

RigidGroupJoint objects are permanently inaktive (grayed out) ignoring the Visibility property.

Properties

See also: Property View.

A RigidGroupJoint object is derived from an App FeaturePython object and inherits all its properties. It also has the following additional properties:

Data

Rigid Group

  • DataObjects To Rigid Group (LinkList): List of references to components to group together.
  • DataRigidPlacements (PlacementList): Relative placements for restore.
