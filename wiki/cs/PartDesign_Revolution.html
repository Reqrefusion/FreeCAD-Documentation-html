PartDesign Drážka

Popis

Nástroj Orotovat vytvoří těleso otočením vybraného náčrtku nebo 2D objektu kolem zadané osy.

Nahoře: náčrt (A) je otočen o 270 stupňů proti směru hodinových ručiček kolem osy (B); výsledné těleso (C) je znázorněno vpravo.

Použití

  1. Vyberte jeden náčrt nebo jednu či více ploch z tělesa.
  2. Nástroj lze spustit několika způsoby:
    • Stiskněte tlačítko Orotovat.
    • Z menu vyberte možnost Tvorba dílu →Aditivní prvky → Orotovat.
  3. Nastavte parametry rotace, viz Možnosti níže.
  4. Stiskněte tlačítko OK.

Volby

Při vytváření rotace nebo po poklepání na existující rotaci ve stromovém zobrazení se zobrazí panel úloh Parametry orotování. Nabízí následující nastavení:

Typ

introduced in 1.0

Typ nabízí pět různých způsobů, jak zadat úhel otáčení:

Úhel

Zadejte číselnou hodnotu pro Úhel otočení. Při volbě Symetricky k rovině se otáčení bude rozprostírat o polovinu zadaného úhlu na obě strany náčrtu nebo plochy.

K poslední

Otáčení se provede až k poslednímu povrchu opory, na kterou narazí ve svém směru. Pokud žádná opora neexistuje, zobrazí se chybová zpráva.

K první

Otáčení bude pokračovat k prvnímu povrchu opory, o který se ve svém směru opře. Pokud žádná taková opora neexistuje, zobrazí se chybová zpráva.

K ploše

Otočení se rozšíří až k ploše. Stiskněte tlačítko Vybrat plochu a vyberte plochu nebo referenční rovinu tělesa.

Dva úhly

To umožňuje zadat druhý úhel, v němž by se otáčení mělo provádět v opačném směru. Směry lze přepnout zaškrtnutím možnosti Překlopit.

Osy

Specifikuje osu otáčení:

  • Vertical sketch axis: selects the vertical sketch axis.
  • Horizontal sketch axis: selects the horizontal sketch axis.
  • Construction line: selects a construction line from the sketch used by the revolution. The dropdown list will contain an entry for each construction line. The first construction line will be labelled Construction line 1.
  • Base (X/Y/Z)-axis: selects the X-, Y- or Z-axis of the Body's origin.
  • Select reference…: allows the selection of a straight edge or a datum line from the Body.

Note that when changing the axis, the Reversed option may be (un)checked automatically.

Angle

Defines the angle of the revolution. This option is only available if Type is Angle or Two angles. Angles larger than 360° are not possible. Nor are negative values, use the Reversed option instead.

introduced in 1.1: If the Show interactive draggers when editing features preference is selected, the angle can be adjusted with an interactive gizmo in the 3D View.

2nd angle

introduced in 1.0

Defines the angle of the revolution in the opposite direction. This option is only available if Type is Two angles and Angle is smaller than 360°.

Symmetric to plane

Check this option to extend the revolution half the given angle to either side of the sketch or face. This option is only available if Type is Angle.

Reversed

Reverses the direction of the revolution.

Limitations

  • 0.21 and below: A ShapeBinder cannot be used for the profile.
  • 0.21 and below: When using a SubShapeBinder for the profile, selecting the binder in the Tree View will fail, instead the binder's face has to be selected in the 3D View.
