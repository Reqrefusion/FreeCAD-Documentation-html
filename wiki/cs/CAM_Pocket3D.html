Description

The CAM Pocket3D command inserts a 3D Pocket object into the Job. This operation takes into account the bottom surface of the pocket, as well as selected walls that are not vertical. In its current state, this operation is used to rough out a pocket with non-vertical walls and/or non-horizontal bottom. A common finishing technique is to use a ball end mill with the experimental 3D Surface operation.

Sample image of 3D Pocket operation used to clear cylindrical battery holder.

Usage

Creating a 3D Pocket

  1. From within a Job, select one or more Faces from the Job Model to include as the Base Geometry.
  2. There are several ways to invoke the command:
    • Press the Pocket 3D button.
    • Select the CAM → Pocket 3D option from the menu.
  3. Choose a Tool controller from the pop up selection dialogue window.
  4. Add or subtract Base Geometry elements as needed to configure the Operation.
  5. Check the Depths tab to ensure the Start Depth, Finish Depth, and Step Down percentage are correct. The Final Depth is determined by the Body Geometry selection and is not modifiable.
  6. Check the Heights tab to ensure the Safe and Clearance Heights are appropriate.
  7. Check the Operation tab where the Tool controller can be re-selected, the Cut mode can be configured for Climb or Conventional milling, the Pattern can be set, the Step Over percentage can be adjusted, and Pass Extension can be applied.
  8. Click Apply to observe the milling path for the passes of the Operation. Adjust parameters until satisfied with the Operation.
  9. Click OK to save the Operation.

Notes

  • All paths generated from this operation are based on a standard end mill using the diameter of the tool you selected for this 3D Pocket operation.
  • Ball end mills and other shapes are not respected for path generation even if selected as the tool for this operation.

Options

  • Use the ÚdajeAdaptive Pocket Finish property to attempt to minimize air milling below a 3D Pocket in cases where the pocket is a hole through the model.
  • Use the ÚdajeAdaptive Pocket Start property to attempt to minimize air milling upon entry to the pocket. For example, look at the sample image above in the Description section of this page. In order to reduce the air milling above that 3D Pocket, toggle this property to True and the paths will begin closer to the pocket, much nearer to where the pocket actually begins. See the following image and note the difference in the path start height. The air milling is reduced.

Sample image of 3D Pocket operation used to clear cylindrical battery holder with the Adaptive Pocket Start enabled in order to reduce air milling upon entry.

  • If you wish to process the entire model and stock as a whole, use the ÚdajeProcess Stock Area property set to True with no Base Geometry selected.

Properties

Data

Base

Note: It is suggested that you do not edit the Placement property of path operations. Rather, move or rotate the CAM Job model as needed.

  • ÚdajePlacement: Overall placement[position and rotation] of the object - with respect to the origin (or origin of parent object container)
    • ÚdajeAngle: Angle in degrees applied to rotation of the object around Axis property value
    • ÚdajeAxis: Axis (one or multiple) around which to rotate the object, set in sub-properties: X, Y, Z
      • ÚdajeX: X-axis value
      • ÚdajeY: Y-axis value
      • ÚdajeZ: Z axis value
    • ÚdajePosition: Position of the object, set in sub-properties: X, Y, Z - with respect to the origin (or origin of parent object container)
      • ÚdajeX: X-distance value
      • ÚdajeY: Y-distance value
      • ÚdajeZ: Z-distance value
  • ÚdajeLabel: User-provided name of the object (UTF-8)

Depth

  • ÚdajeClearance Height: The height needed to clear clamps and obstructions
  • ÚdajeFinal Depth: Final Depth of Tool- lowest value in Z
  • ÚdajeFinish Depth: Maximum material removed on final pass.
  • ÚdajeSafe Height: The above which Rapid motions are allowed.
  • ÚdajeStart Depth: Starting Depth of Tool- first cut depth in Z
  • ÚdajeStep Down: Incremental Step Down of Tool

Face

  • ÚdajeOffset Pattern: Clearing pattern to use. (Select in which manner the horizontal movements should be done.)

Path

  • ÚdajeActive: Make False, to prevent operation from generating code
  • ÚdajeBase: The base geometry for this operation
  • ÚdajeComment: An optional comment for this Operation
  • ÚdajeCoolant Mode: The coolant mode for this operation.
  • ÚdajeCycle Time: The cycle time estimation for this operation.
  • ÚdajeTool Controller: Defines the Tool controller used in the Operation
  • ÚdajeUser Label: User assigned label

Pocket

  • ÚdajeAdaptive Pocket Finish: Use adaptive algorithm to eliminate excessive air milling below planar pocket bottom.
  • ÚdajeAdaptive Pocket Start: Use adaptive algorithm to eliminate excessive air milling above planar pocket top.
  • ÚdajeCut Mode: The direction that the toolpath should go around the part ClockWise (CW) or CounterClockWise (CCW)
  • ÚdajeExtra Offset: Extra offset to apply to the operation. Direction is operation dependent.
  • ÚdajeHandle Multiple Features: Choose how to process multiple Base Geometry features.
  • ÚdajeKeep Tool Down: Attempts to avoid unnecessary retractions.
  • ÚdajeMin Travel: Use 3D Sorting of Path
  • ÚdajeProcess Stock Area: Process the model and stock in an operation with no Base Geometry selected.
  • ÚdajeStart At: Start pocketing at center or boundary
  • ÚdajeStep Over: Percent of cutter diameter to step over on each pass
  • ÚdajeZig Zag Angle: Angle of the zigzag pattern

Rotation

Note: Rotation is not available for 3D Pocket as of 0.19.

  • ÚdajeEnable Rotation: Enable rotation to gain access to pockets or areas not normal to Z axis.

Start Point

  • ÚdajeStart Point: The custom start point for the path of this operation.
    • ÚdajeX: X-distance value
    • ÚdajeY: Y-distance value
    • ÚdajeZ: Z-distance value
  • ÚdajeUse Start Point: Make True, if manually specifying a Start Point. Set the start point in the property data Start Point field.
