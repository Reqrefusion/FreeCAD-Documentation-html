Popis

Nástroj PartDesign Pořadač dílčích tvarů vytvoří svazek tvarů odkazující na geometrii z jednoho nebo více nadřazených objektů. Pořadač dílčích tvarů se obvykle používá uvnitř Tělesa PartDesign k odkazování na geometrii mimo toto těleso. Přímé použití externí geometrie v Tělesu není povoleno a vede k chybám typu mimo rozsah. Pořadač dílčích tvarů lze však použít i bez vnoření do Tělesa.

Objekt typu Pořadač dílčích tvarů sleduje relativní umístění odkazované geometrie, což je užitečné při vytváření sestav, ale kromě toho má také své vlastní umístění.

Odkazovaná geometrie se může skládat z jednoho nebo více prvků. Každý prvek může být samostatný objekt (například Těleso PartDesign), podobjekt (například Part Krychle uvnitř Std Part, nebo náčrt či prvek uvnitř tělesa), nebo podprvek (plochy, hrany či vrcholu). Výběr geometrie závisí na zamýšleném účelu nástroje Pořadač dílčích tvarů. Pro booleovskou operaci je třeba vybrat těleso. Pro operaci Deska lze použít plochu, náčrt nebo rovinnou čáru. A pro externí geometrii v náčrtu nebo pro připojení náčrtu může být vhodná jakákoli kombinace podprvků. Prvky mohou patřit k různým nadřazeným objektům a mohou dokonce patřit k tělesu, ve kterém je Pořadač dílčích tvarů vnořen. Protože je Pořadač dílčích tvarů založen na propojeních, může odkazovaná geometrie patřit také k externímu dokumentu.

Vlevo jsou dvě tělesa vytvořená ve dvou samostatných Tělesech.
Vpravo jsou dva objekty typu Pořadač dílčích tvarů, které odkazují na geometrii prvního tělesa, jsou vnořeny do druhého tělesa a posunuty do jiné polohy.

Tyto dva Pořadače dílčích tvarů slouží k vytvoření booleovského řezu a Desky ve druhém Tělese.

Použití

Stejný dokument

  1. Pokud se v dokumentu nachází více Těles: případně aktivujte těleso, do kterého by měl být Pořadač dílčích tvarů vnořen.
  2. Vyberte požadovanou geometrii. Podprvky lze vybírat pouze ve 3D pohledu.
  3. Nástroj lze spustit několika způsoby:
    • Stiskněte tlačítko Pořadač dílčích tvarů.
    • Z menu vyberte možnost Tvorba dílu → SPořadač dílčích tvarů.
  4. Vytvoří se Pořadač dílčích tvarů.
  5. Pokud je v dokumentu pouze jeden prvek Těleso, Pořadač dílčích tvarů se k němu automaticky přidá a prvek Těleso se aktivuje. Pokud je tomu tak a Pořadač dílčích tvarů nemá být vnořen, lze ho přetáhnout z prvku Těleso a umístit na uzel dokumentu ve stromovém zobrazení.

Externí dokument

  1. If required open the source document (the external document) and the target document. Both documents must have been saved at least once.
  2. If there are multiple Bodies in the target document: optionally activate the Body the SubShapeBinder should be nested in.
  3. Select the required geometry in the source document. Subelements can only be selected in the 3D View.
  4. Switch to the target document by clicking its tab in the Main View Area.
  5. Invoke the tool as described above.

Start with empty SubShapeBinder

  1. Follow the instructions described under Same document above but without selecting geometry.
  2. An empty SubShapeBinder is created.
  3. Select the required geometry. Subelements can only be selected in the 3D View.
  4. In the Tree View drag and drop the selection onto the SubShapeBinder. If you have selected subelements their parent objects are highlighted in the Tree View, indicating the objects to be dragged.
  5. Optionally add more geometry in the same manner.
  6. To replace already referenced geometry hold down Ctrl during the drag and drop operation.

Notes

  • 2D offsetting is supported for some shape types, included planar faces, edges and wires. Because offsetting is a difficult operation for the software it does not always succeed.
  • A SubShapeBinder that is not nested in a Body can be used as the Base Feature for a new Body.
  • The ÚdajeSupport property contains the links to the referenced geometry. The property is read-only by default, but can be changed by following the instructions described under Start with empty SubShapeBinder.
  • A SubShapeBinder created from a sketch can have an opposite "tool direction". For example a Pad created from the sketch may extend in the +Y direction, while a Pad, with the same properties, created from the SubShapeBinder extends in the -Y direction. Toggling the ÚdajeReversed property (or checkbox) will solve this.

PartDesign SubShapeBinder vs. PartDesign ShapeBinder

See PartDesign ShapeBinder.

Properties

A PartDesign SubShapeBinder object is derived from a Part Feature object and inherits all its properties. It also has the following additional properties:

Data

Base

  • ÚdajeSupport (XLinkSubList): support for the geometry.
  • ÚdajeFuse (Bool): if it is true it will fuse the solid linked shapes.
  • ÚdajeMake Face (Bool): if it is true it will created a face for the linked wires.
  • ÚdajeClaim Children (PropertyBool): if it is true it will claim the linked objects as children in the Tree View.
  • ÚdajeRelative (Bool): if it is true it will enable relative sub-object linking.
  • ÚdajeBind Mode (Enumeration): binding mode, Synchronized, Frozen, Detached.
  • ÚdajePartial Load (Bool): if it is true it will enable partial loading of the objects.
  • Údaje (hidden)Context (XLink): container object of this binder object.
  • ÚdajeBind Copy On Change (Enumeration)
    • Disabled: disables copy on change.
    • Enabled: duplicates properties from ÚdajeSupport object that are marked `CopyOnChange`. Make internal copy of the object with any changed properties to obtain the shape of an alternative configuration.
    • Mutated: indicates that the binder has already mutated by changing any properties marked with `CopyOnChange`. Those properties will no longer be kept in sync between the binder and the bound object.
  • ÚdajeRefine (Bool): if true redundant edges will be removed (for example after a boolean operation).
  • Údaje (hidden)_ Version (Integer): version of this type of object.
  • Údaje (hidden)_ Copied Link (XLinkSub)

Cache

  • Údaje (hidden)Cache_* (Matrix): unity matrix (separate property for each object in ÚdajeSupport).

Offsetting

  • ÚdajeOffset: 2D offset to apply. If Offset = 0, then no offset is applied. If Offset < 0, then the offset is applied inward.
  • ÚdajeOffset Join Type: Join method of offsetting non-tangent joints. The method can be Arcs, Tangent or Intersection.
  • ÚdajeOffset Fill (Bool): If true, a face is made between the new wire and the original wire. See also the ÚdajeMake Face property.
  • ÚdajeOffset Open Result (Bool): Affects the way open wires are processed. If false, an open wire is made. If true, a closed wire is made from a double-sided offset, with rounds around open vertices.
  • ÚdajeOffset Intersection (Bool): Affects the way compounds are processed. If false, all children are processed independently. If true, and children are edges and wires, the children are offset in a collective manner.

View

Base

  • PohledUse Binder Style (Bool): If true the colors of the binder object depend on the fine-tuning parameter DefaultDatumColor. If false, normal shape colors are applied.
