Draft Clone

Popis

Nástroj Clone vytvoří propojenou kopii vybraného objektu, která bude sledovat veškeré budoucí úpravy původního objektu (s výjimkou umístění). Jedním z příkladů použití je situace, kdy chcete provést booleovskou operaci v PartDesignu na objektu vytvořeném v jiném pracovním prostředí. Lze použít většinu typů objektů, pokud se jedná o tělesa. Pokud potřebujete klonovat více objektů (tj. těles) nebo kontejner dílů, můžete použít klonovací nástroj v pracovním prostředí Draft. Je třeba si uvědomit, že klonování v pracovním prostředí Part Design nastaví aktuální umístění klonu na nulu (jak kartézský posun, tak prostorové orientace). Naproti tomu klonování v pracovním prostředí Draft vypočítá a nastaví číselné hodnoty aktuálního umístění a orientace klonovaných objektů vzhledem ke kontejneru klonovaných objektů.

Nástroj Klon umožňuje klonovat konkrétní prvky Tělesa PartDesign nebo základní objekty těchto prvků (např. náčrtky). Klonovaný objekt bude vytvořen hierarchicky uvnitř samostatného Tělesa.

Clone of the pin while being translated in 3D space as an independent object

Usage

  1. In the Tree View, select the object to be cloned.
  2. There are several ways to invoke the tool:
    • Press the Clone button.
    • Select the Part Design → Clone option from the menu.

Properties

  • ÚdajeBase Feature: sets the original object the clone is based on. To replace, press the … button to get a list of available objects. Changing this property now correctly preserves the clone's display and computed placement instead of showing incorrect geometry. Positioning the source object at a specific location before cloning can be used to control the shape's placement relative to the Clone's origin. introduced in 26.3
  • ÚdajePlacement: defines the orientation and position of the Clone in the 3D space. See Placement.
  • ÚdajeLabel: label given to the Clone object. Change to suit your needs.
