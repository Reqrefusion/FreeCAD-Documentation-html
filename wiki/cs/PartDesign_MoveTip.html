Popis

Příkaz Nastavit Tip, jak je tento příkaz označen v kontextovém menu, předefinuje Tip, což je prvek viditelný mimo těleso. Ve výchozím nastavení je Tip poslední prvek přidaný do tělesa; někdy však může být užitečné dočasně nastavit jako Tip prvek, který se nachází dříve ve stromu. To lze provést za účelem přidání náčrtu, referenční geometrie nebo prvku, který měl být zpětně vytvořen dříve v historii tělesa.

Tip je ve stromovém zobrazení vizuálně označen překryvnou ikonou, která představuje bílou šipku uvnitř zeleného kruhu. Tipem je například následující prvek:

Usage

  1. In the Tree View, right-click the feature to set as tip.
  2. Select the Set Tip option from the context menu.
  3. The new tip is set to visible, and all elements below the tip are hidden from view. Elements newly created from that point will be placed under the tip, and above the other existing elements.

Note: It is important not to forget to set the tip again to the last feature at the bottom of the Body tree.
