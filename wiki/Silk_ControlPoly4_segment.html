Description

The Silk ControlPoly4 segment command creates a 4 point segment polygon, a ControlPoly4_segment object, for a curve segment of a primary curve between two points on the curve.

Segmented ControlPoly4´s.

Primary curve → Points on curve added → 3 segment polygons between the points

Usage

  1. Select in the Tree View or in the 3D View:
    1. One primary curve.
    2. The first point on the curve.
    3. The second point on the curve.
  2. There are several ways to invoke the tool.
    • Press the ControlPoly4_segment button.
    • Select the Silk → ControlPoly4_segment option from the menu.
  3. A segment polygon, a ControlPoly4_segment object, is created.

Notes

  • Segmenting (sectioning, cutting) is a core Silk modeling technique, essential for blending. The current workflow uses curve segments as references to cut surfaces. There are plans to cut surfaces by drawing points directly on them, but since the same result is already achievable using curve segments, this convenience is a medium priority.
  • Why so much segmenting in Silk — segmenting curves, then segmenting surfaces, so much time spent aligning segmentation points? Because building off segments/pieces of a single Bezier curve or surface preserves "relatedness" between the parts. They blend well, and sections separated by gaps still feel like part of the same surface. This sense of connectedness is nearly impossible to achieve by trying to "harmonize" two curves or surfaces that were built separately and then merged. The key to blending in Silk is sharing edges between base surfaces (which are not otherwise aligned), and then blending strips of the surfaces near that shared edge. The shared edges and strips produce blends that look decent even before fine-tuning.

Properties

See also: Property View.

A segment polygon, a ControlPoly4_segment object is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional properties:

Data

C1 - Inputs

  • DataNL_Curve (Link): Reference curve.
  • DataPoint_onCurve_0 (Link): Segment start point.
  • DataPoint_onCurve_1 (Link): Segment end point.
  • Datareverse (Bool): Default is False. Reverses the parameter direction.

C2 - Outputs

  • DataLegs (Part::PropertyGeometryList): Control segments.
  • DataPoles (VectorList): Poles.
  • DataWeights (FloatList): Weights.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is ControlPoly4_segment. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
