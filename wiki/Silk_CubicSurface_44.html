Description

The Silk CubicSurface_44 command creates a cubic surface from a ControlGrid44.

A CubicSurface_44 built from a ControlGrid44

Usage

  1. Select a ControlGrid44
  2. There are several ways to invoke the command.
    • Press the CubicSurface_44 button.
    • Select the Silk → CubicSurface_44 option from the menu.
  3. A CubicSurface_44 object, is created.

Properties

See also: Property View.

A CubicSurface_44 is derived from a ..., formally a yyy object and inherits all its properties. It also has the following additional properties:

Data

C1 - Inputs

  • DataGrid (Link): Control Grid.
  • Datareverse (Bool): Default is False. Reverses the surface normal direction.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is CubicSurface_44. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
