Description

The Silk SilkPose command does ...

Usage

  1. There are several options to select elements in the 3D View:
    • Select 1 vertex. Uses the parent object's orientation, sets PR mode.
    • Select 1 vertex and another element belonging to the same or to another object, sets PR mode.
    • Select 3 vertices of 1, 2, or 3 objects, sets 3P mode.
  2. There are several ways to invoke the command.
    • Press the SilkPose button.
    • Select the Silk → SilkPose option from the menu.
  3. One of the following objects is created:
    • A SilkPose_PR object if the first or second selection option was chosen.
    • A SilkPose_3P object if the third selection option was chosen.

Properties

See also: Property View.

All SilkPose objects are derived from a Part feature, or more precise a Part::FeaturePython object, and inherit all its properties. They also have the following common additional properties:

Data

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_version (String): The class version of this object.


A SilkPose_PR also has the following individual additional properties:

Data

C1.1 - ref inputs

  • Dataposition_ref (LinkSub): The subObject (vertex) used to define position.
  • Datarotation_ref (Link): The Object used to define rotation.

C1.2 - direct inputs

  • Datarelative_axes (Enumeration): Default is XY. The relative orientation to the rotation reference (XY, XZ, or YZ).
  • Datasymbol_scale (Float): Default is 20.0. The overall size of the 3D symbol.

C3 - Identifiers

  • Dataobject_type (String): Default is SilkPose_PR. The workbench class used to create this object.


A SilkPose_3P also has the following individual additional properties:

Data

C1.1 - ref inputs

  • DataO_ref (LinkSub): The subObject (vertex) used to define origin.
  • DataX_ref (LinkSub): The subObject (vertex) used to define x direction.
  • DataY_ref (LinkSub): The subObject (vertex) used to define y direction.

C1.2 - direct inputs

  • Dataswap_XY (Bool): Default is False. Swaps X and Y references.

C1.3 - direct inputs

  • Dataflip_X (Bool): Default is False. Reverses the x direction.
  • Dataflip_Y (Bool): Default is False. Reverses the y direction.
  • Datarelative_axes (Enumeration): Default is XY. The relative orientation to the rotation reference (XY, XZ, or YZ).

C1.4 - direct inputs

  • Datasymbol_scale (Float): Default is 20.0. The overall size of the 3D symbol.

C3 - Identifiers

  • Dataobject_type (String): Default is SilkPose_3P. The workbench class used to create this object.
