Description

The Silk ControlGrid44_EdgeSegment command creates a ControlGrid44 from a CubicSurface_44 and one CubicCurve_4 segment.

A full-strip edge segment cut from a CubicSurface_44

A CubicSurface_44 and a CubicCurve_4 → Resulting ControlGrid44 on the surface

Usage

  1. Select in the 3D View:
    1. A CubicSurface_44.
    2. A CubicCurve_4 that matches part of an edge of that surface.
  2. There are several ways to invoke the command.
    • Press the ControlGrid44_EdgeSegment button.
    • Select the Silk → ControlGrid44_EdgeSegment option from the menu.
  3. A ControlGrid44_EdgeSegment object, is created.

Properties

See also: Property View.

A ControlGrid44_EdgeSegment is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional property:

Data

C1 - Inputs

  • DataNL_Curve (Link): Control grid.
  • DataNL_Surface (Link): Control grid.
  • Datareverse (Bool): Default is False. Reverses the surface normal direction.
  • Datatolerance (Float): Default is 1e-06. Point-to-point connection tolerance for the 4 corners.

C2 - Outputs

  • DataLegs (Part::PropertyGeometryList): Control segments.
  • DataPoles (VectorList): Poles.
  • DataWeights (FloatList): Weights.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is ControlGrid44_EdgeSegment. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
