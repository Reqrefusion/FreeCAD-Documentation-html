Template:Test version

Usage

{{Test version|since=1.0|content=
This text applies to version 1.0 and later.
}}

Parameters

  • only: Only the specified version or comma-separated versions.
  • since: The specified version and later versions, inclusive.
  • after: Versions later than the specified version, exclusive.
  • until: The specified version and earlier versions, inclusive.
  • before: Versions earlier than the specified version, exclusive.
  • content: Content to display.

All supplied conditions must match.

For a version range, combine conditions: 

{{Test version|since=0.20|before=1.0|content=
This text applies to versions 0.20 and 0.21.
}}

Use Template:Test version inline for text within a sentence. Without JavaScript, all content remains visible.
