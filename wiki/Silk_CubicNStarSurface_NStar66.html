Description

The Silk CubicNStarSurface_NStar66 command creates a CubicNStarSurface_NStar66 from a ControlGridNStar66.

The finished N-star surface filling a multi-sided corner

Usage

  1. Select a ControlGridNStar66
  2. There are several ways to invoke the command.
    • Press the CubicNStarSurface_NStar66 button.
    • Select the Silk → CubicNStarSurface_NStar66 option from the menu.
  3. A CubicNStarSurface_NStar66 object, is created.

Properties

See also: Property View.
