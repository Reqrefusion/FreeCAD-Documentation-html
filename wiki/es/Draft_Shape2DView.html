Descripción

El comando Draft Shape2DView crea proyecciones 2D a partir de objetos seleccionados, generalmente sólidos 3D o Planos de Sección. Las proyecciones se colocan en la Vista 3D.

Las proyecciones de dimensiones de las formas 2D se pueden mostrar en una página del Entorno de Trabajo de Dibujo Técnico usando el comando Vista del Boceto. Alternativamente, este Entorno ofrece sus propios comandos de proyección. Pero estos crean proyecciones que solo se muestran en la página de dibujo y no en la Vista 3D.

Proyección de figuras sólidas sobre el plano XY

Utilización

  1. Opcionalmente, gire la Vista 3D. La dirección de la cámara en la Vista 3D determina el vector de proyección. Por ejemplo, una Vista Superior se proyectará sobre el plano XY. El vector de proyección se ignora para las proyecciones creadas a partir de Planos de Sección.
  2. Opcionalmente, seleccione uno o más objetos.
  3. Existen varias formas de ejecutar el comando:
    • Pulse el botón Vista 2D de Forma.
    • Seleccione la opción Modificación → Vista 2D de la Forma del menú.
  4. Si aún no ha seleccionado ningún objeto: seleccione un objeto en la Vista_3D.
  5. Los objetos proyectados se crean en el plano XY.

Cómo generar planos y secciones con diferentes grosores de línea

Se pueden generar fácilmente dibujos con diferentes grosores de línea para las líneas visibles y las de corte utilizando dos objetos shape2Dview del mismo Plano de Sección. Uno de los objetos shape2Dview tiene su modo de proyección configurado en Sólido, que renderiza las líneas visibles, y el otro configurado en Líneas de corte o Caras de corte para renderizar las líneas de corte. A continuación, ambos objetos shape2Dview se colocan en la misma ubicación, uno encima del otro.

Propiedades

Véase también: Vista de Propiedades.

Un objeto Vista 2D se deriva de un objeto Pieza 2D y hereda todas sus propiedades. También tiene las siguientes propiedades adicionales:

Datos

Borrador

  • DatosAuto Actualización (Booleano): Especifica si la proyección debe recalcularse automáticamente si el objeto DatosBase cambia. Seleccionar Falso puede ser útil si hay muchas vistas 2D en un documento o si son complejas. Si se establece en Falso, se debe usar el comando Actualización Estándar para actualizar la proyección.
  • DatosBase (Enlace): Especifica el objeto que se va a proyectar.
  • DatosClip (Booleano): Si es Verdadero, el contenido se recorta a los bordes del plano de sección, si corresponde. Esto anula la propiedad Clip del objeto base.
  • DatosNúmero de Caras (Lista de Enteros): Especifica los índices de las caras que se van a proyectar. Solo funciona si el DatosModo de proyección es: Caras individuales.
  • DatosFusionar (Booleano): Especifica si los objetos del entorno BIM del mismo tipo y material se fusionan o no.
  • DatosLíneas ocultas (Booleano): Especifica si se muestran o no las líneas ocultas.
  • DatosEn el lugar (Booleano): Solo funciona si el objeto seleccionado es un plano de sección y el DatosModo de proyección es Líneas de corte o Caras de corte. Especifica si la proyección aparecerá coplanar con el plano de sección.
  • DatosProyección (Vector): Especifica la dirección de la proyección. Se ignora si la DatosBase es un Plano de Sección.
  • DatosModo de Proyección (Enumeración): Especifica el modo de proyección. Los modos disponibles son:
    • Sólido: Proyecta todo el objeto seleccionado.
    • Caras Individuales: Proyecta únicamente las caras de la lista DatosCaras Numeradas.
    • Cortar Líneas: Solo funciona si el objeto seleccionado es un Plano de Sección y proyecta únicamente las aristas cortadas por el plano de sección.
    • Cortar Caras: Solo funciona si el objeto seleccionado es un Plano de Sección y proyecta como caras las áreas que atraviesan los sólidos mediante el plano de sección.
    • Caras Sólidas: Proyecta el objeto seleccionado completo cortando las caras una por una. Se puede usar si el modo Sólido produce resultados incorrectos.
  • DatosLongitud del Segmento (Float): Especifica el tamaño en milímetros de los segmentos lineales si la DatosTeselación es Verdadera.
  • DatosTeselación (Booleano): Especifica si se debe realizar la teselación. La teselación implica que las curvas se reemplazan por secuencias de segmentos de línea. Esto puede requerir muchos recursos computacionales si la DatosDimensión del Segmento es demasiado corta.
  • DatosVisible Solo (Booleano): Especifica si la proyección solo debe recalcularse si es visible.
  • DatosPuntos de Exclusión (Lista de Vectores): Una lista de puntos de exclusión. Cualquier arista que pase por alguno de esos puntos no se dibujará.
  • DatosNombres de Exclusión (Lista de Nombres): Una lista de nombres de objetos. Cualquier objeto secundario visualizado o recortado cuyo nombre figure en esa lista no se dibujará. introduced in 0.21

Vista

Boceto

  • VistaPatrón (Enumeración): Especifica el Patrón del Borrador con el que se rellenarán las caras proyectadas de los sólidos en la vista de las formas 2D. Esta propiedad solo funciona si el DatosModo de Proyección es Cortar Caras y si el VistaModo de Visualización es Líneas Planas.
  • VistaTamaño del Patrón (Flotar): Especifica el tamaño del Patrón.

Programación de Scripts

Véase también: Autogenerated API documentation y Programación de Scripts básicos en FreeCAD.

Para crear una proyección 2D, utilice el método make_shape2dview (introduced in 0.19) del módulo Borrador. Este método reemplaza al método obsoleto makeShape2DView. 

shape2dview = make_shape2dview(baseobj, projectionVector=None, facenumbers=[])
  • baseobj es el objeto que se va a proyectar.
  • projectionVector es el vector de proyección. Si no se proporciona, se utiliza el eje Z.
  • facenumbers es una lista de números de caras (basada en 0). Si se proporciona, solo se consideran estas caras.
  • shape2dview se devuelve con la proyección 2D creada.

Modifique la propiedad ProjectionMode del objeto creado si es necesario. Puede ser: "Solid", "Individual Faces", "Cutlines", "Cutfaces" o "Solid faces".

Ejemplo: 

import FreeCAD as App
import Draft

doc = App.newDocument()

box = doc.addObject("Part::Box", "Box")
box.Length = 2300
box.Width = 500
box.Height = 1000

shape1 = Draft.make_shape2dview(box)

shape2 = Draft.make_shape2dview(box, App.Vector(1, -1, 1))

shape3 = Draft.make_shape2dview(box, App.Vector(-1, 1, 1), [0, 5])
shape3.ProjectionMode = "Individual Faces"

doc.recompute()
