Grupo Estándar, Cuerpo

Descripción

Pieza Estándar (llamado internamente App Pieza) es un contenedor de propósito general que mantiene juntos un grupo de objetos para que puedan moverse juntos como una unidad en la Vista 3D.

El objeto Pieza Estándar se desarrolló como el bloque de construcción básico para crear ensamblajes mecánicos. En particular, está diseñado para organizar objetos que tienen una Topografía de Forma, como Primitivas, Cuerpos y otras Características. La Pieza Estándar proporciona un Objeto Origen con ejes X, Y y Z locales, y planos estándar, que se pueden usar como referencia para posicionar los objetos contenidos. Además, las piezas Estándar se pueden anidar dentro de otras piezas Estándar para crear un ensamblaje grande a partir de subensamblajes más pequeños.

Aunque está principalmente destinado a cuerpos sólidos, Piezas Estándar puede utilizarse para gestionar cualquier objeto que tenga una propiedad Colocación, por lo que también puede contener Características de Malla, Croquis y otros objetos derivados de la clase App GeoFeature.

No confunda el Cuerpo con la Pieza Estándar. El primero es un objeto específico utilizado en el Entorno de Trabajo de Diseño de Pieza, destinado a modelar un objeto mediante Características. Por otro lado, la Pieza Estándar no se utiliza para modelar, sino solo para organizar objetos en el espacio, con la intención de crear Ensamblajes.

La herramienta Pieza Estándar no está definida por un entorno de trabajo específico, sino por el sistema base; por lo tanto, se encuentra en la Barra de Herramientas de Estructura disponible en todos los entornos de trabajo. Para agrupar objetos arbitrariamente sin considerar su posición, utilice Grupo Estándar. Este objeto no afecta la ubicación de los elementos que contiene; simplemente es una carpeta para organizar la vista de árbol.

Izquierda: elementos dentro de una parte estándar en la Vista_de_árbol. Derecha: objetos posicionados en el espacio, referidos al origen de la parte estándar.

Uso

  1. Pulse el botón Nueva Pieza.
  2. Se crea una pieza vacía que automáticamente pasa a estar activa.
  3. Para añadir objetos a la pieza, selecciónelos en la vista de árbol y arrástrelos sobre ella.
  4. Para eliminar objetos de la pieza, arrástrelos fuera de ella, sobre la etiqueta del documento en la parte superior de la Vista de Árbol.
  5. También se pueden añadir y eliminar objetos editando la propiedad DatosGrupo de la pieza.

Notas

  • Un objeto solo puede pertenecer a una única pieza.
  • Las operaciones 3D como Pieza Booleana no se pueden aplicar a las piezas. Por ejemplo, no se pueden seleccionar dos piezas y realizar una Fusión o un Corte.

Propiedades

La Pieza Estándar, denominada internamente App Pieza (App::Pieza clase), deriva de la App GeoFeature (clase App::GeoFeature) y hereda casi todas sus propiedades. Además, posee varias propiedades adicionales. En particular, propiedades que le permiten gestionar información en el contexto de un ensamblado, como por ejemplo, DatosTipo, DatosId, DatosLicencia, DatosLicenseURL y DatosGrupo.

Estas son las propiedades disponibles en la Vista de Propiedades. Las propiedades ocultas se pueden mostrar mediante el comando Mostrar ocultos en el menú contextual de la Vista de propiedades.

Consulte Característica de la Pieza para obtener una explicación de algunas de las propiedades que se enumeran a continuación.

Explicación detallada

Estado activo

Un documento abierto puede contener varias partes. Sin embargo, solo una parte puede estar activa. La parte activa se muestra en la vista de árbol con el color de fondo especificado por el valor Objeto Contenedor Activo en el editor de preferencias. También se mostrará en negrita.

Para activar o desactivar una pieza:

  • Haga doble clic sobre ella en la Vista_de_árbol, o
  • Abra el menú contextual (clic derecho) y seleccione Objeto activo.

Documento con dos partes estándar, de las cuales la segunda está activa.

Origen

El origen consta de los tres ejes estándar (X, Y, Z) y los tres planos estándar (XY, XZ e YZ). Se pueden adjuntar bocetos y otros objetos a estos elementos al crearlos.

Izquierda: Origen de la parte en la Vista_de_árbol. Derecha: representación de los elementos de origen en la Vista_3D.

Nota: El origen es un objeto App Origen (App::Origen clase), mientras que los ejes y los planos son objetos de tipo App::Línea y App::Plano respectivamente. Cada uno de estos elementos se puede ocultar y mostrar individualmente con la barra Espaciadora; esto es útil para elegir la referencia correcta al crear otros objetos.

Nota 2: todos los elementos dentro de la Pieza están referenciados al Origen de la Pieza, lo que significa que la Pieza se puede mover y rotar con respecto al sistema de coordenadas global sin afectar la ubicación de los elementos en su interior.

Gestión de la Visibilidad

La visibilidad de la pieza tiene prioridad sobre la de cualquier objeto que contenga. Si la pieza está oculta, los objetos que contiene también lo estarán, incluso si su propiedad VistaVisibilidad individual está configurada como true. Si la pieza está visible, la propiedad VistaVisibilidad de cada objeto determina si este se muestra o no.

La visibilidad de la pieza estándar determina si los objetos agrupados bajo ella se muestran en la Vista 3D o no. Izquierda: la pieza está oculta, por lo que ninguno de los objetos se mostrará en la Vista 3D. Derecha: la pieza está visible, por lo que cada objeto controla su propia visibilidad.

Programación de Scripts

Véase también: Programación Básica de Scripts en FreeCAD y Objetos Programados.

Consulte Característica para obtener información general sobre cómo agregar objetos al documento.

Una parte estándar (App Part) se crea con el método addObject() del documento. Una vez que existe una parte, se le pueden agregar otros objetos con los métodos addObject() o addObjects(). 

import FreeCAD as App

doc = App.newDocument()
part = App.ActiveDocument.addObject("App::Part", "Part")

obj1 = App.ActiveDocument.addObject("PartDesign::Body", "Body")
obj2 = App.ActiveDocument.addObject("Part::Box", "Box")

part.addObjects([obj1, obj2])
App.ActiveDocument.recompute()

No se puede crear un App::Part con script. Sin embargo, se puede agregar comportamiento App::Part a un objeto Part::FeaturePython con script utilizando el siguiente código: 

class MyGroup(object):
    def __init__(self, obj=None):
        self.Object = obj
        if obj:
            self.attach(obj)

    def dumps(self):
        return

    def loads(self, _state):
        return

    def attach(self, obj):
        obj.addExtension("App::OriginGroupExtensionPython")
        obj.Origin = FreeCAD.ActiveDocument.addObject("App::Origin", "Origin")

    def onDocumentRestored(self, obj):
        self.Object = obj

class ViewProviderMyGroup(object):
    def __init__(self, vobj=None):
        if vobj:
            vobj.Proxy = self
            self.attach(vobj)
        else:
            self.ViewObject = None

    def attach(self, vobj):
        vobj.addExtension("Gui::ViewProviderOriginGroupExtensionPython")
        self.ViewObject = vobj

    def dumps(self):
        return None

    def loads(self, _state):
        return None

App.ActiveDocument.addObject("Part::FeaturePython",
                             "Group",
                             MyGroup(),
                             ViewProviderMyGroup(),
                             True)
