Description

The Silk ControlGridNStar66 command creates a ControlGridNStar66 from three or more SubGrid63_2Surf64 objects.

An N-star grid blending a star-shaped corner where multiple surfaces meet

Usage

  1. Select three to six SubGrid63_2Surf64 objects sequentially, counter-clockwise, looking from the outer side.
  2. There are several ways to invoke the command.
    • Press the ControlGridNStar66 button.
    • Select the Silk → ControlGridNStar66 option from the menu.
  3. A ControlGridNStar66 object, is created.

Properties

See also: Property View.
