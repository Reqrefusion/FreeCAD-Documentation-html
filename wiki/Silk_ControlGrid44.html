Description

The Silk ControlGrid44 command creates a ControlGrid44 from four connected ControlPoly4 edges.

A ControlGrid44 built from four ControlPoly4 edges

Four connected ControlPoly4 edges → Resulting ControlGrid44

Usage

  1. Preselect 4 connected ControlPoly4 edges in the 3D View.
  2. There are several ways to invoke the command.
    • Press the ControlGrid44 button.
    • Select the Silk → ControlGrid44 option from the menu.
  3. A ControlGrid44_4 object is created.

Properties

See also: Property View.

A ControlGrid44_4 is derived from a ..., formally a yyy object and inherits all its properties. It also has the following additional properties:

Data

C1 - Inputs

  • DataPoly0 (Link): First control polygon.
  • DataPoly1 (Link): Second control polygon.
  • DataPoly2 (Link): Third control polygon.
  • DataPoly3 (Link): Fourth control polygon.
  • Datareverse (Bool): Default is False. Reverses the parameter direction.
  • Datatolerance (Float): Default is 1e-06. Point-to-point connection tolerance for the 4 corners.

C2 - Outputs

  • DataLegs (Part::PropertyGeometryList): Control segments.
  • DataPoles (VectorList): Poles.
  • DataWeights (FloatList): Weights.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is ControlGrid44_4. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
