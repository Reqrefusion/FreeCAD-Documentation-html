Introdução

Macros são uma maneira conveniente de reproduzir ações complexas no FreeCAD. Basta gravar as ações à medida que as executa, salvá-las com um nome e reproduzi-las sempre que desejar. Como as macros são, na verdade, uma lista de comandos em Python, você também pode editá-las e criar scripts bastante complexos.

Embora os scripts Python normalmente tenham a extensão .py, as macros do FreeCAD devem ter a extensão .FCMacro . Uma coleção de macros escritas por usuários experientes pode ser encontrada na página receitas de macros.

Consulte a Central de usuários avançados para saber mais sobre a linguagem de programação Python e sobre a criação de macros. Em particular, você deve começar por estas páginas:

  • Introdução ao Python
  • Tutorial de scripts em Python
  • Noções básicas de scripts no FreeCAD

Como funciona

Ative a saída do console no menu Editar → Preferências → Python → Macro → Mostrar comandos de script no console Python. Você verá que, no FreeCAD, cada ação realizada — como pressionar um botão — gera um comando Python. São esses comandos que podem ser gravados em uma macro. A principal ferramenta para criar macros é a barra de ferramentas de macros: . Nela, você encontra quatro botões: gravar, parar gravação, editar e executar a macro atual.

É muito simples de usar: pressione o botão de gravação, dê um nome à sua macro e, em seguida, execute algumas ações. Quando terminar, clique no botão de parar a gravação, e suas ações serão salvas. Agora você pode acessar a janela da macro usando o botão de edição.

Caixa de diálogo de macros, listando as macros disponíveis no sistema

Lá, você pode gerenciar suas macros, bem como excluí-las, editá-las, duplicá-las, instalá-las ou criar novas do zero. Ao editar uma macro, ela será aberta em uma janela de edição onde você poderá fazer alterações no código.

Exemplo

Pressione o botão de gravação, dê um nome a ela — digamos, "cilindro 10x10" — e, em seguida, na Bancada de Trabalho Part, crie um cilindro com raio = 10 e altura = 10. Depois, pressione o botão "parar gravação". Na caixa de diálogo de edição de macros, você pode visualizar o código Python que foi gravado e, se desejar, fazer alterações nele. Para executar sua macro, basta pressionar o botão de execução na barra de ferramentas enquanto a macro estiver aberta no editor. Sua macro é sempre salva no disco; portanto, qualquer alteração feita ou qualquer nova macro criada estará disponível na próxima vez que você iniciar o FreeCAD.

Personalização

Naturalmente, não é prático carregar uma macro no editor apenas para utilizá-la. O FreeCAD oferece formas muito melhores de usar sua macro, como atribuir-lhe um atalho de teclado ou criar uma entrada no menu. Depois de criar a macro, tudo isso pode ser feito por meio do menu Ferramentas → Personalizar.

Imagem:Configuração de macros.jpg

Dessa forma, você pode transformar sua macro em uma ferramenta de verdade, assim como qualquer ferramenta padrão do FreeCAD. Isso, somado ao poder dos scripts em Python no FreeCAD, permite adicionar facilmente suas próprias ferramentas à interface.

Consulte Personalizar barras de ferramentas para uma descrição mais detalhada.

Criando macros sem gravação

Você também pode copiar e colar código Python diretamente em uma macro, sem gravar ações da interface gráfica. Basta criar uma nova macro, editá-la e colar o código. Em seguida, você pode salvar a macro da mesma forma que salva um documento do FreeCAD. Na próxima vez que iniciar o FreeCAD, a macro aparecerá no item "Macros Instaladas" do menu Macro.

Consulte Como instalar macros para uma descrição mais detalhada.

Macro repositories

There are two main places for macros. The first one is the official peer-reviewed macro repository on GitHub. The second one is the Macros recipes page from which you can pick some useful macros to add to your FreeCAD installation. Macros from both repositories can be installed via the Addon Manager directly from FreeCAD.
