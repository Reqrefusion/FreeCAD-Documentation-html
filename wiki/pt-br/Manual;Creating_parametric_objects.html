No capítulo anterior, exploramos como criar geometria do tipo Part e exibi-la na tela associando-a a um objeto de documento "estático" (não paramétrico). Embora eficaz, essa abordagem torna-se trabalhosa quando é necessário modificar a forma. Cada alteração exige a criação de uma nova forma e sua reatribuição ao objeto, resultando em fluxos de trabalho repetitivos e ineficientes.

Ao longo deste manual, vimos como os objetos paramétricos abordam essa questão ao permitir atualizações dinâmicas. Ao modificar uma única propriedade, a forma é recalculada automaticamente, eliminando a necessidade de atualizações manuais. Esse processo de recálculo possibilita uma modelagem mais eficiente e confere adaptabilidade aos projetos. Internamente, os objetos paramétricos operam de forma semelhante ao que já realizamos: eles recalculam o conteúdo de sua propriedade Shape sempre que uma de suas propriedades é alterada. Esse processo iterativo ocorre de forma fluida e garante que o objeto permaneça consistente com os parâmetros definidos.

O FreeCAD oferece um sistema intuitivo para criar objetos paramétricos inteiramente em Python. Esses objetos são definidos utilizando uma classe Python, a qual:

  • Declara as propriedades necessárias para o objeto.
  • Define o comportamento quando qualquer uma dessas propriedades é modificada.

A estrutura de um objeto paramétrico desse tipo é tão simples quanto isto: 

class myParametricObject:

    def __init__(self, obj):
        obj.Proxy = self
        obj.addProperty("App::PropertyFloat", "MyLength")
        ...

    def execute(self,obj):
        print ("Recalculating the shape...")
        print ("The value of MyLength is:")
        print (obj.MyLength)
        ...

Todas as classes Python geralmente possuem um método `__init__`. Esse método é executado quando uma classe é instanciada — isto é, quando um objeto Python é criado a partir da classe. Você pode pensar em uma classe como um "modelo" ou projeto utilizado para criar instâncias reais de si mesma. Cada instância da classe torna-se um objeto independente, com seus próprios atributos e métodos. Em nosso método `__init__`, realizamos duas tarefas cruciais:

  • Armazene a própria classe no atributo Proxy do objeto de documento do FreeCAD:

Ao atribuir self ao atributo Proxy do objeto de documento do FreeCAD, vinculamos a lógica da nossa classe Python ao objeto do FreeCAD. Isso significa que o objeto de documento "carregará" o código da classe Python em seu interior, permitindo que ele se comporte de acordo com a lógica definida na classe. Essa conexão possibilita que o FreeCAD saiba como interagir com o objeto paramétrico e como recalculá-lo.

  • Crie todas as propriedades de que o objeto necessita:

Utilizando o método addProperty, definimos as propriedades personalizadas exigidas pelo objeto. As propriedades atuam como parâmetros ou variáveis ​​para o objeto e podem ser acessadas, modificadas e exibidas na Vista de Propriedades do FreeCAD. No exemplo, adicionamos uma propriedade de ponto flutuante chamada MyLength. Essa propriedade influenciará posteriormente a forma ou o comportamento do objeto.

Existem muitos tipos de propriedades disponíveis no FreeCAD, variando de números de ponto flutuante a strings e até mesmo tipos especializados para geometria e materiais. Para explorar a lista completa de tipos de propriedade disponíveis, você pode digitar o seguinte código no console do Python: 

FreeCAD.ActiveDocument.addObject("Part::FeaturePython", "dummy").supportedProperties()

A segunda parte fundamental da nossa classe é o método `execute`. Esse método é acionado automaticamente sempre que o objeto é marcado para recomputação, o que ocorre quando uma de suas propriedades é modificada. É no método `execute` que são realizados todos os recálculos do objeto, garantindo que sua forma e comportamento sejam atualizados para refletir quaisquer alterações. Dentro do método `execute`, você realiza todas as operações necessárias para gerar a nova geometria do objeto. Normalmente, isso envolve recalcular a forma com base nos valores atuais de suas propriedades e, em seguida, atribuir a forma atualizada ao atributo `Shape` do objeto, utilizando uma instrução como `obj.Shape = myNewShape`. O método `execute` recebe um único argumento, `obj`, que representa o objeto do documento do FreeCAD associado ao seu objeto paramétrico. Isso permite manipular diretamente o objeto dentro do método, como acessar suas propriedades, atualizar sua geometria ou realizar outras operações.

Resumindo:

  • O método execute é chamado sempre que o objeto precisa ser atualizado.
  • Ele é responsável por recalcular a forma e atribuí-la ao atributo Shape do objeto.
  • O argumento obj fornece acesso ao objeto do documento do FreeCAD, permitindo realizar alterações programaticamente.

Com esse sistema, o FreeCAD cuida do restante — garantindo que o objeto seja atualizado corretamente no documento e exibido de forma adequada na interface gráfica.

Um ponto fundamental a ser lembrado é que, ao criar objetos paramétricos em um documento do FreeCAD, o código Python utilizado para defini-los não é salvo dentro do arquivo. Trata-se de uma medida de segurança intencional. Se os arquivos do FreeCAD pudessem armazenar código Python, isso abriria brechas para que agentes maliciosos distribuíssem arquivos contendo scripts nocivos capazes de danificar o computador de um usuário. Consequentemente, ao compartilhar um arquivo do FreeCAD que contenha objetos paramétricos criados com código Python personalizado, o destinatário também precisa ter acesso ao código utilizado para definir esses objetos. Sem ele, o FreeCAD não conseguirá recalcular ou interagir corretamente com os objetos.

A maneira mais simples de garantir isso é salvar o código Python em um arquivo de macro. Ao distribuir seu arquivo do FreeCAD, você pode incluir a macro juntamente com ele. Alternativamente, você pode compartilhar a macro no repositório de macros do FreeCAD, permitindo que outras pessoas a baixem e utilizem facilmente. Essa abordagem assegura que seus objetos paramétricos personalizados permaneçam funcionais em outros sistemas, ao mesmo tempo em que mantém as melhores práticas de segurança.

Abaixo, faremos um pequeno exercício: criar um objeto paramétrico que consiste em uma simples face retangular paramétrica. Exemplos mais complexos estão disponíveis em exemplos de objetos paramétricos e no próprio código-fonte do FreeCAD.

Atribuiremos ao nosso objeto duas propriedades: Comprimento e Largura, que utilizaremos para construir um retângulo. Em seguida, como o objeto já contará com uma propriedade de Posicionamento (*Placement*) pré-existente (todos os objetos geométricos a possuem por padrão, dispensando a necessidade de adicioná-la manualmente), deslocaremos o retângulo para a localização e rotação definidas nessa propriedade; assim, o usuário poderá mover o retângulo para qualquer lugar editando a propriedade de Posicionamento. 

class ParametricRectangle:

    def __init__(self,obj):
        obj.Proxy = self
        obj.addProperty("App::PropertyFloat", "Length")
        obj.addProperty("App::PropertyFloat", "Width")

    def execute(self, obj):
        # We need to import the FreeCAD module here too, because we might be running out of the Console
        # (in a macro, for example) where the FreeCAD module has not been imported automatically:
        import FreeCAD
        import Part

        # First we need to make sure the values of Length and Width are not 0
        # otherwise Part.LineSegment will complain that both points are equal:
        if (obj.Length == 0) or (obj.Width == 0):
            # If yes, exit this method without doing anything:
            return

        # We create 4 points for the 4 corners:
        v1 = FreeCAD.Vector(0, 0, 0)
        v2 = FreeCAD.Vector(obj.Length, 0, 0)
        v3 = FreeCAD.Vector(obj.Length,obj.Width, 0)
        v4 = FreeCAD.Vector(0, obj.Width, 0)

        # We create 4 edges:
        e1 = Part.LineSegment(v1, v2).toShape()
        e2 = Part.LineSegment(v2, v3).toShape()
        e3 = Part.LineSegment(v3, v4).toShape()
        e4 = Part.LineSegment(v4, v1).toShape()

        # We create a wire:
        w = Part.Wire([e1, e2, e3, e4])

        # We create a face:
        f = Part.Face(w)

        # All shapes have a Placement too. We give our shape the value of the placement
        # set by the user. This will move/rotate the face automatically.
        f.Placement = obj.Placement

        # All done, we can attribute our shape to the object!
        obj.Shape = f

Em vez de colar o código acima no console do Python, é melhor salvá-lo em algum lugar para que possamos reutilizá-lo e modificá-lo mais tarde. Por exemplo, em uma nova macro (menu Macro -> Macros -> Criar). Dê a ela um nome, como "ParamRectangle". No entanto, as macros do FreeCAD são salvas com a extensão .FCMacro, que o Python não reconhece ao usar o comando `import`. Portanto, antes de usar o código acima, precisaremos renomear o arquivo ParamRectangle.FCMacro para ParamRectangle.py. Isso pode ser feito facilmente pelo seu gerenciador de arquivos, navegando até a pasta de Macros indicada no menu Ferramentas -> Macros.

Uma vez feito isso, agora podemos fazer o seguinte no Console do Python: 

import ParamRectangle

Ao explorar o conteúdo de ParamRectangle, podemos verificar que ele contém a nossa classe ParametricRectangle.

Para criar um novo objeto paramétrico usando nossa classe `ParametricRectangle`, utilizaremos o código a seguir. Observe que usamos `Part::FeaturePython` em vez de `Part::Feature`, que vínhamos utilizando nos capítulos anteriores (a versão Python permite definir nosso próprio comportamento paramétrico): 

myObj = FreeCAD.ActiveDocument.addObject("Part::FeaturePython", "Rectangle")
ParamRectangle.ParametricRectangle(myObj)
myObj.ViewObject.Proxy = 0 # This is mandatory unless we code the ViewProvider too.
FreeCAD.ActiveDocument.recompute()

Aqui está uma breve explicação dos comandos anteriores:

  • myObj = FreeCAD.ActiveDocument.addObject("Part::FeaturePython", "Rectangle"): Cria um novo objeto Part::FeaturePython chamado Rectangle no documento ativo do FreeCAD. Esse objeto foi projetado especificamente para um comportamento paramétrico personalizado, permitindo que uma lógica definida em Python gerencie suas propriedades e seu comportamento.
  • ParamRectangle.ParametricRectangle(myObj): Inicializa o objeto associando-o à classe ParametricRectangle do módulo ou script ParamRectangle. Isso vincula a lógica personalizada definida em Python ao objeto, permitindo que ele atue como um objeto paramétrico.
  • myObj.ViewObject.Proxy = 0: Redefine o atributo ViewObject.Proxy para 0, garantindo que o objeto utilize o gerenciamento de visualização padrão do FreeCAD. Esta etapa é necessária, a menos que você defina um ViewProvider personalizado para gerenciar a representação visual do objeto.
  • FreeCAD.ActiveDocument.recompute(): Recalcula o documento para atualizar a geometria e refletir as alterações na interface gráfica do FreeCAD, tornando o novo objeto totalmente visível e funcional.

Nada aparecerá na tela por enquanto, pois as propriedades Length (Comprimento) e Width (Largura) estão definidas como 0, o que acionará nossa condição de "não fazer nada" dentro do método `execute`. Basta alterarmos os valores de Length e Width para que nosso objeto apareça magicamente e seja recalculado em tempo real.

É claro que seria trabalhoso ter que digitar essas 4 linhas de código Python toda vez que quiséssemos criar um novo retângulo paramétrico. Uma maneira muito simples de resolver isso é colocar as 4 linhas mencionadas dentro do nosso arquivo `ParamRectangle.py`, ao final, após o término da classe `ParametricRectangle` (podemos fazer isso a partir do editor de macros).

Agora, ao digitar `import ParamRectangle`, um novo retângulo paramétrico será criado automaticamente. Melhor ainda: podemos adicionar um botão à barra de ferramentas que fará exatamente isso:

  • Abra o menu Ferramentas -> Personalizar
  • Na aba "Macros", selecione a nossa macro ParamRectangle.py, preencha os detalhes conforme desejado e clique em "Adicionar":

  • Na guia Barras de Ferramentas, crie uma nova barra de ferramentas personalizada na bancada de trabalho de sua escolha (ou globalmente), selecione sua macro e adicione-a à barra de ferramentas:

É isso: agora temos um novo botão na barra de ferramentas que, ao ser clicado, criará um retângulo paramétrico.

Lembre-se de que, se você quiser distribuir arquivos criados com esta nova ferramenta para outras pessoas, elas também precisarão ter a macro ParamRectangle.py instalada em seus computadores.
