Tutorial sobre FreeCAD e IFC nativo

O FreeCAD, uma plataforma de modelagem CAD 3D livre e de código aberto (FOSS), oferece ferramentas de BIM há muitos anos por meio da bancada de trabalho Arch. A partir da versão 1.0, lançada em novembro de 2024, as ferramentas Arch foram ampliadas e renomeadas para constituir a bancada de trabalho BIM, recebendo também a adição de um novo sistema IFC nativo. Este tutorial apresentará os diferentes conceitos utilizados no IFC nativo e demonstrará como aplicá-los ao trabalhar em um modelo de exemplo.

O formato IFC

Não se pode começar a falar sobre IFC nativo sem antes mencionar o Industry Foundation Classes, mais conhecido como IFC. O IFC é um formato de arquivo, mas também — e fundamentalmente — um formato de dados. Trata-se de um padrão (uma norma ISO registrada: a 19650) que especifica como os diferentes componentes de uma edificação devem ser representados digitalmente, quais propriedades cada um deles deve possuir, que relações podem ou devem estabelecer com outros elementos, etc. Em suma, é uma receita para descrever uma edificação digitalmente.

O formato IFC possui muitas características interessantes. Primeiramente, ele é aberto e público (mantido por um consórcio, assim como o formato HTML); deriva do formato STEP — um formato de geometria 3D sólido e amplamente conhecido na indústria mecânica; é legível por humanos (podendo ser aberto em um editor de texto); e os dados podem ser gravados não apenas em um, mas em vários formatos de arquivo, podendo até mesmo servir como banco de dados.

Essas características tornam o formato geometricamente confiável — graças ao seu "avô", o STEP — e também uma escolha muito sensata para confiar seus dados, pois, daqui a 50 anos, você ainda conseguirá abrir arquivos IFC e recuperar as informações, mesmo que o seu software BIM tenha deixado de existir. Além disso, o IFC está se tornando cada vez mais o formato de arquivo preferencial exigido pelas autoridades para a concessão de licenças de construção.

Até o momento, no entanto, o formato IFC tem sido utilizado principalmente como um formato de "exportação". Os projetistas geralmente salvam seus projetos no formato nativo de suas aplicações BIM e exportam arquivos IFC apenas quando necessário. Isso é suficiente para apresentar o trabalho, mas bastante problemático se outras pessoas também precisarem trabalhar com o modelo, pois ocorre uma perda significativa de dados e as informações são totalmente reescritas a cada exportação; assim, lidar com uma nova versão do modelo costuma ser uma dor de cabeça para os demais envolvidos.

Com o IFC nativo, nosso objetivo é mudar isso.

O conceito nativo de IFC

A ideia vem de um artigo de Bruno Postle que descreve como o formato IFC poderia ser usado não apenas como formato de exportação, mas também como arquivo principal do projeto, em vez dos formatos (geralmente proprietários) usados ​​por aplicativos BIM. Para conseguir isso, é essencial que as aplicações BIM tratem o formato IFC de forma nativa, ou seja, em vez de converter cada vez o seu próprio conteúdo do seu formato interno para IFC, devem manipular diretamente os dados IFC.

Na prática, no FreeCAD, você pode abrir ou criar modelos IFC, explorá-los e modificar seu conteúdo; cada alteração será claramente registrada, localizável, identificável e passível de reversão. Alterações feitas por outras pessoas enquanto você trabalhava podem ser mescladas, mesmo que elas estejam utilizando outros aplicativos (nativos em IFC).

O trabalho no suporte nativo a IFC no FreeCAD ainda não foi concluído, mas a funcionalidade já é totalmente utilizável para "trabalho real". Se você já conhece as ferramentas BIM do FreeCAD, há muito pouco a aprender, pois a maior parte do fluxo de trabalho utiliza as mesmas ferramentas.

Preciso do IFC?

A decisão é sua. O IFC é um formato rigoroso, no qual cada elemento (uma parede, um pavimento, uma janela) possui atributos e características muito específicos que não podem ser modificados. Essa padronização garante compatibilidade e confiabilidade. Por outro lado, isso significa que você "não pode fazer o que quiser" com o IFC; é preciso respeitar as definições do formato. Isso é excelente e muito bem-vindo ao trabalhar com outras pessoas, pois é exatamente o que se espera de um "padrão". Existem garantias sobre o que você encontrará ao abrir um arquivo IFC, mas isso também pode, obviamente, limitar a criatividade.

Um dos axiomas da bancada de trabalho BIM no FreeCAD é não limitar a criatividade. Tudo é possível: qualquer forma geométrica, qualquer relação paramétrica. Ao trabalhar com a bancada BIM sem o IFC nativo, essa liberdade está ao seu alcance. Ao habilitar o IFC nativo, essa liberdade passa a ser restrita. Isso é bom ou ruim para o seu projeto? Depende.

Pessoalmente, recomendo trabalhar sem IFC quando você estiver atuando sozinho e ainda desenvolvendo conceitos, para assim aproveitar a máxima liberdade. Quando o projeto estiver consolidado e outras pessoas passarem a participar, esse pode ser o momento de migrar para um fluxo de trabalho nativo em IFC, visando aproveitar as vantagens da padronização. Lembre-se de que você pode fazer essa mudança a qualquer momento, ou até mesmo exportar seu projeto (inicialmente não nativo em IFC) para o formato IFC quando desejar. Raramente é necessário começar utilizando IFC de forma nativa logo de imediato.

Abrir e criar modelos IFC

Localizar e visualizar modelos IFC

Se você nunca trabalhou com IFC antes, talvez queira começar examinando alguns modelos de exemplo. Por ser um formato aberto, felizmente, é muito fácil encontrar modelos de exemplo na internet. Uma simples busca por "example IFC models" já ajuda bastante. Eu sugeriria, por exemplo, esta casa modelo canônica mantida pelo consórcio IFC, mas vários sites reúnem coleções de arquivos de exemplo, como este no BIMPlot.

Existem muitos aplicativos para visualizar arquivos IFC. Alguns são gratuitos e outros são, inclusive, de código aberto (FOSS). Entre os visualizadores IFC proprietários, porém gratuitos, destacam-se o BIMVision e o ODA IFC viewer (que funciona em Windows, Mac e Linux). Quanto aos visualizadores FOSS, um simples que utilizo bastante é o IFC++, disponível nos repositórios do Debian/Ubuntu. O FreeCAD e o Bonsai também são visualizadores IFC bons e rápidos.

Poder abrir e visualizar seus arquivos IFC em outro aplicativo é fundamental ao trabalhar com esse formato, pois permite verificar se o conteúdo que você está enviando a colegas ou clientes contém tudo o que é necessário.

O que torna um modelo IFC bom

O formato IFC é complexo, e as aplicações BIM — mesmo as comerciais mais caras — são notoriamente ruins ou muito ruins ao lidar com arquivos IFC. Por isso, a experiência pode variar bastante: os arquivos IFC com os quais você se depara podem ser de péssima qualidade e estar cheios de dados inúteis, chegando, por vezes, a ser praticamente inutilizáveis. Esse fato tem sido frequentemente utilizado por defensores de aplicações BIM proprietárias para desacreditar o formato IFC e tentar demonstrar sua ineficiência.

No entanto, não é difícil criar modelos IFC de qualidade. Mas é preciso contar com um aplicativo que leve o formato a sério e deixe o usuário no controle do que é exportado e de como isso é feito.

As coisas que você deve saber são poucas:

  • Herdado do formato STEP, um arquivo IFC é um arquivo de texto, no qual cada linha representa um elemento e começa com um número de identificação (ID). Por exemplo:

    #66=IFCWALL('3JmWkr',$,'MyWall',$,$,(#71),$,$,$,.SOLIDWALL.);

    A linha acima define um elemento da classe IfcWall, com ID 66. Os itens entre parênteses são seus atributos. Mais informações sobre atributos abaixo.

    O elemento fundamental é a classe (como em 'Industry Foundation Classes'). Cada elemento possui uma classe que define seu tipo: uma parede ou uma janela, mas também um piso, um espaço ou até mesmo uma linha, um círculo, um ponto no espaço 3D ou conceitos como um momento no tempo ou uma tarefa a ser realizada. As classes IFC mais úteis para elementos de construção derivam da classe IfcBuildingElement.

  • Os modelos IFC geralmente seguem uma estrutura rígida: em cada arquivo, deve haver um, e apenas um, IfcProject. O IfcProject é a raiz de todos os objetos dentro de um modelo IFC. Abaixo do IfcProject, geralmente existe pelo menos um IfcSite, que pode conter um ou mais IfcBuildings, os quais, por sua vez, são divididos em IfcBuildingStoreys. Estes podem ser subdivididos em IfcZones e IfcSpaces.

  • Elementos de construção, como IfcWalls ou IfcWindows, são então relacionados a uma das estruturas acima — geralmente um IfcBuildingStorey —, mas também podem estar relacionados a outro elemento de construção; assim, um elemento pode ser composto por vários outros. Essas relações são sempre declaradas explicitamente nos arquivos IFC; nunca são automáticas ou implícitas.

  • Os elementos IFC — sejam eles elementos de construção como paredes ou janelas, elementos estruturais como terrenos e pavimentos, ou qualquer uma das muitas outras classes de elementos oferecidas pelo formato IFC — possuem, todos, um conjunto predefinido de atributos. Atributos são características como nome, posição no espaço ou número de identificação único, definidas pelo formato. Todas as entidades de uma mesma classe devem possuir os mesmos atributos. Os elementos também podem ter propriedades. Ao contrário dos atributos, as propriedades não são definidas pelo formato IFC e podem ser definidas livremente pelo usuário (ou pela aplicação BIM). Pense nelas como atributos personalizados. O formato IFC também propõe conjuntos padrão de propriedades para muitas classes de elementos. Por exemplo, para vigas, existe um conjunto chamado BimCommon, que contém uma série de propriedades típicas de vigas.

  • A geometria dos elementos IFC é definida em elementos separados, associados a cada parede, janela, porta, etc. Ela também pode ser compartilhada por vários elementos. Existem inúmeras maneiras de definir a geometria, e é aí que surgem muitos problemas. Elementos de construção podem ter geometria 3D e 2D (por exemplo, uma vista em planta ou projeção horizontal) e, também, geometria linear (útil para estudos de estabilidade). Uma boa geometria é, geralmente, bem definida e construída de forma sensata. Por exemplo, a geometria de uma parede simples seria definida por um retângulo no plano de base — com largura e comprimento — que é então extrudado verticalmente até uma determinada altura para gerar o formato da parede. Isso corresponde a três linhas no arquivo IFC: o retângulo, a extrusão e a posição do objeto final. Essa estrutura é reconhecível por outros aplicativos BIM, e os parâmetros podem ser alterados (como, por exemplo, a largura do retângulo da base).

  • Em alguns arquivos IFC que você venha a receber, essa informação lógica pode ser totalmente perdida, e a geometria da parede pode acabar definida apenas como um conjunto de faces triangulares. Isso ocorre frequentemente com arquivos convertidos para IFC a partir de outros formatos. Podem surgir outros problemas, como relações incompletas, entre outros. Basta dizer que o formato IFC permite uma enorme variedade de formas de definir a geometria, desde as mais "simples" (faces triangulares) até as mais "inteligentes" (objetos baseados em NURBS), com grande ênfase em sólidos bem definidos (como o nosso retângulo extrudado). Felizmente para nós, essa é a especialidade do FreeCAD.

Abrir, criar e converter modelos IFC

No FreeCAD, abrir um arquivo IFC é feito da mesma forma que qualquer outro arquivo, através do menu Arquivo → Abrir. Por padrão, os arquivos IFC são carregados com apenas um elemento visível na Vista em árvore. Esse é o método de importação mais rápido; geralmente, é possível importar um modelo de 100 MB em questão de segundos.

Você pode alterar as preferências de importação IFC nativa em Editar → Preferências → BIM → IFC Nativo. É possível, por exemplo, definir que toda a estrutura do edifício seja exibida na importação ou que o sistema solicite uma confirmação a cada vez.

A criação de um novo modelo IFC começa simplesmente pela criação de um novo projeto IFC no menu 3D/BIM.

A conversão de um modelo do FreeCAD que não está no formato IFC para IFC nativo pode ser feita simplesmente exportando-o para IFC, utilizando o menu **Arquivo → Exportar** ou o botão de cadeado (mais detalhes abaixo).

Explorando o modelo

Expandindo o conteúdo do modelo

Por padrão, ao abrir arquivos IFC, é exibido apenas o primeiro elemento externo do arquivo — geralmente o `IfcSite`. Para visualizar o conteúdo desse elemento e dos subsequentes, é necessário expandi-lo. A expansão é realizada clicando duas vezes no elemento na visualização em árvore ou, alternativamente, por meio da opção de menu Utils → IFC expand. Esse comando pode ser personalizado e ter um atalho de teclado atribuído, permitindo navegar pela visualização em árvore com as teclas de seta e expandir o modelo onde for necessário utilizando apenas o teclado.

Clicar duas vezes em um elemento na visualização em árvore irá, na primeira vez, revelar seus elementos filhos e, na segunda vez — ou caso não haja mais elementos filhos a revelar —, carregar suas propriedades completas, material e forma.

Isso permite carregar um modelo o mais rápido possível e expandir ou definir elementos conforme necessário. Você pode alterar esse comportamento em Editar → Preferências → BIM → IFC Nativo.

Bloqueio e desbloqueio

Quando um modelo IFC é carregado no FreeCAD, ele pode ser bloqueado ou desbloqueado. Por padrão, abrir arquivos IFC resulta no bloqueio deles, enquanto importá-los (usando Arquivo → Importar) os deixa desbloqueados.

O bloqueio ou desbloqueio é feito simplesmente usando o botão de bloqueio na barra de status do FreeCAD:

  • Modo bloqueado: significa que o documento do FreeCAD *é* o arquivo IFC. Você não vê o IfcProject (ele é o próprio documento do FreeCAD na visualização em árvore), e qualquer ação realizada nesse documento é aplicada automática, transparente e imediatamente aos dados IFC. Adicionar uma parede modifica o arquivo IFC, assim como adicionar uma linha ou uma cota; tudo é feito em IFC. Não é possível ter no documento nenhum elemento do FreeCAD que não faça parte do arquivo IFC. Você pode converter qualquer modelo do FreeCAD (BIM ou não) para IFC clicando no botão de bloqueio.
  • Modo desbloqueado: também chamado de modo híbrido, significa que o projeto IFC reside dentro de um objeto projeto. Você pode ter objetos normais do FreeCAD (que não sejam IFC) juntamente com os elementos IFC. Para adicionar um elemento ao projeto IFC, você mesmo deve incluí-lo, arrastando-o para o projeto ou para um dos subelementos do projeto. Você pode criar um novo projeto IFC vazio usando o menu 3D/BIM → Projeto.
  • Trabalhando sem nenhum projeto IFC: Lembre-se de que não é necessário criar um projeto IFC para iniciar um projeto BIM (isso pode ser feito posteriormente, a qualquer momento, se necessário). Você pode simplesmente começar a construir paredes e adicionar pavimentos e telhados, sem definir uma estrutura IFC ou sequer se preocupar com o IFC.

O modo bloqueado significa um modo cauteloso: ao abrir um arquivo criado por outra pessoa, você não quer quebrar nada; você quer explorar o arquivo e, talvez, corrigir algo ou fazer algumas alterações pontuais. Você quer garantir que as alterações realizadas sejam estritamente localizadas e rastreáveis.

Em todos os outros casos, não há necessidade ou vantagem real em bloquear o seu modelo. Na verdade, você pode alterar o comportamento padrão para abrir modelos IFC como desbloqueados, se preferir, em Editar → Preferências → BIM → IFC Nativo.

Ao trabalhar com um modelo IFC, muitas vezes você deseja verificar o que foi alterado nos dados IFC desde o último salvamento. Isso é feito utilizando Utils → IFC Diff. As alterações são apresentadas no formato diff, com seções destacadas em vermelho e verde. Esse formato também é compreendido por sistemas computacionais como o Git, capazes de rastrear grandes conjuntos de alterações, tornando assim seus arquivos IFC elementos de primeira classe nesses sistemas.

Estrutura do modelo

Como visto anteriormente, a maioria dos arquivos IFC utiliza uma estrutura padrão Terreno → Edifício → Pavimento (Site → Building → Storey). Isso é tão comum que muitas vezes é considerado obrigatório, embora não esteja expressamente definido na norma IFC. Você poderia, perfeitamente, ter todos os seus elementos diretamente vinculados ao `IfcProject`. No entanto, como a padronização funciona quando todos decidem utilizar o mesmo sistema, é recomendável incluir pelo menos um terreno, um edifício e um pavimento (chamado de Level no FreeCAD) em seu modelo.

No FreeCAD, é possível utilizar Grupos para organizar ainda mais os objetos dentro de um nível. Por exemplo, no pavimento térreo, você poderia criar um grupo 'Paredes' para incluir todas as suas paredes, um grupo 'Carpintaria' para as vigas de madeira, etc. O formato IFC oferece suporte a grupos; no entanto, não é prática padrão inserir grupos dentro de um elemento da estrutura da edificação, como um pavimento. Por isso, por padrão, os grupos são gravados como IfcBuildingElementAssemblies em vez de IfcGroups. No entanto, no FreeCAD, consideramos esse comportamento útil e defendemos que ele seja permitido. Por isso, existe uma opção de preferência para habilitá-lo. A maioria dos aplicativos BIM abre sem problemas arquivos que contêm grupos dentro de outros elementos. Essa opção de preferência existe para ajudar a disseminar nossa visão e, possivelmente, convencer as pessoas.

Então, mãos à obra: vamos começar a quebrar o nosso modelo...

Adicionando e modificando elementos

Modificando atributos e propriedades

Depois de abrir um modelo, podemos começar a modificar seu conteúdo. Vale ressaltar que, no momento em que escrevo este tutorial, não existe um editor gráfico de geometria para elementos IFC (embora isso esteja no roteiro de desenvolvimento e deva chegar em breve). A maneira de modificar a geometria dos elementos é alterando suas propriedades geométricas.

Quando elementos IFC são carregados a partir do arquivo, seus atributos são exibidos na Visualização de Propriedades (Property View), sob o grupo IFC. Lá, você pode alterar itens como nome, descrição ou até mesmo a classe dos elementos.

Ao clicar duas vezes em um elemento na visualização em árvore, você primeiro exibirá os elementos filhos desse elemento. Ao clicar duas vezes uma segunda vez, você carregará dados adicionais, como conjuntos de propriedades, propriedades personalizadas, materiais e dados de forma. Além disso, será criado um conjunto de propriedades de geometria que permitirá modificar a geometria desse elemento. Essas propriedades de geometria também constituem a base do futuro editor gráfico.

Todas essas propriedades adicionais podem ser alteradas diretamente, e novas propriedades personalizadas podem ser adicionadas usando os dois botões abaixo do editor de propriedades.

Modificando a geometria

Você pode alterar a posição de qualquer elemento modificando sua propriedade Placement (ou utilizando as ferramentas Mover ou Rotacionar).

Para modificar a geometria, como a largura de uma parede, você precisa primeiro clicar duas vezes nela para exibir suas propriedades geométricas. Se essa parede tiver sido construída da maneira padrão — como um retângulo extrudado —, você verá a largura e o comprimento do retângulo, bem como a altura da extrusão, entre essas propriedades.

É claro que tudo depende de como a parede foi definida no arquivo IFC. Ela pode não ser um retângulo extrudado. Nesse caso, menos propriedades geométricas — ou propriedades diferentes — podem estar disponíveis.

Adicionando novos objetos BIM

A maneira de adicionar novos objetos depende do modo atual: bloqueado ou desbloqueado. No modo bloqueado, qualquer elemento que você desenhe — como uma parede ou uma coluna — é criado automaticamente no próprio arquivo IFC. Após a criação, pode ser necessário posicioná-lo no nível ou edifício correto; isso é feito simplesmente arrastando a nova parede para baixo do nível adequado na visualização em árvore (Tree view).

No modo desbloqueado, sua nova parede ainda não será um elemento IFC. Você sempre precisará arrastar a parede manualmente para o local correto após a criação.

Tipos

No IFC, qualquer elemento pode ser definido por um tipo. Um tipo (por exemplo, IfcWallType, IfcWindowType) é um elemento IFC que pode conter características, propriedades ou até mesmo geometria em comum, as quais serão utilizadas automaticamente por todos os objetos desse tipo. Em algumas aplicações BIM, isso é por vezes denominado "famílias".

No FreeCAD, em projetos BIM que não utilizam IFC, costumávamos fazer isso por meio de clonagem. No IFC nativo, há suporte completo para tipos. Para definir um tipo, a maneira mais fácil é criar um objeto de uma classe desejada — por exemplo, uma parede —, clicar com o botão direito sobre ele na visualização em árvore e selecionar IFC → Converter para tipo.

Quando um objeto é convertido em um tipo, ele é movido para um grupo especial chamado "Types" (Tipos) no projeto. Ele pode, então, ser referenciado por qualquer outra parede no projeto.

Adicionando conteúdo para download

Em um projeto BIM, frequentemente é necessário adicionar conteúdos para download, como peças de mobiliário, eletrodomésticos ou elementos como esquadrias pré-fabricadas. Esses elementos são geralmente baixados de sites de fabricantes ou de bibliotecas BIM.

Em todos esses casos, a qualidade e o formato dos elementos que você baixa são importantes. Você deve priorizar (nessa ordem): utilizar um formato de arquivo bem suportado pelo FreeCAD, obter modelos com boa qualidade geométrica e garantir a presença de metadados suficientes (cor, materiais, informações do fabricante, etc.). Algumas boas ideias são:

  • Arquivos STEP do GrabCAD: os arquivos STEP contam com excelente suporte no FreeCAD e geralmente apresentam geometria de alta qualidade, sendo um formato muito utilizado na engenharia. Eles também costumam ser convertidos muito bem para o formato IFC.
  • Arquivos IFC de bibliotecas de modelos como o BIMObject: embora o uso do formato IFC possa parecer interessante, os arquivos IFC disponibilizados nesses sites são frequentemente convertidos automaticamente a partir de outros formatos (proprietários), o que pode resultar em baixa qualidade.
  • Exportação de modelos de aplicativos BIM proprietários, como Revit ou ArchiCAD, para o formato SAT, seguida da abertura desses arquivos no FreeCAD com o complemento Inventor Loader (que pode ser instalado pelo Gerenciador de Complementos): embora esses aplicativos permitam exportar peças e elementos para IFC, muitas vezes a qualidade da geometria é prejudicada nesse processo. A exportação de tipos e famílias para o formato SAT geralmente resulta em uma qualidade comparável à dos arquivos STEP. No entanto, o complemento Inventor Loader ainda está em desenvolvimento e pode não funcionar com todos os arquivos.

Salvando e manipulando arquivos

Um arquivo do FreeCAD que contenha um projeto IFC nativo — seja ele bloqueado ou desbloqueado — sempre terá um arquivo IFC associado, no qual os dados IFC são armazenados. Ao criar um novo projeto sem ainda ter salvo o arquivo, o conteúdo IFC permanece na memória. Assim que você salva o arquivo, um arquivo IFC complementar é criado e passa a ficar vinculado ao arquivo do FreeCAD.

No modo bloqueado, o documento do FreeCAD contém, em sua propriedade IFC File Path (Caminho do Arquivo IFC), o caminho para o arquivo IFC associado. Como tudo o que ocorre no FreeCAD acontece diretamente no arquivo IFC, o arquivo do FreeCAD deixa de ser necessário. As opções 'Salvar' e 'Salvar como' no menu de arquivos do FreeCAD são substituídas por 'Salvar arquivo IFC' e 'Salvar arquivo IFC como...'. Ao salvar, você estará salvando o arquivo IFC, e nenhum arquivo do FreeCAD será gravado. Literalmente, você trabalha apenas com o arquivo IFC.

No modo desbloqueado, existe um objeto project no documento do FreeCAD que também possui uma propriedade IFC file Path (Caminho do arquivo IFC), a qual aponta para o arquivo IFC associado. Se você compartilhar seu arquivo com outra pessoa, precisará fornecer também o arquivo IFC. Se você mover o arquivo IFC, precisará corrigir a propriedade IFC File Path do objeto de projeto.

No entanto, é possível distribuir o arquivo do FreeCAD sem o arquivo IFC: defina a propriedade "Shape Mode" de todos os objetos como "Shape". Isso fará com que o arquivo do FreeCAD preserve a forma de todos os objetos e abra corretamente, mesmo que o arquivo IFC não esteja presente. Nesse caso, porém, os objetos não serão editáveis.

Gerando saída

Criando vistas e conteúdo 2D

Vistas 2D, destinadas a serem colocadas em folhas do TechDraw, ainda podem ser criadas da mesma maneira de antes: adicionando planos de corte, criando vistas 2D, preenchendo-as com anotações e, em seguida, posicionando-as em folhas. O processo é exatamente o mesmo tanto para modelos BIM que não são IFC quanto para modelos IFC nativos.

No entanto, por padrão, os objetos IFC nativos são carregados sem sua geometria (a propriedade "Shape Mode" é definida como 'Coin'). Isso economiza muito tempo durante o carregamento. Contudo, os algoritmos de corte utilizados para gerar vistas 2D exigem a geometria completa; portanto, ao incluir objetos IFC nativos em um plano de corte, o "Shape Mode" deles será definido automaticamente como 'Shape'.

Embora a folha final em si não possa ser salva atualmente no arquivo IFC, as vistas 2D, os planos de corte e suas anotações podem. Ao adicionar um plano de corte a um projeto (seja arrastando e soltando no modo desbloqueado ou automaticamente no modo bloqueado), um grupo é criado automaticamente sob o projeto. Esse grupo representa uma vista 2D (sua propriedade "Tipo de Objeto" é definida como 'DRAWING'), e tudo o que você adicionar a esse grupo fará parte dessa vista 2D.

Criando planilhas

No momento, as folhas não são salvas no arquivo IFC. Portanto, no caso de arquivos bloqueados, as folhas precisarão ser recriadas.

Criando agendamentos

Tabelas e consultas de todos os tipos podem ser criadas da mesma maneira tanto para projetos IFC nativos quanto para projetos não IFC, utilizando a ferramenta de Tabela. Tabelas também podem ser adicionadas a um projeto IFC nativo; nesse caso, a planilha associada a elas não é salva no arquivo IFC e deve ser recriada ao abrir o arquivo.

Scripting em Python

IfcOpenShell

O IfcOpenShell é o componente de software utilizado em todas as operações relacionadas ao IFC no FreeCAD. A bancada de trabalho BIM pode funcionar sem ele, mas, nesse caso, todas as operações IFC ficam desabilitadas. O IfcOpenShell é responsável pela criação e modificação de arquivos e objetos IFC, bem como pela geração de geometria BREP para os objetos do FreeCAD que representam elementos IFC. Atualmente, o FreeCAD utiliza o IfcOpenShell apenas por meio de sua interface Python.

O IfcOpenShell oferece uma documentação abrangente que explica detalhadamente como utilizá-lo.

You can also use both IfcOpenShell and ifc_tools to manipulate IFC data directly. Below is a short example of how to use IfcOpenShell to open an IFC file and analyze its contents: 

import ifcopenshell
my_ifc_file = ifcopenshell.open("/path/to/some/file.ifc")
walls = my_ifc_file.by_type("IfcWall") # get a list of all IfcWalls
some_specific_object = my_ifc_file[66] # get an object by its ID
some_specific_object = my_ifc_file.by_id(66) # alternative way
print(some_specific_object.Name) # you can access attributes that way

IfcOpenShell itself has no specific FreeCAD functionality (yet), so you would use it basically to do non-FreeCAD operations on objects, for example retrieve or modify objects and attributes, modify attributes, or even directly add objects. Be sure to have a look at the IfcOpenShell Python documentation to know more.

In FreeCAD, once you load an IFC file, an IfcOpenShell file object is created and attached to the project (the project object for unlocked files or the FreeCAD document itself for locked projects). Everything you do in FreeCAD actually manipulates that object. You can easily get access and manipulate the IfcOpenShell file object of a FreeCAD native IFC project. For example, in locked mode, you do: 

import FreeCAD
my_doc = FreeCAD.loadFile("/path/to/some/file.ifc")
my_ifc_file = my_doc.Proxy.ifcfile

In unlocked mode, each project object also has a Proxy.ifcfile member.

The ifc_tools module

The ifc_tools module is the main tool to use IfcOpenShell in FreeCAD's BIM module. It contains many tools and functions to do everything FreeCAD needs to do with IFC files and objects, such as creating new files, opening files, creating elements, modifying attributes, etc.

When working with FreeCAD objects, using ifc_tools is much more convenient as it handles for you all the relationship between the FreeCAD object and the IFC object it represents. For example: 

from nativeifc import ifc_tools
selection = FreeCADGui.Selection.getSelection()
my_obj = selection[0] # just get the first selected object
project = ifc_tools.get_project(my_obj)
ifcfile = ifc_tools.get_ifcfile(project)
ifc_elem = ifc_tools.get_ifc_element(my_obj)
my_obj.LongName = "Changed long name" # this updates the IFC data too
print(ifc_elem.LongName)

There is much more in ifc_tools, such as utilities to create and modify FreeCAD objects (and their underlying IFC elements). Below are a few simple examples to get you started:

Load the shape of selected objects

By default, opening an IFC file will only load a lightweight 3D representation of each element. To do more serious work with them, we might need to load their full shape: 

for obj in FreeCADGui.Selection.getSelection():
    obj.ShapeMode = "Shape"
FreeCAD.ActiveDocument.recompute()

Load the property sets of selected objects

Property sets and their included properties are rendered as object properties in FreeCAD. Once they are loaded, you can simply manipulate the values through the properties editor in FreeCAD (or via Python): 

from nativeifc import ifc_psets
for obj in FreeCADGui.Selection.getSelection():
    ifc_psets.show_psets(obj)
my_object.FireResistanceClass = "1B" # manipulate properties once loaded

Saving an IFC file

ifc_tools.save(project)

Add a new IFC document

Use the Project tool from the BIM workbench to produce a native IFC project object. It is not mandatory to save your new IFC project immediately, but it is a good practice anyway. If you forget to do so, you will get notified and be able to do it when saving the FreeCAD document. 

doc = FreeCAD.ActiveDocument
new_project = ifc_tools.create_document(doc)
ifc_tools.save(new_project, "/path/for/our/new/file.ifc")

Modifying the IFC class of an object

Changing the class is very easy, one can simply select another one in the object's class property. Be warned, this might also change the predefined attributes of that object, so some attributes might vanish. 

my_object.Class = "IfcWall"

Aggregate (and convert) any FreeCAD object to an IFC project

Suppose we built a new wall, and we need to add it to an IFC project. We can do that graphically by dragging it and dropping it onto the project in the tree view, but it is as easy in Python: 

import Arch
my_new_wall = Arch.makeWall(None, 200, 20, 300)
ifc_tools.aggregate(my_new_wall, project)

Add a new model structure

When creating a new project, you can also have a basic structure automatically created for you by answering 'yes' on the dialog that will pop up. But you can also easily do that in Python: 

import Arch
doc = FreeCAD.ActiveDocument
project = ifc_tools.create_document(doc)
site = Arch.makeSite()
site = ifc_tools.aggregate(site, project)
building = Arch.makeBuilding()
building = ifc_tools.aggregate(building, site)
level = Arch.makeFloor()
level = ifc_tools.aggregate(floor, building)

Change the schema of an IFC document

Simply change the 'Schema' property of the project. Be warned, this can have deep consequences (some object types might have changed in the new schema version), so use with care and check your data afterwards. 

project.Schema = "IFC4"

There is much more to explore, as more functionality is available through the different native IFC submodules, each one provides tools to deal with a certain aspect of IFC (property sets, geometry, layers…). Be sure to explore them if needed!

I hope you now have a good idea of where to start and what can be done with native IFC in FreeCAD. Be sure to head to the BIM section on the FreeCAD forum if you need some help!
