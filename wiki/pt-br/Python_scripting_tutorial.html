Introdução

O Python é uma linguagem de programação relativamente fácil de aprender e entender. É uma linguagem de código aberto e multiplataforma, podendo ser utilizada para diversas finalidades: desde simples scripts de shell até programas muito complexos. No entanto, seu uso mais difundido é como linguagem de script incorporada a outras aplicações. É dessa forma que ele é utilizado no FreeCAD. A partir do Console Python ou de scripts personalizados, você pode controlar o FreeCAD e fazê-lo realizar operações muito complexas.

Por exemplo, a partir de um script Python, você pode:

  • Criar novos objetos.
  • Modificar objetos existentes.
  • Modificar a representação 3D desses objetos.
  • Modificar a interface do FreeCAD.

Existem várias maneiras de usar Python no FreeCAD:

  • A partir do interpretador Python do FreeCAD, onde você pode executar comandos em uma interface do tipo "linha de comando".
  • Por meio de Macros, que são uma maneira conveniente de adicionar rapidamente uma ferramenta ausente à interface do FreeCAD.
  • A partir de scripts externos, que podem ser usados ​​para criar soluções bastante complexas, inclusive Workbenches (ambientes de trabalho) completos.

Neste tutorial, trabalharemos em alguns exemplos básicos para você começar, mas há muito mais documentação sobre scripts em Python disponível nesta wiki. Se você é totalmente iniciante em Python e quer entender como a linguagem funciona, também temos uma introdução básica ao Python.

Antes de prosseguir com a criação de scripts em Python, vá para Editar → Preferências → Geral → Visualização de relatório e marque duas caixas:

  • Redirecionar saída interna do Python para a visualização de relatório.
  • Redirecionar erros internos do Python para a visualização de relatório.

Em seguida, vá para Exibir → Painéis e marque:

  • Visualização de relatório.

Escrevendo código Python

Existem duas maneiras de escrever código Python no FreeCAD: no Console Python (selecione Exibir → Painéis → Console Python no menu) ou no Editor de macros (selecione Macro → Macros no menu). No console, você escreve comandos Python um de cada vez, executando-os ao pressionar Enter, enquanto as macros podem conter códigos mais complexos compostos por várias linhas, executados apenas quando a macro é iniciada.

Explorando o FreeCAD

Vamos começar criando um novo documento vazio: 

doc = FreeCAD.newDocument()

Se você digitar isso no console Python do FreeCAD, notará que, assim que digitar FreeCAD., uma janela aparecerá, permitindo completar rapidamente o restante da linha. Melhor ainda: cada item da lista de preenchimento automático possui uma dica de ferramenta explicando sua função. Isso facilita a exploração das funcionalidades disponíveis. Antes de escolher newDocument, dê uma olhada nas outras opções.

Template:Legenda

Agora, nosso novo documento será criado. Isso é semelhante a clicar no botão Novo na barra de ferramentas. Na verdade, a maioria dos botões no FreeCAD não faz nada além de executar uma ou mais linhas de código Python. Melhor ainda: você pode ativar uma opção em Editar → Preferências → Python → Macro para Mostrar comandos de script no console Python. Isso fará com que todo o código Python executado ao clicar nos botões seja exibido no console. É muito útil para aprender a reproduzir ações usando Python.

Agora, vamos voltar ao nosso documento e ver o que podemos fazer com ele: 

doc.

Explore as opções disponíveis. Normalmente, nomes que começam com letra maiúscula são atributos — eles contêm um valor —, enquanto nomes que começam com letra minúscula são funções (também chamadas de métodos) — eles "fazem algo". Nomes que começam com um sublinhado geralmente servem para o funcionamento interno do módulo, e você não precisa se preocupar com eles. Vamos usar um dos métodos para adicionar um novo objeto ao nosso documento: 

box = doc.addObject("Part::Box", "myBox")

Nada acontece. Por quê? Porque o FreeCAD foi projetado para lidar com o panorama geral. Um dia, ele trabalhará com centenas de objetos complexos, todos interdependentes. Fazer uma pequena alteração em algum ponto pode ter um grande impacto; pode ser necessário recalcular todo o documento, o que pode levar muito tempo. Por esse motivo, quase nenhum comando atualiza a cena automaticamente. Você deve fazer isso manualmente: 

doc.recompute()

Agora, nosso cubo apareceu. Muitos dos botões que adicionam objetos no FreeCAD, na verdade, realizam duas ações: adicionar o objeto e recomputar. Se você tiver ativado a opção Mostrar comandos de script no console Python mencionada anteriormente, tente adicionar uma esfera usando o botão da interface gráfica; você verá as duas linhas de código Python sendo executadas em sequência.

Agora, vamos explorar o conteúdo da nossa caixa: 

box.

Você verá imediatamente algumas coisas muito interessantes, como: 

box.Height

Isso imprimirá a altura atual da nossa caixa. Agora, vamos tentar alterar isso: 

box.Height = 5

Se você selecionar sua caixa com o mouse, verá que na Visualização de Propriedades, na aba Dados, aparece a nossa propriedade DadosHeight. Todas as propriedades de um objeto do FreeCAD que aparecem ali (e também na aba Visualização — falaremos mais sobre isso depois) também são diretamente acessíveis via Python, por meio de seus nomes, assim como fizemos com a propriedade DadosHeight. Tente alterar as outras dimensões da caixa.

Vetores e posicionamentos

Vetores são um conceito fundamental em qualquer aplicação 3D. Um vetor é uma lista de 3 números (x, y e z) que descreve um ponto ou posição no espaço 3D. Muitas operações podem ser realizadas com vetores, como adições, subtrações, projeções e muito mais. No FreeCAD, os vetores funcionam da seguinte maneira: 

myvec = FreeCAD.Vector(2, 0, 0)
myvec.x
myvec.y
othervec = FreeCAD.Vector(0, 3, 0)
sumvec = myvec.add(othervec)

Outra característica comum dos objetos do FreeCAD é o seu posicionamento. Cada objeto possui uma propriedade DadosPlacement, que contém a DadosBase (posição) e a DadosRotation (orientação) do objeto. É fácil de manipular; por exemplo, para mover o nosso objeto: 

box.Placement
box.Placement.Base
box.Placement.Base = sumvec
 
otherpla = FreeCAD.Placement()
box.Placement = otherpla

Agora, você precisa entender alguns conceitos importantes antes de prosseguirmos.

Aplicativo e Interface Gráfica

O FreeCAD foi projetado para também poder ser utilizado sem a sua interface de usuário, como uma aplicação de linha de comando. Por isso, quase todos os objetos no FreeCAD consistem em duas partes: um Object (seu componente de "geometria") e um ViewObject (seu componente "visual"). Ao trabalhar no modo de linha de comando, a parte geométrica está presente, mas a parte visual está desativada.

Para ilustrar o conceito, vamos analisar nosso objeto cubo. As propriedades geométricas do cubo, como suas dimensões, posição, etc., são armazenadas no Object, enquanto suas propriedades visuais, como cor, espessura da linha, etc., são armazenadas no ViewObject. Isso corresponde às abas Dados e Visualização no Editor de Propriedades. O objeto de visualização de um objeto é acessado da seguinte forma: 

vo = box.ViewObject

Agora você também pode alterar as propriedades na guia Exibir: 

vo.Transparency = 80
vo.hide()
vo.show()

Ao iniciar o FreeCAD, o console Python já carrega dois módulos básicos: FreeCAD e FreeCADGui (que também podem ser acessados ​​pelos seus atalhos App e Gui). Eles contêm diversas funcionalidades genéricas para trabalhar com documentos e seus objetos. Para ilustrar esse conceito, observe que tanto FreeCAD quanto FreeCADGui possuem um atributo ActiveDocument, que corresponde ao documento aberto no momento. No entanto, FreeCAD.ActiveDocument e FreeCADGui.ActiveDocument não são o mesmo objeto. Eles são os dois componentes de um documento do FreeCAD e contêm atributos e métodos diferentes. Por exemplo, FreeCADGui.ActiveDocument contém ActiveView, que é a Vista 3D aberta no momento.

Módulos

O verdadeiro poder do FreeCAD reside em seus módulos dedicados, com suas respectivas bancadas de trabalho (*workbenches*). A aplicação base do FreeCAD é, mais ou menos, um recipiente vazio; sem seus módulos, ela pouco mais consegue fazer além de criar documentos novos e vazios. Cada módulo não apenas adiciona novas bancadas de trabalho à interface, mas também novos comandos Python e novos tipos de objeto. Como resultado, diversos tipos de objeto diferentes — e até mesmo totalmente incompatíveis entre si — podem coexistir no mesmo documento. Os módulos mais importantes do FreeCAD que abordaremos neste tutorial são: Part, Mesh, Sketcher e Draft.

Tanto o Sketcher quanto o Draft utilizam o módulo Part para criar e manipular suas geometrias, ao passo que o Mesh é totalmente independente e gerencia seus próprios objetos. Mais detalhes abaixo.

Você pode verificar todos os tipos de objeto base disponíveis para o documento atual da seguinte forma: 

doc.supportedTypes()

Os diferentes módulos do FreeCAD não são carregados automaticamente no console Python. Isso serve para evitar uma inicialização muito lenta. Os módulos são carregados apenas quando você precisa deles. Assim, por exemplo, para explorar o conteúdo do módulo Part: 

import Part
Part.

Mas falaremos mais sobre o módulo Part abaixo.

Módulo de malha

Malhas são um tipo muito simples de objeto 3D, utilizadas, por exemplo, pelo SketchUp, Blender e 3D Studio Max. Elas são compostas por três elementos: pontos (também chamados de vértices), linhas (também chamadas de arestas) e faces. Em muitas aplicações, inclusive no FreeCAD, as faces podem ter apenas 3 vértices. Naturalmente, nada impede que você tenha uma face maior composta por vários triângulos coplanares.

Malhas são simples, mas, justamente por serem simples, é fácil ter milhões delas em um único documento. No entanto, no FreeCAD, elas têm menos utilidade e servem principalmente para permitir a importação de objetos em formatos de malha (.stl, .obj) provenientes de outros aplicativos. O módulo Mesh também foi amplamente utilizado como o principal módulo de testes durante o primeiro mês de existência do FreeCAD.

Objetos de malha e objetos do FreeCAD são coisas diferentes. Você pode encarar o objeto do FreeCAD como um contêiner para um objeto de malha (e, como veremos a seguir, também para objetos do tipo *Part*). Portanto, para adicionar um objeto de malha ao FreeCAD, devemos primeiro criar um objeto do FreeCAD e um objeto de malha e, em seguida, adicionar o objeto de malha ao objeto do FreeCAD: 

import Mesh
mymesh = Mesh.createSphere()
mymesh.Facets
mymesh.Points
 
meshobj = doc.addObject("Mesh::Feature", "MyMesh")
meshobj.Mesh = mymesh
doc.recompute()

Este é um exemplo padrão que utiliza o método createSphere() para criar uma esfera, mas você também pode criar malhas personalizadas do zero, definindo seus vértices e faces.

Módulo Part

O módulo Part é o módulo mais poderoso de todo o FreeCAD. Ele permite criar e manipular objetos BRep. BREP significa "Boundary Representation" (Representação de Fronteira). Um objeto BREP é definido por superfícies que delimitam e definem um volume interno. Ao contrário das malhas, os objetos BREP podem apresentar uma grande variedade de componentes, desde faces planas até superfícies NURBS muito complexas.

O módulo Part baseia-se na poderosa biblioteca OpenCasCade, que permite realizar uma ampla gama de operações complexas nesses objetos, como operações booleanas, arredondamentos, *lofts*, etc.

O módulo Part funciona da mesma maneira que o módulo Mesh: você cria um objeto do FreeCAD — um objeto Part — e, em seguida, adiciona o objeto Part ao objeto do FreeCAD: 

import Part
myshape = Part.makeSphere(10)
myshape.Volume
myshape.Area

shapeobj = doc.addObject("Part::Feature", "MyShape")
shapeobj.Shape = myshape
doc.recompute()

The Part module (like the Mesh module) also has a shortcut that automatically creates a FreeCAD object and adds a shape to it, so you can shorten the last three lines to: 

Part.show(myshape)

By exploring the contents of myshape, you will notice many interesting subcomponents such as Faces, Edges, Vertexes, Solids and Shells, and a wide range of geometry operations such as cut (subtraction), common (intersection) or fuse (union). The Topological data scripting page explains all that in detail.

Draft module

FreeCAD features many more modules, such as Sketcher and Draft, that also create Part objects. These modules add additional parameters to the objects created, or even implement a whole new way to handle the Part geometry in them. Our box example above is a perfect example of a parametric object. All you need to define the box is to specify the parameters height, width and length. Based on those, the object will automatically calculate its Part shape. FreeCAD allows you to create such objects in Python.

The Draft module adds 2D parametric object types (which are all Part objects) such as lines and circles, and also provides some generic functions that not only work on Draft objects, but on any Part object. To explore what is available, simply do: 

import Draft
rec = Draft.makeRectangle(5, 2)
mvec = FreeCAD.Vector(4, 4, 0)
Draft.move(rec, mvec)
Draft.move(box, mvec)

Interface

The FreeCAD user interface is made with Qt, a powerful graphical interface system, responsible for drawing and handling all the controls, menus, toolbars and buttons around the 3D view. Qt provides a module, PySide, which allows Python to access and modify Qt interfaces such as FreeCAD's. Let's try to fiddle with the Qt interface and produce a simple dialog: 

from PySide import QtGui
QtGui.QMessageBox.information(None, "Apollo program", "Houston, we have a problem")

Notice that the dialog that appears has the FreeCAD icon in its toolbar, meaning that Qt knows that the order has been issued from inside the FreeCAD application. It is possible to manipulate any part of the FreeCAD interface.

Qt is a very powerful interface system that allows you to do very complex things. It also has some easy-to-use tools such as the Qt Designer with which you can design dialogs graphically and then add them to the FreeCAD interface with a few lines of Python code.

Macros

Now that you have a good understanding of the basics, where are we going to keep our Python scripts, and how are we going to launch them inside FreeCAD? There is an easy mechanism for that, called Macros. A macro is a Python script that can be added to a toolbar and launched via a mouse click. FreeCAD provides you with a simple text editor (Macro → Macros → Create) where you can write or paste scripts. Once the script is done, use Tools → Customize → Macros to define a button for it that can be added to toolbars.

External scripts

An alternative method for creating, saving, and running your own Python scripts is to create them outside FreeCAD, using an editor of your choice (for example, Vim). To run your Python script inside FreeCAD, be sure to save it with the .py extension.

Then use File → Open to open your script. It will load into a new tab in the Main view area. You can run your script by clicking the Execute macro button. Any errors or script output will be shown in the Report View.

When you make and save any modifications to your already-loaded script, a dialog box will appear asking whether you want to reload the modified script into FreeCAD.
