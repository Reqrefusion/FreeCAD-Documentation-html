Apresentando o FreeCAD

O FreeCAD é um modelador 3D paramétrico. A modelagem paramétrica permite modificar facilmente seu projeto, retornando ao histórico do modelo e alterando seus parâmetros. O FreeCAD é de código aberto (licença LGPL) e altamente modular, permitindo extensões e personalizações bastante avançadas, especialmente graças ao uso intensivo da linguagem Python.

Instalando o FreeCAD

Você tem a opção de instalar a versão estável mais recente (atualmente, maio de 2015: versão 0.15) ou uma versão de desenvolvimento (atualmente 0.16). Na verdade, as versões de desenvolvimento do FreeCAD costumam ser bastante estáveis, e é altamente recomendável que você experimente uma versão de desenvolvimento, a menos que tenha um motivo específico para não fazê-lo. Como o desenvolvimento do FreeCAD é bastante rápido, certifique-se, se estiver baixando manualmente, de verificar periodicamente e reinstalar/atualizar para aproveitar as melhorias mais recentes.

  • No Windows: Baixe a versão mais recente compatível com a sua versão do Windows (32 ou 64 bits) em https://github.com/FreeCAD/FreeCAD/releases. Clique duas vezes no arquivo para instalar.
  • No Mac OS: Baixe a versão mais recente em https://github.com/FreeCAD/FreeCAD/releases. Clique duas vezes no arquivo para instalar.
  • No Ubuntu: A versão do FreeCAD disponibilizada pelo Ubuntu geralmente está desatualizada; por isso, recomenda-se utilizar o PPA mantido pela comunidade do FreeCAD. Para instalar, abra o aplicativo "Fontes de Software" (Software Sources) do Ubuntu e adicione `ppa:freecad-maintainers/freecad-stable` (para a versão estável) ou `ppa:freecad-maintainers/freecad-daily` (para a versão de desenvolvimento) às fontes de software.
  • Em outras plataformas: Na maioria das distribuições Linux populares (Debian, Fedora, etc.), o FreeCAD está incluído nos repositórios oficiais de software. No entanto, nem sempre é a versão mais recente. Se a versão de que você precisa não estiver disponível, a única opção é compilar o FreeCAD por conta própria (as instruções estão no site do FreeCAD).

Conteúdo adicional opcional

  • Habilitação de importação/exportação IFC: Para importar e exportar projetos no formato de arquivo IFC, o FreeCAD utiliza o importador IfcOpenShell, que deve ser instalado separadamente a partir de https://ifcopenshell.org. Certifique-se de escolher uma versão baseada no Python 2.7, que é a mesma versão do Python utilizada pelo FreeCAD.
  • Bancada de trabalho Drawing Dimensioning: Uma bancada de trabalho adicional para o FreeCAD que oferece diversas ferramentas práticas para adicionar cotas e anotações às folhas de desenho 2D do FreeCAD: https://github.com/hamish2014/FreeCAD_drawing_dimensioning (instruções de instalação na página da web)
  • Bancada de trabalho Assembly2: Uma bancada de trabalho adicional para o FreeCAD que oferece uma série de ferramentas básicas de montagem: https://github.com/hamish2014/FreeCAD_assembly2 (instruções de instalação na página da web)

Dicas rápidas para começar

A coleção de tutoriais disponível na wiki do FreeCAD ainda é bastante limitada. No entanto, muitos membros da comunidade FreeCAD utilizam o YouTube para publicar videoaulas. Não deixe de pesquisar conteúdos relacionados ao FreeCAD no YouTube; essa é, sem dúvida, a melhor fonte de material de aprendizado.

O FreeCAD é um aplicativo altamente técnico, e sua curva de aprendizado pode ser íngreme. Não deixe de consultar tutoriais e a wiki de documentação, e não hesite em fazer perguntas no fórum caso encontre algum problema específico. Perguntas bem formuladas geralmente recebem respostas rápidas e detalhadas.

Uma lista bem geral de coisas que você precisa saber

A interface do FreeCAD é dividida em bancadas de trabalho (*workbenches*). As bancadas de trabalho são, basicamente, conjuntos de ferramentas (botões de barra de ferramentas e menus) agrupados, geralmente para uma tarefa específica. Ao mudar para outra bancada de trabalho, a interface exibe as ferramentas dessa bancada, mas o conteúdo do seu documento 3D permanece inalterado. Você continua trabalhando no mesmo documento e nos mesmos objetos.

O FreeCAD ainda está em desenvolvimento; há muitos bugs e o aplicativo pode travar ocasionalmente. Salve o trabalho com frequência e ative os arquivos de backup em Editar → Preferências → Documento.

A maioria dos objetos no FreeCAD é paramétrica. Isso significa que sua geometria é criada automaticamente a partir de uma série de parâmetros. Esses parâmetros são sempre editáveis ​​na Visualização de Propriedades. Eles estão sempre divididos entre parâmetros que afetam a geometria em si (aba Dados) e parâmetros que afetam apenas a exibição do objeto (aba Vista). No entanto, objetos criados em outros aplicativos e importados para o FreeCAD geralmente não são definidos por parâmetros e, portanto, não são editáveis.

  • Vários ambientes de trabalho (PartDesign e Arch) são projetados para operar apenas com objetos sólidos e não funcionarão com objetos que não sejam sólidos. Uma boa regra prática é sempre tentar trabalhar com objetos sólidos.

Embora o FreeCAD possa importar e trabalhar com objetos de malha (bancada de trabalho *Mesh*), ele foi projetado principalmente para trabalhar com um tipo de objeto mais avançado chamado B-Rep, utilizado pela maioria de suas bancadas de trabalho (*Part*, *PartDesign*, *Draft*, *Sketcher*, *Arch*). Ao importar arquivos baseados em malha (.dae, .orb, .stl...), geralmente é necessário converter esses objetos para B-Rep antes de poder realizar operações significativas com eles. Por outro lado, formatos de arquivo baseados em sólidos (.step, .iges), quando importados para o FreeCAD, geram diretamente objetos B-Rep. Formatos 2D (.dxf, .svg) também resultam em conteúdo B-Rep.

O FreeCAD oferece diferentes formas, ou modos, de utilizar os botões do mouse. Esses modos podem ser configurados nas preferências ou alterados rapidamente clicando com o botão direito no fundo da visualização 3D. Eles estão descritos em https://wiki.freecad.org/Mouse_navigation. Os modos mais adequados para trabalhos em CAD são "CAD" ou "Gestures" (Gestos).

Exercício: modelagem de um painel de cobertura

Para demonstrar um fluxo de trabalho típico no FreeCAD, vamos modelar um painel de telhado conforme descrito em https://wiki.opensourceecology.org/wiki/MicroHouse_4_Roof_-_Module_-_Build_Instructions. Para isso, começaremos desenhando as diferentes peças em um esboço 2D com restrições geométricas e, em seguida, utilizaremos o objeto especial "Janela Arch" (Arch Window), capaz de criar objetos 3D complexos a partir de um esboço 2D que contenha os contornos de várias peças. Por fim, como não precisamos de uma janela, mas sim de um painel de telhado, simplesmente converteremos nosso objeto de janela para outro tipo do módulo Arch.

1. Abra o FreeCAD e defina suas unidades de preferência como “imperiais”

No menu Editar → Preferências → Geral → Unidades

2. Mude para a bancada de trabalho de esboço (Sketcher) e crie um novo esboço no plano XY.

Normalmente, a menos que haja um motivo específico para não fazê-lo, você deve sempre começar a desenhar seus esboços 2D no plano de base, ao redor da origem (0,0). Em seguida, é o objeto 3D gerado a partir deles que será movido ou rotacionado para a posição desejada.

3. Desenhe dois retângulos. Em cada um deles, aplique uma restrição vertical de 16 pés e uma restrição horizontal de 2 polegadas.

Não se preocupe com as dimensões das peças ao desenhá-las; as restrições as redimensionarão adequadamente. Para adicionar uma restrição de dimensão (vertical ou horizontal), você pode selecionar uma linha ou dois pontos (mantendo a tecla CTRL pressionada).

4. Assim que os dois retângulos estiverem com o tamanho correto, aplique uma restrição vertical de 0 entre os pontos de seus cantos e uma restrição horizontal de 4 pés.

Isso garante que nossos dois retângulos estejam posicionados corretamente um em relação ao outro.

5. Adicione as duas peças adicionais de 2 pol. x 6 pol.

Adicione mais dois retângulos e repita o processo. Observe que, no exemplo acima, não especificamos o comprimento dessas peças; em vez disso, definimos uma restrição de distância entre suas extremidades e as peças verticais longas, deixando um pequeno espaço de 0,05 polegadas entre elas. Isso ocorre porque, se fizermos os retângulos se tocarem, o FreeCAD poderá identificar incorretamente os contornos (loops), resultando em comportamentos inesperados ao usar a ferramenta de janela do módulo Arch. Esse pequeno truque garante que cada retângulo seja reconhecido como um contorno independente pela ferramenta de janela do Arch.

6. Adicione as peças de reforço de canto

A mesma coisa. Faça-os com 6 polegadas de largura e separe-os dos outros retângulos por 0,05 polegadas.

7. Desenhe 7 peças de reforço intermediárias, defina a largura delas como 2 polegadas e restrinja as extremidades esquerda e direita a 0,05 polegadas dos retângulos verticais (ou a 0 polegada das extremidades dos outros retângulos horizontais)

Dependendo do seu sistema, o FreeCAD pode começar a ficar lento ao processar novas restrições. Essa é a desvantagem de usar objetos com restrições: eles consomem rapidamente muitos recursos do sistema. Você deve sempre avaliar se realmente precisa delas. Também é possível excluir as restrições depois que elas tiverem cumprido sua função. Essas dimensões deixarão de ser fixas, mas, a menos que você mova as peças, elas não mudarão. Se necessário, você sempre poderá adicionar as restrições novamente mais tarde.

8. Calcule o espaçamento entre as 7 peças de reforço e defina restrições verticais entre elas.

No nosso caso, o comprimento total é de 192 polegadas; subtraindo as duas peças das extremidades (2 x 2 polegadas) e os dois reforços de canto (2 x 6 polegadas), temos 192 – (4 + 12) = 176. Removendo as 7 peças de reforço (7 x 2), obtemos 162. Dividindo esse valor por 8, encontramos o espaço entre cada reforço: 20,25.

9. Obtendo um esboço totalmente restrito

No painel à direita (aba Tarefas na Visualização Combinada -> mensagens do Solver), você pode ver a mensagem “... 2 graus de liberdade”. Isso significa que nosso esboço não está totalmente restrito (ele ainda possui duas “maneiras” de ser deformado). Isso ocorre porque, embora nenhuma parte dele possa se mover em relação às outras, o esboço como um todo ainda pode se deslocar vertical e horizontalmente. Para evitar isso, podemos simplesmente pegar um de seus vértices, selecionar o ponto de origem da grade (onde os eixos verde e vermelho se cruzam) e clicar no botão de restrição de ponto. Isso faz com que o esboço fique verde, indicando que está totalmente restrito e que nenhuma parte dele pode mais se mover.

Na verdade, isso não é absolutamente necessário. No entanto, é sempre melhor acompanhar a posição exata dos objetos (agora temos certeza de que nosso canto está no ponto (0,0)). Isso será útil caso algo dê errado mais tarde ou se precisarmos determinar a posição de um objeto construído com base neste esboço.

Agora podemos clicar no botão "Fechar" e nosso esboço base estará criado:

10. Mude para a bancada de trabalho Arch e, com o esboço selecionado, pressione o botão “janela”

Nosso esboço agora desapareceu e um de seus retângulos foi levemente extrudado, transformando-se em uma peça sólida:

Embora isso pareça errado, acontece simplesmente porque a ferramenta Janela em Arco criou um elemento padrão a partir do maior contorno fechado que conseguiu identificar no esboço base. Vamos corrigir isso em breve. Além disso, observe que o esboço não desapareceu; ele foi apenas ocultado e "incorporado" ao seu novo objeto pai. Você ainda pode encontrá-lo na visualização em árvore, expandindo o objeto da janela, e alternar sua visibilidade pressionando a tecla ESPAÇO.

11. Edite os componentes da janela clicando duas vezes neles na exibição em árvore

Ao clicar duas vezes na janela, o esboço base torna-se visível novamente e acessamos a interface de edição: à esquerda, uma lista dos contornos encontrados no esboço base; à direita, as peças sólidas construídas a partir dele.

Comece removendo a peça "Default".

Em seguida, selecione o primeiro loop (Wire0). Ele será destacado na visualização 3D. Pressione o botão "Add" para criar uma nova peça a partir dele. Dê um nome a ela, certifique-se de que o fio correto esteja definido e aplique uma extrusão de 6 polegadas. O deslocamento (offset) deve permanecer em 0, já que queremos que ela fique posicionada "no chão".

O valor "Type" será usado para atribuir materiais à janela (ainda não implementado), portanto, por enquanto, você pode deixá-lo como "Frame".

Em seguida, pressione o botão "Create component". Às vezes, o FreeCAD não consegue determinar corretamente a direção da extrusão; portanto, você deve editar o componente e alterar o valor de 6 polegadas para -6 polegadas.

Repita isso para todas as peças necessárias:

When closing the edit panel we obtain the object above. Note that by default, window objects are represented semi-transparent. Since this will actually not be a window, we can just turn that off by setting its Transparency value to 0 in its View properties.

12. Add the cover panel

We now have our panel frame, but not the base panel itself. To do that, the best way is to open our base sketch, and add a new rectangle. Remember though to not make any of the corners of that rectangle coincident to corners of other rectangles, in order not to confuse our window object, which might require us to redo the whole series of components if the order of the loops would change.

We can therefore constrain this new rectangle 0.05 inches inside the perimeter. This will require us to place 4 new constraints.

We can then edit our window again, and add new components. We can see that a new Wire has been found. This time, we will use it to add a 8mm polycarbonate panel (note that you can mix units without problems in FreeCAD, and write “8mm” as the thickness, even if you are working in inches). We will also give it an offset of 0.05 inches, so it is slightly offsetted from the frame, just for consistency, as all the parts of our object have that offest between them.

We can now create another component based on the same Wire, in order to place another panel on top of our frame. This time, we will give it an offset of 6.05 inches. Our panel is finally complete:

13. Turn the window into another type of Arch component

This is not really necessary at the moment, but it might become important later when we export or work to other construction-oriented applications, for example via IFC, we don't want our panel to be identified as a window.

The Arch workbench of FreeCAD provides an easy way to handle that, which is that any object type can always become another, by being the base of another type. In this case, let's turn our window into a Panel object, simply by selecting the window and pressing the Panel tool.

Notice that the color of the resulting panel has changed, that is because materials support in FreeCAD and the Arch module is still incomplete. When it is finished, this will be properly handled.

14. Duplicating the panel

Our panel can then be duplicated and copied over in several ways, for example by using copy/paste. But a more interesting way is to use the Draft Clone tool (also present on the Arch workbench, like all other Draft tools). The Clone tool keeps the relationship between the base object and its clone, so any modification to the base object will reflect in all its clones.

In the current development version of FreeCAD, clones of Arch objects are now Arch objects themselves too.

15. Rotating and positioning the panels.

While the assembly workbench of FreeCAD is not ready yet, we need to position our pieces manually, either by manipulating their Placement property, or by using the Draft Move and Rotate tools, which are actually only visual ways to modify the Placement of objects.

Both Draft Rotate and Move tools make use of the Draft Snapping system. Different snapping positions (endpoints, midpoints, etc) are available, that can be switched on/off, allowing to perform very precise positionning and rotations.
