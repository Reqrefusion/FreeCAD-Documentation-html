Introdução

A biblioteca PySide é um *wrapper* em Python para o Qt, um *toolkit* de interface gráfica do usuário (GUI) multiplataforma. O FreeCAD utiliza o Qt como seu principal *toolkit* de GUI. O Qt, por si só, é mais do que apenas um *toolkit* de GUI; trata-se de uma coleção de bibliotecas C++ voltadas para diversas finalidades — é possível, por exemplo, realizar operações de rede utilizando componentes da biblioteca Qt —, tudo isso acessível em Python por meio do PySide. Qualquer interface gráfica que possa ser criada em C++ também pode ser criada e modificada em Python. Uma vantagem de utilizar Python é que as interfaces Qt podem ser desenvolvidas e testadas em tempo real, uma vez que não há necessidade de compilar os arquivos de código-fonte.

A maneira recomendada de importar o PySide (de qualquer versão) no FreeCAD é: 

from PySide import QtCore, QtGui, QtWidgets

Versões do Qt e PySide

  • A versão 1.0 do Qt foi lançada em meados da década de 1990
  • A versão 4.0 do Qt foi lançada em 2005, e a série 4.x foi oficialmente descontinuada em 2015
    • O wrapper Python para o Qt4.x chama-se PySide
  • A versão 5.0 do Qt foi lançada em 2012, e a série 5.x foi oficialmente descontinuada em 2020.
    • O wrapper Python para o Qt5.x chama-se PySide2
  • A versão 6.0 do Qt foi lançada em 2020; é a série de versão atual
    • O wrapper Python para o Qt6.x chama-se PySide6

FreeCAD e PySide

A ideia original por trás do FreeCAD era reunir o Cas.CADE (núcleo geométrico), o Qt (toolkit de GUI) e o Python para criar um programa de CAD paramétrico 3D gratuito com um mecanismo de script integrado. Isso ocorreu no início dos anos 2000 — ou seja, antes da existência do PySide; por isso, utilizou-se um wrapper diferente, o PyQt, durante a primeira década de existência do FreeCAD. O PySide surgiu para resolver questões de licenciamento relacionadas ao PyQt, e a migração do FreeCAD para o PySide foi realizada em 2013 (commit 1dc122dc9a).

Se você quiser saber qual versão do Qt sua instalação utiliza, a caixa de diálogo "Sobre" contém listas de versões que incluem o Qt.

Para mais informações, consulte:

  • Wikipedia:PySide
  • Diferenças entre PySide e PyQt

Ao instalar o FreeCAD, você obtém tanto o Qt quanto a versão correspondente do PySide como parte do pacote. Se você mesmo estiver realizando a compilação, deve verificar se versões compatíveis dessas duas bibliotecas estão instaladas para que o FreeCAD funcione corretamente. Naturalmente, o PySide só funcionará se o Qt estiver presente.

Compatibilidade entre múltiplas versões

A principal diferença entre o PySide e as bibliotecas subsequentes PySide2 e PySide6 reside nos namespaces. O PySide (Qt4) possui os namespaces principais QtGui e QtCore, enquanto o PySide2 (Qt5) e o PySide6 (Qt6) introduziram o namespace adicional QtWidgets, onde todos os widgets estão agora localizados — anteriormente, eles ficavam no namespace QtGui.

A abordagem do FreeCAD para lidar com as diferentes versões do Qt/PySide consiste em chamá-las todas de PySide — algo que, na verdade, deveria ser encarado como PySideX. Não importa qual versão do Qt/PySide esteja instalada; todas são importadas como PySide.

A shim handles the differences between the versions. This PySide shim is located in the Ext/ directory of an installation of FreeCAD compiled for Qt5/Qt6. 

/usr/share/freecad/Ext/PySide

This module just imports the necessary classes from PySide2/6, and places them in the PySide namespace. This approach was chosen for it's ability to provide backwards compatibility from a Qt4 perspective. 

PySide2.QtCore -> PySide.QtCore
PySide2.QtGui -> PySide.QtGui
PySide2.QtWidgets -> PySide.QtWidgets
PySide2.QtSvg -> PySide.QtSvg
PySide2.QtUiTools -> PySide.QtUiTools

For this reason the PySide2.QtWidgets classes are also placed in the PySide.QtGui namespace. 

PySide2.QtWidgets.QCheckBox -> PySide.QtGui.QCheckBox

But the current recommended way is to use the modern namespacing. 

from PySide import QtCore, QtGui, QtWidgets

my_check_box = QtWidgets.QCheckBox()

Documentation

There are some differences in the handling of widgets between the different versions. Programmers should be aware of these incompatibilities, and consult the official documentation if something doesn't work as expected on a given platform. Although rare, sometimes it may be required to make versioned calls through if-clauses.

The PySide documentation refers to the Python-style classes; however, since Qt is originally a C++ library, the same information should be available in the corresponding C++ reference.

  • Qt Modules available from PySide2/PySide6 (Qt5/Qt6).
  • All Qt classes by module in Qt5 for C++.
  • Qt Modules available from PySide (Qt4).
