O Python é uma linguagem de programação de código aberto amplamente utilizada, reconhecida por sua simplicidade, versatilidade e legibilidade. Ele é frequentemente incorporado a aplicativos como linguagem de script, e o FreeCAD não é exceção. Essa integração permite aos usuários automatizar tarefas, personalizar fluxos de trabalho e estender a funcionalidade do software muito além de sua interface gráfica.

O Python oferece diversas vantagens que o tornam particularmente adequado para os usuários do FreeCAD. A linguagem é acessível a iniciantes, com uma sintaxe clara e intuitiva que facilita o aprendizado — mesmo para pessoas sem experiência prévia em programação. Essa acessibilidade é especialmente valiosa na comunidade do FreeCAD, onde muitos usuários provêm de áreas diversas, como engenharia, arquitetura e design, sem possuir amplo conhecimento em programação.

Além disso, a ampla adoção do Python em outras aplicações — como o Blender para modelagem 3D, o Inkscape para gráficos vetoriais e o GRASS GIS para análise geoespacial — torna-o uma habilidade essencial para quem deseja ampliar suas capacidades de criação de scripts. Dominar o Python no FreeCAD não apenas aprimora sua habilidade de criar ferramentas e macros personalizadas, mas também proporciona competências transferíveis que podem ser aplicadas em diversas plataformas de software.

No FreeCAD, o uso de scripts em Python permite que você:

  • Automatize tarefas repetitivas para economizar tempo e reduzir erros.
  • Crie objetos paramétricos personalizados que se adaptam dinamicamente a alterações.
  • Desenvolva macros e ferramentas personalizadas, adequadas a fluxos de trabalho específicos.
  • Interaja com a API (Interface de Programação de Aplicações) do FreeCAD para acessar e manipular geometrias, cenas e elementos da interface do usuário de forma programática.

Ao utilizar o Python, os usuários do FreeCAD podem liberar todo o potencial do software, transformando-o em uma ferramenta poderosa e flexível, adaptada às suas necessidades específicas.

O FreeCAD inclui um console Python avançado, acessível através de Exibir → Painéis → Console Python. Essa ferramenta permite aos usuários realizar operações além da interface gráfica, como acessar recursos avançados, diagnosticar problemas de geometria e automatizar tarefas. Ela também registra comandos Python correspondentes às ações da interface gráfica, caso a opção Mostrar comandos de script no console Python esteja habilitada em Editar → Preferências → Python → Macro). Manter o console aberto permite acompanhar a geração do código Python enquanto você trabalha, oferecendo uma maneira intuitiva de aprender a linguagem ao mesmo tempo em que explora as capacidades do FreeCAD. Por fim, o FreeCAD também conta com um sistema de macros, que permite gravar ações para reproduzi-las posteriormente. Esse sistema também utiliza o console Python, registrando simplesmente tudo o que é executado nele.


Arquivo:FreeCAD Python Console.png

Neste capítulo, conheceremos a linguagem Python de forma geral. Se você tiver interesse em saber mais, a wiki de documentação do FreeCAD possui uma seção extensa dedicada à programação em Python.

Escrevendo código Python

No FreeCAD, você pode escrever código Python de duas maneiras principais: através do console Python (Exibir → Painéis → Console Python) ou usando o editor de macros (Macro → Macros → Criar). O console Python permite inserir comandos um de cada vez, os quais são executados imediatamente ao pressionar a tecla Enter, tornando-o ideal para testes rápidos ou exploração interativa. Já o editor de macros é utilizado para escrever e salvar scripts mais complexos, compostos por várias linhas de código. Essas macros podem ser executadas posteriormente em sua totalidade a partir da janela de macros, oferecendo uma maneira poderosa de automatizar tarefas repetitivas e ampliar as funcionalidades do FreeCAD. Neste capítulo, você poderá utilizar ambos os métodos, mas recomenda-se fortemente o uso do console Python, pois ele informará imediatamente sobre quaisquer erros cometidos durante a digitação.

Se esta é a sua primeira vez usando Python, considere ler esta breve introdução à programação em Python antes de prosseguir; isso tornará os conceitos básicos da linguagem mais claros.

Manipulando objetos do FreeCAD

Vamos começar criando um novo documento vazio: 

doc = FreeCAD.newDocument()

No console Python do FreeCAD, assim que você digita `FreeCAD.` (a palavra "FreeCAD" seguida de um ponto), uma janela de preenchimento automático é exibida. Esse recurso não apenas agiliza seu fluxo de trabalho ao sugerir comandos disponíveis, mas também ajuda você a descobrir novas funções e recursos no FreeCAD. Cada item da lista inclui uma dica de ferramenta (tooltip) que explica sua finalidade, facilitando a compreensão e a exploração das funcionalidades disponíveis. Essa ferramenta de preenchimento automático é especialmente útil tanto para iniciantes que estão aprendendo a criar scripts em Python quanto para usuários avançados que precisam navegar com eficiência pela extensa API do FreeCAD. Reserve um momento para explorar as opções na janela de preenchimento automático — você poderá descobrir comandos que simplificam seu fluxo de trabalho ou abrem novas possibilidades.

Arquivo:FreeCAD python novoDocumento.png

Digitar FreeCAD.newDocument() cria um novo documento vazio no FreeCAD, assim como clicar no botão Novo Documento na barra de ferramentas. Ao executar doc = FreeCAD.newDocument(), o objeto do novo documento é atribuído à variável doc, permitindo que você o manipule programaticamente. Usando doc, você pode adicionar objetos, alterar propriedades ou salvar o documento.

Em Python, o ponto (.) é usado para indicar que um elemento está contido em outro. Por exemplo, `newDocument` é uma função dentro do módulo `FreeCAD`; é por isso que escrevemos `FreeCAD.newDocument`. A janela de preenchimento automático que aparece exibe tudo o que está disponível no módulo `FreeCAD`. Se você digitasse um ponto após `newDocument` (sem adicionar os parênteses), ela mostraria tudo o que pertence à função `newDocument`. Isso ilustra como o Python organiza e acessa objetos e seus componentes. É importante notar que os parênteses são obrigatórios ao chamar uma função Python, pois sinalizam a execução da função.

Agora, vamos voltar ao nosso documento. Vamos ver o que podemos fazer com ele. Digite o seguinte e explore as opções disponíveis: 

doc.

No FreeCAD, as convenções de nomenclatura para comandos Python podem ajudar você a entender a finalidade deles:

  • Nomes que começam com letra maiúscula são tipicamente atributos, que armazenam valores ou dados, como propriedades de um objeto.
  • Nomes que começam com letra minúscula são geralmente funções (também chamadas de métodos), que realizam ações ou operações, como criar ou modificar objetos.
  • Nomes que começam com um sublinhado (_) destinam-se geralmente ao uso interno no módulo e, normalmente, podem ser ignorados.

Essa distinção ajuda você a navegar pela API do FreeCAD e a selecionar o comando adequado às suas necessidades. Por exemplo, você pode usar um método para adicionar um novo objeto a um documento. O método executa a ação de criar e adicionar o objeto, enquanto os atributos armazenam as propriedades do objeto. Compreender essa estrutura facilita a exploração das funcionalidades disponíveis, especialmente ao utilizar o recurso de preenchimento automático ou ao ler as dicas de ferramenta (tooltips). Vamos adicionar um cubo. 

box = doc.addObject("Part::Box", "myBox")

O comando `box = doc.addObject("Part::Box", "myBox")` adiciona um novo objeto de caixa 3D ao documento. Aqui está uma explicação simples:

  • doc.addObject: Isso instrui o FreeCAD a adicionar um novo objeto ao documento.
  • Part::Box: Isso especifica o tipo de objeto a ser criado; neste caso, um paralelepípedo (caixa) 3D.
  • myBox: Isso atribui um nome ao novo objeto, facilitando sua identificação e referência posterior.

O resultado desse comando é que uma caixa aparece no documento ativo, e a variável `box` armazena uma referência a ela para que você possa modificá-la ou interagir com ela posteriormente. Nossa caixa é adicionada à visualização em árvore, mas nada acontece na visualização 3D por enquanto, pois, ao trabalhar com Python, o documento nunca é recalculado automaticamente. Devemos fazer isso manualmente, sempre que necessário: 

doc.recompute()

Agora, nosso cubo apareceu na visualização 3D. Muitos dos botões da barra de ferramentas que adicionam objetos no FreeCAD, na verdade, realizam duas ações: adicionam o objeto e recalculam. Tente adicionar uma esfera usando o botão correspondente na bancada de trabalho Part; você verá as duas linhas de código Python sendo executadas em sequência.

Arquivo:FreeCAD python Sphere.png

Você pode obter uma lista de todos os tipos de objeto possíveis, como Part::Box: 

doc.supportedTypes()

Agora, vamos explorar o conteúdo da nossa caixa: 

box.

Você verá imediatamente algumas coisas muito interessantes, como: 

box.Height

Isso imprimirá a altura atual da nossa caixa. Agora, vamos tentar alterar isso: 

box.Height = 5

Se você selecionar a caixa com o mouse, verá que, no painel de propriedades, na aba Dados (Data), a propriedade Altura (Height) aparece com o novo valor. Todas as propriedades de um objeto do FreeCAD que aparecem nas abas Dados (Data) e Vista (View) também são diretamente acessíveis via Python, por meio de seus nomes, assim como fizemos com a propriedade Altura. As propriedades de dados são acessadas diretamente a partir do próprio objeto; por exemplo: 

box.Length

No FreeCAD, as propriedades visuais são gerenciadas por um ViewObject. Todo objeto do FreeCAD possui um ViewObject associado, que armazena informações sobre como o objeto é exibido na interface gráfica, como cor, transparência ou visibilidade. No entanto, o ViewObject só fica acessível quando o FreeCAD está em execução com sua interface gráfica. Se o FreeCAD for iniciado em um modo não gráfico — como a partir de um terminal com a opção de linha de comando `-c` ou quando utilizado como biblioteca Python em um script externo —, o ViewObject não estará disponível. Isso ocorre porque não há representação visual do objeto nesses modos, uma vez que a interface gráfica não é carregada.

Experimente o exemplo a seguir para acessar a cor da linha da nossa caixa: 

box.ViewObject.LineColor

Vetores e Posicionamentos

Os vetores são um conceito fundamental em qualquer aplicação 3D. Um vetor é essencialmente uma lista de três números (x, y e z) que descrevem um ponto, posição ou direção no espaço 3D. Os vetores são cruciais para definir geometria, transformações e interações no ambiente 3D. Eles servem como blocos de construção para operações como translações, rotações e dimensionamento.

No FreeCAD, vetores são amplamente utilizados para criar e manipular objetos. Eles possibilitam uma ampla gama de operações matemáticas, como adição, subtração, produtos vetoriais, produtos escalares e projeções. Essas operações permitem calcular distâncias, ângulos e direções, ou definir relações entre objetos no espaço.

Compreender os vetores e seu funcionamento é essencial para a criação de scripts e a personalização eficazes no FreeCAD. Por exemplo, vetores são utilizados para posicionar objetos, definir sua orientação ou até mesmo calcular trajetórias para operações complexas, como varreduras (*sweeps*) ou transições (*lofts*).

In FreeCAD, vectors are represented using the Vector class, which provides various methods and properties for performing operations and accessing their components. Mastering these capabilities will significantly enhance your ability to interact with FreeCAD’s 3D environment programmatically. In FreeCAD vectors work like this: 

myvec = FreeCAD.Vector(2, 0, 0)
print(myvec)
print(myvec.x)
print(myvec.y)
othervec = FreeCAD.Vector(0, 3, 0)
sumvec = myvec.add(othervec)

Here is a short breakdown of the above commands:

  • myvec = FreeCAD.Vector(2,0,0): Creates a vector myvec with X = 2, Y = 0, Z = 0.
  • print(myvec): Prints the vector myvec with its components (X, Y, Z).
  • print(myvec.x): Prints the X-component of myvec.
  • print(myvec.y): Prints the Y-component of myvec.
  • othervec = FreeCAD.Vector(0,3,0): Creates a second vector othervec with X = 0, Y = 3, Z = 0.
  • sumvec = myvec.add(othervec): Adds myvec and othervec to create a new vector sumvec containing the sum of their components.

Another common feature of FreeCAD objects is their Placement. As we saw in earlier chapters, each object has a Placement property, which contains the position (Base) and orientation (Rotation) of the object. These properties are easy to manipulate from Python, for example, to move our object: 

print(box.Placement)
print(box.Placement.Base)
box.Placement.Base = sumvec
otherpla = FreeCAD.Placement()
otherpla.Base = FreeCAD.Vector(5, 5, 0)
box.Placement = otherpla

Here is a short breakdown of the above commands:

  • print(box.Placement): Prints the placement of the box, which includes its position, rotation, and orientation in 3D space.
  • print(box.Placement.Base): Prints the position (Base) of the box, which is a vector representing its location in 3D space.
  • box.Placement.Base = sumvec: Sets the base position (location) of the box to the vector sumvec, effectively moving the box to this new position.
  • otherpla = FreeCAD.Placement(): Creates a new placement object named otherpla.
  • otherpla.Base = FreeCAD.Vector(5,5,0): Sets the base position of otherpla to a vector at coordinates (5, 5, 0).
  • box.Placement = otherpla: Applies otherpla to the box, updating its placement to the new position and orientation defined by otherpla.
