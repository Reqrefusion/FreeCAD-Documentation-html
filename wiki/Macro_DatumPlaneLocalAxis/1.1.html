Description

The Datum-Plane Local Axis macro adds local coordinate axes to selected datum planes in the 3D View. It creates one grouped set of Draft line objects for each selected datum plane: red for the local X axis, green for the local Y axis and blue for the local Z axis.


The axes follow the selected plane placement by expression, so they remain useful while checking how a datum plane is oriented inside a body or link hierarchy.

Usage

  1. Select one or more datum planes in the 3D View.
  2. Run the macro.
  3. Inspect the created Datum_Plane_Axis groups and the colored axis lines.
  4. To remove the created axis groups, run the macro again with no selection.

Notes

  • The macro only adds visual helper geometry; it does not change the selected datum plane.
  • The axis length is based on the selected plane size.
  • Selections that do not resolve to a PartDesign::Plane are ignored.
