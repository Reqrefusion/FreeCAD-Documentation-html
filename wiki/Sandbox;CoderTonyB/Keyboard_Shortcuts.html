Introduction

Reference for FreeCAD default keyboard shortcuts: how multi-key shortcuts work, where to view and change them, and stock defaults by category (same categories as the Keyboard tab in Customize).

Covers stock FreeCAD introduced in 1.1 (including 1.1.1): core commands and built-in workbenches. Does not cover user macros or third-party addons (SheetMetal, Cables, Assembly3, EM, and similar).

Shortcuts only run for active commands (standard menu, active workbench, or a visible toolbar). If you customized keys, or a workbench is not loaded, what you see in the UI wins. Check with Tools → Customize... → Keyboard.

See also Interface Customization and Std DlgCustomize.

Where to view and edit shortcuts

On FreeCAD introduced in 1.1 (including 1.1.1):

  1. Select Tools → Customize....
  2. Open the Keyboard tab.
  3. Pick a Category (File, Edit, View, Sketcher, ...).
  4. The list shows Icon, Command, Shortcut (current), and Default.
  5. Select a command, click New shortcut, press the key or sequence, then Assign.

Later FreeCAD builds that use calendar version numbers may move this UI under Preferences (Preferences Editor). That is not FreeCAD 1.1.1.

Tips

  • Search by command name or by shortcut text. Multi-key sequences: comma and space (g, l). Single letters: parentheses ((c)).
  • Multi-key sequence delay is the wait between keys in a sequence (often 300 ms).
  • Reset restores one command; Reset All restores all defaults.
  • If a shortcut does nothing, switch to the workbench that owns the command or show its toolbar.
  • Some bindings are easy to miss, such as workbench switching (W then 1...9 after you order workbenches) and draw-style sequences.

How multi-key shortcuts work

FreeCAD shortcuts use Qt. Two common forms:

  • Modifier chord: hold modifiers and press a key, for example Ctrl+S (Save). Same idea as most desktop apps and SolidWorks file/edit chords.
  • Key sequence (multi-key): press and release one key, then press the next before the multi-key delay ends, for example V then F (Fit all). The UI usually shows this as V, F.

A sequence is not a chord. Do not hold V and F together: press V, release, then F.

Limits

  • At most four key presses in one sequence.
  • If you start a sequence and abandon it, the next keys may be ignored until the sequence times out or fails. Press the first key again, or wait for the timeout.
  • Letter-only sequences are mostly workbench tools, so they stay out of the way of global Ctrl chords.

Prefix design (how to remember them)

Default sequences often use a first key as a group label. That is only a naming habit in the defaults, not a separate mode:

Prefix Typical meaning Examples
V View V F fit all; V S fit selection; V 1...7 draw styles
G Sketcher geometry G L line; G C circle; G R rectangle
K Sketcher constraints (less common ones) K D distance; K A angle
Z Sketcher tools / helpers Z T offset; Z M move
T Tree view options (global) T 1... sync options; T G go to selection
P CAM / Path tools P J job; P P post process
Single letters Frequent sketcher constraints T tangent; H horizontal; E equal

Second keys are often mnemonic (L line, C circle), but not always. Some letters are leftovers after better ones were already taken.

From SolidWorks: sketch tools are often one key while a sketch is active. FreeCAD Sketcher more often uses G... for geometry and keeps many constraints as single keys.

Notes

  • Stock FreeCAD introduced in 1.1 defaults only: no user macros, no third-party addons.
  • If your install differs, use Tools → Customize... → Keyboard.
  • Draft and similar tools also have in-command keys in the task panel while a tool runs. Those are not the same as global accelerators; see the command page and Draft Preferences.
  • Mouse navigation bindings are separate: Mouse navigation.
  • PartDesign often has no defaults; assign shortcuts if you want them.
