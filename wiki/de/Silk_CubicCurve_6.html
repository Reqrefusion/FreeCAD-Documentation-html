Beschreibung

Der Befehl Silk Silk_CubicCurve_6 erstellt aus einem ControlPoly6 eine CubicCurve_6.

Ein CubicCurve_6-Objekt, das eine kubische Kurve anzeigt.

It is mostly intended for blending existing Bézier curves or curve segments.

2 selected adjacent curve segments → Blend polygon → Resulting blend curve

Anwendung

  1. Ein Silk_ControlPoly6 auswählen.
  2. Es gibt mehrere Möglichkeiten, den Befehl aufzurufen:
    • Die Schaltfläche Silk_CubicCurve_6 drücken.
    • Den Menüeintrag Silk → Silk_CubicCurve_6 auswählen.
  3. Ein CubicCurve_6-Objekt wird erstellt.

Notes

  • A 6-control-point cubic NURBS curve. G2 continuous throughout; G3 continuous throughout except at two points along the curve, where it is G2 only.
  • The practical use of this curve is to preview blends on curves before doing the full work of blending surfaces.
  • This is currently an endpoint in the Silk design workflow.
  • The input ControlPoly6 can be used to build grids and surfaces; alternatively, this curve can be used with the rest of FreeCAD — extruded, revolved, etc. — if curve design is all that is needed from Silk.

Eigenschaften

Siehe auch: Eigenschaften-Ansicht.

Ein CubicCurve_6-Objekt wird von einem Part-Formelement, oder genauer einem Part::FeaturePython-Objekt abgeleitet und übernimmt alle seine Eigenschaften. Es besitzt auch die folgenden zusätzlichen Eigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftPoly (Link): Kontrollpolygon.
  • Daten-Eigenschaftreverse (Bool): Der Standardwert ist False. Kehrt die Parameterrichtung um.

C3 - Identifiers

  • Daten-EigenschaftinternalName (String): Der dauerhafte interne FreeCAD-Name dieses Objekts.
  • Daten-Eigenschaftobject_type (String): Standardeinstellung CubicCurve_6. Die Klasse des Arbeitsbereichs, die zum Erstellen dieses Objekts verwendet wird.
  • Daten-Eigenschaftobject_version (String): Die Version der Klasse dieses Objekts.
