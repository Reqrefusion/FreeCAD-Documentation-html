Das Makro Tabellenkalkulations-Abhängigkeits-Prüfer zeigt für eine Auswahl von Tabellenzellen alle Abhängigkeiten zwischen Tabellenzellen und sogar zwischen einer Zelle und Objekteigenschaften an. Alle Informationen werden in Form einer aufklappbaren Baumstruktur dargestellt, die den Zellennamen, den Alias, die Formel und den Wert der Zelle enthält. Es werden rekursiv angezeigt:

  • Zellen, die andere Zellen verwenden
  • Zellen, die von anderen Zellen verwendet werden

The macro also helps you find and diagnose errors in your document. Run it on the whole document and check only Errors: you see at once every cell, property or constraint in error, the one where the error starts (bold red), and the value that causes it (orange), for example a cell containing a text where a number is expected. When the cause is unknown (division by zero, pad of length zero...), the values used by the faulty line are shown in orange italic, to check. See Error detection.

Das Makro ist mehrsprachig und unterstützt derzeit Englisch und Französisch. Es wird die Sprache verwendet, die in den FreeCAD-Einstellungen ausgewählt ist.

Als Ergänzung zu diesem Makro möchten man vielleicht auch einen Blick auf Folgendes werfen: Makro Skizzen-Beschränkungen aus Kalkulationstabellen.

Anwendungsbeispiele

  • Sich einen Überblick über die Abhängigkeiten zwischen Zellen sowie zwischen Zellen und Objekteigenschaften verschaffen.
  • Sich die Auswirkungen des Löschens einer Zelle ansehen.
  • Prüfen, ob eine Zelle ungenutzt ist.
  • Überprüfen und Bearbeiten von Ausdrücken.
  • Aliase oder Beschriftungen zuweisen.
  • Überprüfen und Bearbeiten von Beschriftungen.
  • In der Skizze eine Randbedingung suchen, die mit einer Tabellenzelle verknüpft ist.
  • …

Anwendung

In einer Tabelle eine oder mehrere Zellen auswählen und dann das Makro ausführen.

Das Symbol für die Aktualisierung führt eine Neuberechnung der Analyse durch, beispielsweise nachdem eine Zelle bearbeitet oder die Auswahl geändert wurde.

Mit der Schaltfläche Erweitern/Reduzieren kann die gesamte Baumstruktur ein- oder ausgeblendet werden. Dies kann auch für einzelne Zweige getan werden, indem auf die Symbole ▶ oder ▼ geklickt wird.

Die Informationen auswählen, die angezeigt werden sollen:

  • Uses / Used by: the two branches of each line.
  • Cells, Constraints, Others: the kinds of lines shown.
  • Errors: when checked, the lines in error are always shown, with what they use. When unchecked, it does not prevent the lines in error from being shown. With Errors alone, you only see the errors and their causes.
  • Columns: Label/alias, Expression, Result and constraint Type can be shown or hidden.

Error detection in the FreeCAD document

  • Red: the cell or property is in error (cell error, expression that fails, value refused by FreeCAD, invalid object, sketch constraint refused by the solver).
  • Bold red: the error starts here; a red line without bold gets its error from another line (shown in its tooltip).
  • Orange: next to a line in error, the value that causes it, e.g. a cell containing the text a where a number is expected. The cell itself is not in error, so it is orange only next to that line.
  • Orange italic: next to a line in error whose cause is unknown (division by zero, pad of length zero...), the values it uses, to check.

The tooltip of each line explains its state.

In the tree

Mit einem einfachen Klick können die Bezeichnungen oder Aliase sowie der Inhalt (Ausdruck) direkt geändert werden.

Ein Doppelklick auf eine Randbedingungszeile öffnet die Skizze, die diese Randbedingung enthält, und wählt sie aus, sodass sie hervorgehoben wird.
