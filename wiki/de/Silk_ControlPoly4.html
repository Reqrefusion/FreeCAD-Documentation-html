Beschreibung

Der Befehl Silk ControlPoly4 erstellt ein 4-Punkt-Kontrollpolygon, ein ControlPoly4-Objekt, aus einer oder zwei Skizzen, kann aber auch Linienzüge aus einigen anderen Silk-Objekten extrahieren. Er ist dazu gedacht, eine kubische Bezier-Kurve zu steuern (und vier von ihnen steuern eine kubische Bezier-Oberfläche).

Ein 3D-Kontrollpolygon aus zwei Knotenpunktskizzen aufgebaut

Dieser Befehl ist der zweite von drei Schritten zum Erstellen einer parametrischen kubischen Bezier-Kurve:

  1. Eine oder zwei Skizzen erstellen.
  2. Ein Silk ControlPoly4-Kontrollpolygon erstellen.
  3. Eine Silk CubicCurve_4-Kurve erstellen.

Skizze → Kontrollpolygon → Resultierende Bezier-Kurve

Anwendung

  1. Dieses Werkzeug erstellt unterschiedliche Objekte mit individuellen Eigenschaften und Berechnungsmodi abhängig von den ausgewählten Eingabeelementen:
    • 3L-Modus: Eine Skizze in der Baumansicht oder in der 3D-Ansicht auswählen, die einen Linienzug aus 3 geraden Linien enthält.
    • 2N-Modus: Zwei Knotenpunktskizzen in der Baumansicht oder in der 3D-Ansicht auswählen, die jeweils einen Kreis und eine gerade Linie, die im Kreismittelpunkt beginnt, enthält.
    • FirstElement-Modus: Eine Skizze in der Baumansicht oder in der 3D-Ansicht auswählen, die eine beliebige Kombination unterschiedlicher Linien enthält. Nur der zuerst erkannte Bogen in der Skizze wird berücksichtigt bzw. die zuerst erkannte gerade Linie, wenn in der Skizze kein Bogen vorhanden ist.
    • GridEdge-Modus: Einen Punkt oder eine Linie auf einer Kante eines ControlGrid44-Gitters in der Baumansicht auswählen.
    • 2X4P-Modus: Zwei ControlPoly4-Linienzüge in der Baumansicht oder in der 3D-Ansicht auswählen.
    • 2P-Modus: Zwei Point_onCurve-Objekte in der Baumansicht oder in der 3D-Ansicht auswählen.
  2. Es gibt mehrere Möglichkeiten, den Befehl aufzurufen:
    • Die Schaltfläche ControlPoly4 drücken.
    • Den Menüeintrag Silk → ControlPoly4 auswählen.
  3. Dem Modus entsprechend wird eins der folgenden Objekte erstellt:
    • ControlPoly4_3L
    • ControlPoly4_2N
    • ControlPoly4_FirstElement
    • ControlPoly4_GridEdge
    • ControlPoly4_2X4P
    • ControlPoly4_2P
  4. Wahlweise Parameter in der Eigenschaften-Ansicht einstellen.

Hinweise

  • 4-Punkt-Kontrollpolygone sind als Eingabe für einige andere Silk-Objekte erforderlich:
    • 1 von diesen wird zum Erstellen einer CubicCurve_4-Kurve verwendet.
    • 1 von diesen in Verbindung mit 2 Point_onCurve-Punkten wird zum Erstellen eines ControlPoly4_segment-Linienzuges verwendet.
    • 4 von diesen werden zum Erstellen eines ControlGrid44-Gitters verwendet.
    • 3 von diesen werden zum Erstellen eines ControlGrid44_Rotate-Gitters verwendet.
    • 2 von diesen control polygons in Verbindung mit 2 ControlPoly6-Linienzügen objects werden zum Erstellen eines ControlGrid64-Gitters verwendet.
  • Das Bearbeiten der zugrundeliegenden Skizze aktualisiert automatisch den Linienzug. Kurven und Oberflächen, die an diesem Linienzug befestigt sind, werden auch aktualisiert. In den Skizzen sollte sichergestellt sein, dass die Ansicht-EigenschaftHide dependent auf false eingestellt ist. Dies ergibt eine Aktualisierung der der Linienzüge (sowie Kurven und Oberflächen) in Echtzeit, während eine Skizze bearbeitet wird.
  • Da Linienzüge sowohl zum Erstellen von Oberflächen als auch zum Erstellen von Kurven eingesetzt werden und die Oberflächen unser eigentliches Ziel sind, wird das Erstellen von Linienzügen als unabhängiger Schritt beibehalten. Nach dem Erstellen einer Kurve bzw. Oberfläche, kann die Skizze bearbeitet werden, um die Änderungen an der Kurve bzw. der Oberfläche zu beobachten.
  • Knotenpunktskizzen sind dazu gedacht, auf unterschiedlichen Ebenen positioniert zu werden, so dass die sich ergebenden Linienzüge, Kurven und Kanten von Oberflächen vollständig 3D sind. Sie eignen sich bestens zum Verbinden der Endpunkte von Linienskizzen, die sich auf unterschiedlichen Ebenen befinden. Knotenpunktskizzen werden üblicherweise mit dem Kreis im Ursprung erstellt und die Skizze mit FreeCADs Mapping-Tools (zu finden auf dem Reiter Daten in der Eigenschaften-Ansicht) an einem neuen Ort mit neuer Ausrichtung abgelegt. Auf diese Weise wird der Kreis nie bearbeitet und der freie Endpunkt der Linie kann beliebig eingestellt werden.
  • Ein Linienzug, der in einem Gitter bzw. einer Oberfläche verwendet wird, kann mit weiteren Skizzen verknüpft werden, so dass die Arbeit, die in der Erstellung des Gitters bzw. der Oberfläche steckt, nicht erneut verrichtet werden muss — einfach die Verknüpfung mit der Skizze austauschen und neu berechnen (Verknüpfte Skizzen befinden sich ebenfalls im Reiter Daten der Eigenschaften-Ansicht).

Eigenschaften

Siehe auch: Eigenschaften-Ansicht.

Alle ControlPoly4-Objekte werden von einem Part-Formelement, oder genauer einem Part::FeaturePython-Objekt abgeleitet und übernehmen alle seine Eigenschaften. Sie besitzen auch die folgenden gemeinsamen zusätzlichen Eigenschaften:

Daten

C2 - Outputs

  • Daten-EigenschaftLegs (Part::PropertyGeometryList): Kontrollabschnitte.
  • Daten-EigenschaftPoles (VectorList): Pole.

C3 - Identifiers

  • Daten-EigenschaftinternalName (String): Der unveränderliche interne FreeCAD-Name dieses Objekts.
  • Daten-Eigenschaftobject_version (String): Die Version der Klasse dieses Objekts.


Ein ControlPoly4_3L-Objekt besitzt außerdem die folgenden individuellen zusätzlichen Eigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftSketch (Link): Referenzskizze.
  • Daten-EigenschaftWeights (FloatList): Gewichte.
  • Daten-Eigenschaftreverse (Bool): Standardeinstellung False. Kehrt die Parameterrichtung um.
  • Daten-Eigenschafttolerance (Float): Standardwert 1e-06. Toleranz für Punkt-zu-Punkt-Verbindungen der 3 Linien.

C3 - Identifiers

  • Daten-Eigenschaftobject_type (String): Standardeinstellung ControlPoly4_3L. Die Klasse des Arbeitsbereichs, die zum Erstellen dieses Objekts verwendet wird.


Ein ControlPoly4_2N-Objekt besitzt außerdem die folgenden individuellen zusätzlichen Eigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftSketch0 (Link): Referenzskizze.
  • Daten-EigenschaftSketch1 (Link): Referenzskizze.
  • Daten-EigenschaftWeights (FloatList): Gewichte.
  • Daten-Eigenschaftreverse (Bool): Standardeinstellung False. Kehrt die Parameterrichtung um.
  • Daten-Eigenschafttolerance (Float): Standardwert 1e-06. Toleranz für die Punkt-zu-Punkt-Verbindung von Kreis zu Linie in jedem Knotenpunkt.

C3 - Identifiers

  • Daten-Eigenschaftobject_type (String): Standardeinstellung ControlPoly4_2N. Die Klasse des Arbeitsbereichs, die zum Erstellen dieses Objekts verwendet wird.

Ein ControlPoly4_2P-Objekt besitzt außerdem die folgenden individuellen zusätzlichen Eigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftPoint0 (Link): Erstes pointOnCurve-Referenzobjekt.
  • Daten-EigenschaftPoint1 (Link): Zweites pointOnCurve-Referenzobjekt.
  • Daten-EigenschaftScale0 (Float): Skaliert die Starttangente (die Summe mit Scale1 sollte kleiner oder gleich 3.0 oder der Gesamtlänge sein).
  • Daten-EigenschaftScale0_abs (Bool): Skalierungsart der Starttangente (False = relativ, True = absolut).
  • Daten-EigenschaftScale1 (Float): Skaliert die Endtangente (die Summe mit Scale0 sollte kleiner oder gleich 3.0 oder der Gesamtlänge sein).
  • Daten-EigenschaftScale1_abs (Bool): Skalierungsart der Endtangente (False = relativ, True = absolut).
  • Daten-EigenschaftWeights (FloatList): Gewichte.
  • Daten-Eigenschaftreverse (Bool): Standardeinstellung False. Kehrt die Parameterrichtung um.
  • Daten-Eigenschafttolerance (Float): Wird derzeit nicht verwendet.

C3 - Identifiers

  • Daten-Eigenschaftobject_type (String): Standardeinstellung ControlPoly4_2P. Die Klasse des Arbeitsbereichs, die zum Erstellen dieses Objekts verwendet wird.
