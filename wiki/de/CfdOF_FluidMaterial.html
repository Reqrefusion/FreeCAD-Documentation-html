Beschreibung

The CfdOF FluidMaterial command opens a task panel to edit a Fluid Properties‏‎ object. This object holds the properties of a fluid used in a simulation. These can be entered manually, or selected from a fluid library. One Fluid Properties‏‎ object is automatically added when an Analysis container is created. In case of a multi-phase Physics Model, additional fluids can be defined by adding more Fluid Properties‏‎ objects.

Anwendung

Zusätzliches Fluid-Datenobjekt erstellen (mehrphasig)

  1. If required: activate the correct Analysis container by double-clicking it in the Tree View.
  2. Ensure the DatenPhase property of the Physics Model in the container is set to FreeSurface.
  3. There are several ways to invoke the command:
    • Press the Add fluid properties‏‎ button.
    • Select the CfdOF → Add fluid properties‏‎ option from the menu.
  4. A FluidProperties data object is added to the container.
  5. The task panel opens. See Options for more information.
  6. Press the OK button to confirm and finish the command.

Fluid-Datenobjekt bearbeiten

  1. Do one of the following:
    • Only for single phase: Follow steps 1 and 3 described above.
    • For single phase and multi-phase: Double-click a FluidProperties data object in the Tree View.
  2. The task panel opens. See Options for more information.
  3. Press the OK button to confirm and finish the command.

Optionen

Die im Physikmodell ausgewählten Optionen bestimmen, welche Eingaben im Aufgaben-Fenster Fluideigenschaften erforderlich sind. Die folgende Abbildung zeigt das Aufgaben-Fenster Fluideigenschaften für eine nicht-isotherme Simulation.

Materialname

In das Eingabefeld kann der Name der Flüssigkeit eingegeben werden. Eine aus der Bibliothek Vordefinierte Flüssigkeiten ausgewählte Flüssigkeit wird automatisch in dieses Eingabefeld übernommen, kann jedoch überschrieben werden. Der eingegebene Name erscheint in der Baumstruktur des Analyse-Containers.

Eigenschaften von Flüssigkeiten

  • Isotherme Fluide
Die physikalischen Eigenschaften eines isothermen Fluids ändern sich während der Simulation nicht, weshalb nur Daten für einen einzigen Temperaturpunkt benötigt werden.
  • Eingabefeld Cp.
Spezifische Wärmekapazität bei konstantem Druck.
Dies ist erforderlich, wenn nicht-isotherme, einphasige Flüssigkeiten im stationären Zustand simuliert werden. Cp ist die Energiemenge, die benötigt wird, um die Temperatur von 1 kg Flüssigkeit in einem isobaren Prozess um ein Kelvin zu erhöhen. Da es sich um einen stationären Zustand handelt, ist nur ein einziger Datenpunkt unter den Bedingungen erforderlich, unter denen die Simulation stattfindet.
  • Eingabefeld Density (Dichte).
Masse pro Volumeneinheit eines Materials/einer Flüssigkeit.
  • Eingabefeld DynamicViscosity.
Ein Maß für den Widerstand einer Flüssigkeit gegen Verformung bei einer bestimmten Geschwindigkeit, das manchmal auch als absolute Viskosität bezeichnet wird. Die dynamische Viskosität geteilt durch die Dichte der Flüssigkeit ergibt die kinematische Viskosität.
  • Nicht-isotherm
  • Optionally select Compressible.
When a non-isothermal simulation is selected, in the Physics Model, the Compressible checkbox becomes visible. If unchecked, incompressible fluids can be simulated within a compressible solver, if the compressibility plays no significant role.
  • Eingabefeld Molar Mass (Molmasse).
Die Molmasse oder das Molekulargewicht der Flüssigkeit.
  • Polynomials
Temperature-polynomials are used when simulating non-isothermal, incompressible fluids. The simulation occurs over a temperature range and the fluid property data must be determined over the range.
The Polynomial provides a means of inputting coefficients for a temperature-polynomial, in the format:
Temperature-polynomial = a + b × T + c × T2 + d × T 3
where a, b, c and d are coefficients and T is Temperature. The polynomials will accept up to 8 coefficients. Enter each coefficient, separated by a space, for the temperature-polynomial, starting with the constant followed by the higher powers.
e.g. Cp = 9850.69 -48.6714xT +0.13736T2 -0.000127063xT3
would be entered as:
9850.69 -48.6714 0.13736 -0.000127063
  • Eingabefeld CpPolynomial.
Temperaturpolynom für die spezifische Wärmekapazität bei konstantem Druck.
  • Eingabefeld DensityPolynomial.
Temperaturpolynom für die Dichte.
  • Eingabefeld DynamicViscosityPolynomial.
Temperaturpolynom für die dynamische Viskosität.
  • Eingabefeld ThermalConductivityPolynomial.
Temperaturpolynom für die Wärmeleitfähigkeit.
  • Sutherland
The Sutherland formula is used when simulating non-isothermal, compressible fluids. It is used for approximating the viscosity of gases, at different temperatures. It is used for single-component gases at low pressure, however can also be used for Air, as the main components of Nitrogen and Oxygen have very similar properties.
  • Eingabefeld SutherlandRefTemperature.
Die Temperatur, T0, bei der die SutherlandRefViscosity bestimmt wurde.
  • Eingabefeld SutherlandRefViscosity.
Die empirische Referenzviskosität, μ0, bestimmt bei der Sutherland-Referenztemperatur.
  • Eingabefeld SutherlandTemperature.
S, manchmal auch als Sutherland-Konstante bezeichnet, ist eine effektive Temperatur, die für das Gas charakteristisch ist.

Vordefinierte Flüssigkeitsbibliothek

  • Drop-down box
The fluid properties for a number of components exist within the Predefined fluid library. Selecting a fluid from the drop-down, will automatically populate the Fluid properties input boxes above
  • Referenzdaten
Unterhalb des Ausklapp-Menüs werden die Referenzbedingungen für die ausgewählte Flüssigkeit angegeben. Beispielsweise lautet die Angabe für inkompressibles Meerwasser: „Meerwasser (30 %) 20 Grad Celsius 1 atm“.

Hinweise

  • Die im Aufgaben-Fenster Fluideigenschaften verfügbaren Eingabefelder und Optionen hängen von den im Aufgabenbereich Physikmodell ausgewählten Optionen ab. Um den Arbeitsablauf zu vereinfachen, empfehlen wir, zunächst den Aufgabenbereich Physikmodell auszufüllen, bevor dieses Aufgaben-Fenster bearbeitet wird.
