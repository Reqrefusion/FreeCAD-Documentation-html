Beschreibung

Der Befehl Silk ControlGrid44_Rotate erstellt ein dreiseitiges 4x4-Kontrollgitter, ein ControlGrid44-Objekt aus 3 miteinander verbundenen 4-Punkt--Polygonen.

Ein Rotationsgitter, das drei Polygonkanten zu einem Punkt zusammenführt

Ein Ring aus 3 miteinander verbundenen 4-Punkt-Polygonen → Resultierendes dreiseitiges 4x4-Kontrollgitter

Anwendung

  1. 3 verbundene ControlPoly4-Kanten in der 3D-Ansicht auswählen.
  2. Es gibt mehrere Möglichkeiten, den Befehl aufzurufen:
    • Die Schaltfläche ControlGrid44_Rotate drücken.
    • Den Menüeintrag Silk → ControlGrid44_Rotate auswählen.
  3. Ein ControlGrid44_3_Rotate-Objekt wird erstellt.

Notes

  • This tool produces a "triangle" surface that "rotates" from the first edge selected to the third, following along the second edge. Order is "left, bottom, right," with the rotational pivot at the "top" corner.
  • Typical use is to merge a set of surfaces to a point (such as closing a tube). Also used to interface with spheres and ellipsoids.
  • This is a degenerate grid (one edge collapsed to a point) that results in a "revolve"-like surface. Produces true spheres from arc polys, true ellipsoids from ellipse-arc polys, but also accepts non-arc polys.
  • Surface tangency across multiple grids can be achieved automatically from well-prepared arcs of circles and ellipses, but using general curves as input does not have an easily predictable outcome, and additional blending may be required.
  • Although degenerate, this grid is the correct way to interface with spheres, since it does not introduce additional collapsed edges — in this particular case, the NURBS degeneracy is not a flaw at all, but a standard CAD construct.
  • A four-sided version able to create true tori (and sphere strips) is planned, but not yet ready.

Eigenschaften

Siehe auch: Eigenschaften-Ansicht.

Ein ControlGrid44_3_Rotate-Objekt wird von einem Part-Formelement, oder genauer einem Part::FeaturePython-Objekt abgeleitet und übernimmt alle seine Eigenschaften. Es besitzt auch die folgenden zusätzlichen Eigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftPoly0 (Link): Erstes Kontrollpolygon.
  • Daten-EigenschaftPoly1 (Link): Zweites Kontrollpolygon.
  • Daten-EigenschaftPoly2 (Link): Drittes Kontrollpolygon.
  • Daten-Eigenschaftreverse (Bool): Der Standardwert ist False. Kehrt die Parameterrichtung um.
  • Daten-Eigenschafttolerance (Float): Der Standardwert ist 1e-06. Toleranz für Punkt-zu-Punkt-Verbindungen an den drei Ecken.

C2 - Outputs

  • Daten-EigenschaftLegs (Part::PropertyGeometryList): Kontrollsegmente.
  • Daten-EigenschaftPoles (VectorList): Pole.
  • Daten-EigenschaftWeights (FloatList): Gewichte.

C3 - Identifiers

  • Daten-EigenschaftinternalName (String): Der dauerhafte interne FreeCAD-Name dieses Objekts.
  • Daten-Eigenschaftobject_type (String): Standardeinstellung ControlGrid44_3_Rotate. Die Klasse des Arbeitsbereichs, die zum Erstellen dieses Objekts verwendet wird.
  • Daten-Eigenschaftobject_version (String): Die Version der Klasse dieses Objekts.
