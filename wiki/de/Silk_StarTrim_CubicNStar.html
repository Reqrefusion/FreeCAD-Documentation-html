Beschreibung

Der Befehl Silk StarTrim_CubicNStar erstellt eine Eck-Übergangsflächen-Kragen, ein StarTrim_CubicNStar-Objekt, aus einer Eck-Übergangsfläche.

Eine Eck-Übergangsfläche → Resultierender Eck-Übergangsflächen-Kragen

Anwendung

  1. Eine Eck-Übergangsfläche auswählen
  2. Es gibt mehrere Möglichkeiten, den Befehl aufzurufen:
    • Die Schaltfläche Silk_StarTrim_CubicNStar drücken.
    • Den Menüeintrag Silk → Silk_StarTrim_CubicNStar auswählen.
  3. Ein Eck-Übergangsflächen-Kragen, ein StarTrim_CubicNStar-Objekt, wird erstellt.

Hinweise

  • Wenn es erforderlich wird, Wellen einer schlechten Eckgeometrie in einer Vieleck-Übergangsfläche zu glätten, kann dieses Werkzeug deren mittleren Bereich ausschneiden und hinterlässt einen Kragen, der mit einer normalen Flächenfüllung geschlossen werden kann.
(- Welches Werkzeug könnte verwendet werden und wie erhält man die Randkurven? -)

Eigenschaften

Siehe auch: Eigenschaften-Ansicht.

Ein Eck-Übergangsflächen-Kragen, ein StarTrim_CubicNStar-Objekt, wird von einem Part-Formelement, oder genauer einem Part::FeaturePython-Objekt abgeleitet und übernimmt alle seine Eigenschaften. Es besitzt auch die folgenden zusätzlichen Eigenschaften:

Daten

StarTrim_CubicNStar

  • Daten-EigenschaftCubicNStar (Link): Stern-Basisoberfläche
  • Daten-EigenschaftNSurf_center (Part::PropertyGeometryList): N kubische Oberflächen Surfaces, mittlerer Abschnitt.
  • Daten-EigenschaftNSurf_lag (Part::PropertyGeometryList): N kubische Oberflächen, nachfolgender Kantenabschnitt.
  • Daten-EigenschaftNSurf_lead (Part::PropertyGeometryList): N kubische Oberflächen, führender Kantenabschnitt.
  • Daten-EigenschaftNSurf_main (Part::PropertyGeometryList): N kubische Oberflächen, Haupt-Eckabschnitt.
