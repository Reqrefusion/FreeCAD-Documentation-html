Einleitung

SVG ist die Abkürzung für Scalable Vector Graphics (Skalierbare Vektor-Grafik), ein vektorbasiertes Bildformat für zweidimensionale Grafiken.

Vektorbasierte Formate wie SVG sind in technischen Zeichenprogrammen wie FreeCAD sehr nützlich, da ein SVG-Bild auf jede beliebige Größe skaliert werden kann, ohne seine Form oder Menge an Details zu verlieren. Das SVG kann auf jede erforderliche Auflösung skaliert und für den Druck in Bitmap-Formate wie PNG oder JPEG umgewandelt werden.

Das SVG-Bild wird in einer Sprache vom Typ XML beschrieben, was bedeutet, dass es mit einem einfachen Texteditor geöffnet und bearbeitet werden kann, um Änderungen vorzunehmen. Aufgrund ihres textbasierten Charakters kann die Datei auch leicht durchsucht, indiziert und komprimiert werden. Die SVG-Auszeichnungssprache ist ein offener Standard, der seit 1999 vom World Wide Web Consortium (W3C) entwickelt wurde. Das bedeutet, dass eine SVG-Datei von konformen Betrachtern und Zeichenprogrammen auf die gleiche Weise gelesen und interpretiert werden sollte.

Für weitere Informationen zum SVG-Format siehe: Scalable Vector Graphics.

SVG in FreeCAD

FreeCAD ist in erster Linie eine Anwendung zum 3D-Modellieren, und hat daher nicht sehr viele 2D-Zeichenwerkzeuge. Andererseits ist FreeCAD rauf SVG-Dateien angewiesen:

  • Symbole (Icons) in der grafischen Benutzerschnittstelle, die Werkzeuge im Menü und in den Symbolleisten repräsentieren oder Objekte und Formelemente in der Baumansicht.
  • Vorlagen (Templates) für den Arbeitsbereich TechDraw, die Papierblätter repräsentieren, die das Format einer Zeichnung bestimmen und maßstabsgerechtes Drucken ermöglichen. Sie können auch Rahmen und ein Schriftfeld bereitstellen.
  • Zeichnungselemente (Symbols), TechDraw Ansichten, die jeweils eine einzelne SVG-Datei einbetten, um häufig verwendete grafische Beschriftungselemente bereitzustellen.

Darüber hinaus kann FreeCAD SVG-Dateien in den 3D-Raum importieren:

  • Als eine Bildebene, die über ihre Eigenschaft Placement positioniert werden kann.
  • Als separate 2D-Formen auf der XY-Ebene, die als Basisgeometrie für weiteres Modellieren verwendet werden können.

Letztlich hat FreeCAD auch Werkzeuge zum Exportieren in SVG-Dateien:

  • 3D-Geometrie kann als Flattened SVG gespeichert werden. In diesem Falle wird die ausgewählte Geometrie auf die XY-Ebene projiziert und nur die X- und Y-Koordinaten verwendet, um SVG-Elemente abzuleiten.
  • TechDraw stellt ein Werkzeug bereit, um die aktuelle Zeichnung zu speichern.

Std Importieren und Std Exportieren führen Aufgaben zum 3D-Import und -Export im Zusammenhang mit SVG-Daten aus; sie verwenden die Funktion Draft SVG des Draft-Moduls, um 3D-Geometrie in das bzw. aus dem SVG-Format zu konvertieren.

Anwendung

Hier gibt es ein paar zusätzliche Beschreibungen mit Fokus auf SVG-Dateien für Std Import und Std Export.

3D-Import

  1. Make there is an activate document.
  2. Select the File → Import... option from the menu.
  3. In the file browser that appears do one of the following:
    • With the default settings unchanged:
      1. Select a file and press the Open button.
      2. The Select Module dialog appears. From Open svg as select:
        • Image formats (FreeCAD) to import the SVG file as an image plane.
        • SVG as geometry (importSVG) to import the SVG file as separate shapes.
      3. Press the Open button to close the dialog and finish the tool.
    • Optionally select the SVG as geometry filter option.
    1. Select the desired SVG file and press the Open button to finish the tool.
  4. Depending on the selected options an image plane or several shape and text objects are added to the document.

3D-Export

Eine oder mehrere Formen auswählen.

  1. Den Menüeintrag Datei → Exportieren... auswählen.
  2. Im Datei-Browser, der erscheint, die Filteroption Flattened SVG auswählen.
  3. Einen Dateinamen eingeben.
  4. Einen Ordner zum Speichern der SVG-Datei auswählen.
  5. Die Schaltfläche Speichern drückken, um den Browser zu schließen und das Werkzeug zu beenden.

2D-Import und -Export

Die Beschreibungen der 2D-Werkzeuge sind gut die SVG-Dateien fokussiert, so dass hier das Verweisen auf die entsprechenden Seiten ausreicht.

  • Vorlagen sind SVG-Dateien, die erforderlich sind, um Zeichnungsblätter (Page-Objekte) in TechDraw anzulegen.
    • Neues Zeichnungsblatt importiert die voreingestellte SVG-Vorlagendatei.
    • Neues Zeichnungsblatt aus Vorlage öffnet einen Datei-Browser zum Auswählen und Importieren einer SVG-Vorlagendatei.
  • A symbol is a kind of TechDraw view used to add an SVG image for graphical annotation purposes to a TechDraw Page and optionally connect it with another TechDraw feature as its owner.
    • Insert SVG opens a file browser to select and import an SVG symbol file.
  • Optionally, when a drawing is finished the page can be exported as an SVG file.
    • Export Page as SVG
