Beschreibung

Der Befehl Silk ControlPoly6 erstellt einen 6-Punkt-Kontrollpolygon, ein ControlPoly6-Objekt, aus einer oder zwei Skizzen, kann aber auch Linienzüge aus einigen anderen Silk-Objekten extrahieren. Er ist dazu gedacht, eine bestehende kubische Bezier-Kurve/Kurvensegmente zu steuern.

Ein ControlPoly6, das aus einer Sechs-Punkt-Linienskizze erzeugt wurde.

It is mostly intended for blending existing Bézier curves or curve segments.

2 selected adjacent curve segments → Resulting blend polygon → Intended blend curve

Anwendung

  1. Dieses Werkzeug erstellt unterschiedliche Objekte mit individuellen Eigenschaften und Berechnungsmodi abhängig von den ausgewählten Eingabeelementen:
    • 5L-Modus: Eine Skizze in der Baumansicht oder in der 3D-Ansicht auswählen, die einen Linienzug aus 5 geraden Linien enthält.
    • 2N-Modus: Zwei erweiterte Knotenpunktskizzen in der Baumansicht oder in der 3D-Ansicht auswählen, die jeweils einen Kreis, eine gerade Linie, die im Kreismittelpunkt beginnt und eine zweite Linie, die am Endpunkt der ersten Linie beginnt, enthält.
    • FirstElement-Modus: Eine Skizze in der Baumansicht oder in der 3D-Ansicht auswählen, die eine beliebige Kombination unterschiedlicher Linien enthält. Nur der zuerst erkannte Bogen in der Skizze wird berücksichtigt bzw. die zuerst erkannte gerade Linie, wenn in der Skizze kein Bogen vorhanden ist.
    • Bezier-Modus: Einen ControlPoly4-Linienzug in der Baumansicht oder in der 3D-Ansicht auswählen. Dies ergibt eine exakte Übereinstimmung im ControlPoly6-Format.
    • FilletBezier -Modus: Zwei ControlPoly4-Linienzüge, die an einem Ende verbunden sind, in der Baumansicht oder in der 3D-Ansicht auswählen. Dies ergibt eine Übergangskurve mit G2-Stetigkeit.
  2. Es gibt mehrere Möglichkeiten, den Befehl aufzurufen:
    • Die Schaltfläche ControlPoly6 drücken.
    • Den Menüeintrag Silk → ControlPoly6 auswählen.
  3. Dem Modus entsprechend wird eins der folgenden Objekte erstellt:
    • ControlPoly6_5L.
    • ControlPoly6_2N.
    • ControlPoly6_FirstElement.
    • ControlPoly6_Bezier.
    • ControlPoly4_FilletBezier.
  4. Wahlweise Parameter in der Eigenschaften-Ansicht einstellen.

Hinweise

  • 6 point control polygons are required input objects for several other Silk objects:
    • 1 of these is used to create a CubicCurve_6.
    • 4 of these are used to create a ControlGrid66.
    • 2 of these control polygons in connection with 2 ControlPoly4 objects are used to create a ControlGrid64.
  • This control polygon is used to produce non-Bezier cubic curves and/or surfaces (number of control points greater than degree + 1). It only guarantees G2 internally. Its benefit is that it allows controlling curvature at connection points/edges to cubic Bezier curves/surfaces, which is why it is mostly intended for blending existing Bezier curves/curve-segments.
    • This is Bezier curve blending, the main use case, and it offers a good preview of how blending grids/surfaces will work. The hard corner between the two Bezier curves disappears, and the start and end of the poly match the original curves up to G2.
    • If you choose to build ControlPoly6, ControlGrid64, and ControlGrid66 objects manually, you will likely sometimes find yourself with a ControlPoly4 or a CubicCurve_4 in a location where a ControlPoly6 would be preferable. Silk can always convert a CubicCurve_4 to a ControlPoly6 exactly; the reverse is not true. All Beziers have an exact matching ControlPoly6, but a random ControlPoly6 does not generally have a matching Bezier.
    • 6-point cubic curves/surfaces are intended to be generated automatically by other tools, because of their G2 connection properties. Even when generated automatically, this poly is not generally recommended for direct use in building grids/surfaces (though it is allowed). The one genuinely valuable use case, in the context of the official workflow, is studying a set of Beziers and their blends in 2D before building the surfaces in 3D — very useful, for example, on the mirror plane of a design when it is not yet certain how many Beziers and blends the design requires.

Eigenschaften

Siehe auch: Eigenschaften-Ansicht.

Alle ControlPoly6-Objekte werden von einem Part-Formelement, oder genauer einem Part::FeaturePython-Objekt abgeleitet und übernehmen alle seine Eigenschaften. Sie besitzen auch die folgenden zusätzlichen Eigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftWeights (FloatList): Gewichte.
  • Daten-Eigenschaftreverse (Bool): Der Standardwert ist False. Kehrt die Parameterrichtung um.

C2 - Outputs

  • Daten-EigenschaftLegs (Part::PropertyGeometryList): Kontrollabschnitte.
  • Daten-EigenschaftPoles (VectorList): Pole.

C3 - Identifiers

  • Daten-EigenschaftinternalName (String): Der permanente interne FreeCAD-Name dieses Objekts.
  • Daten-Eigenschaftobject_version (String): Die Version der Klase dieses Objekts.


Ein ControlPoly6_5L-Objekt verfügt zudem über die folgenden individuellen Zusatzeigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftSketch (Link): Referenzskizze.
  • Daten-Eigenschafttolerance (Float): Default is 1e-06. Toleranz der Punkt-zu-Punkt-Verbindungen für die fünf Linien.

C3 - Identifiers

  • Daten-Eigenschaftobject_type (String): Der Standardwert ist ControlPoly6_5L. Die Arbeitsbereichs-Klasse, die zum Erstellen dieses Objekts verwendet wurde.


Ein ControlPoly6_2N-Objekt verfügt zudem über die folgenden individuellen Zusatzeigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftSketch0 (Link): Referenzskizze.
  • Daten-EigenschaftSketch1 (Link): Referenzskizze.
  • Daten-Eigenschafttolerance (Float): Der Standardwert ist 1e-06. Toleranz für die Punkt-zu-Punkt-Verbindung der Kreis-Linie in jedem Knoten.

C3 - Identifiers

  • Daten-Eigenschaftobject_type (String): Der Standardwert ist ControlPoly6_2N. Die Arbeitsbereichs-Klasse, die zum Erstellen dieses Objekts verwendet wurde.
