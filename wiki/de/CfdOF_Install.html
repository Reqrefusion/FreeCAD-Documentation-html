Voraussetzungen

Der externe Arbeitsbereich CfdOF ist auf folgende externe Programme angewiesen, von denen ein Teil automatisch installiert werden kann (Anweisungen dazu findet man weiter unten).

  1. Aktuelle Veröffentlichungsversion von FreeCAD (mindestens Version 0.20.0 / Git-Commit 29177) oder Aktuelle Entwicklungsversion (Vorabversion).
  2. OpenFOAM Foundation Versionen 9–10 oder ESI-OpenCFD Versionen 2006–2306.
  3. Paraview.
  4. cfMesh (angepasste Version, aktualisiert für die Kompilierung mit den neuesten OpenFOAM-Versionen).
  5. HiSA (High Speed Aerodynamic Solver).
  6. Gmsh (Version 2.13 oder höher) – optional, zur Erzeugung von Tetraeder-Netzen.

Einrichten des Arbeitsbereichs CfdOF

Windows

Die neueste Version oder Entwicklungsversion von FreeCAD (64-Bit-Version) kann heruntergeladen und installiert werden, indem man entweder das Installationsprogramm ausführt oder das .7z-Archiv in ein Verzeichnis <freecad-directory> entpackt. Im letzteren Fall kann FreeCAD direkt von dort aus ausgeführt werden (<freecad-directory>\bin\FreeCAD.exe).</freecad-directory></freecad-directory>

CfdOF selbst wird über den Addon-Manager in FreeCAD installiert:

  • FreeCAD starten
  • Werkzeuge → Addon-Manager
  • CfdOF in der Liste der Arbeitsbereiche auswählen und auf „Installieren/Aktualisieren“ klicken
  • FreeCAD neu starten
  • Informationen zur Installation der Abhängigkeiten findet man weiter unten

Hinweis: Der Arbeitsbereiche CfdOF kann jederzeit über den Addon-Manager aktualisiert werden.

Installation von Abhängigkeiten

Abhängigkeiten lassen sich bequem über das CfdOF-Einstellungsfenster in FreeCAD überprüfen und installieren. Im FreeCAD-Fenster Bearbeiten → Einstellungen und dann CfdOF wählen. Die Abhängigkeiten können als einzelne Komponenten oder als Teil eines Docker-Containers installiert werden (siehe Abschnitt Docker-Container-Installation weiter unten).

Die Installation von OpenFOAM erfolgt über das OpenCFD-MinGW-Paket, und auch die BlueCFD-Core-Portierung von OpenFOAM wird unterstützt.

OpenFOAM kann manuell über die oben genannten Links oder durch Klicken auf die entsprechende Schaltfläche im oben beschriebenen Einstellungsfenster installiert werden. Sollten bei der Ausführung von OpenFOAM in CfdOF Probleme auftreten, bitte sicherstellen, dass die Installation ordnungsgemäß funktioniert, indem die Anweisungen auf den entsprechenden Websites befolgt werden.

Um eine korrekte Anbindung an die OpenFOAM-Installation zu gewährleisten, muss CfdOF in der Lage sein, in sein Installationsverzeichnis zu schreiben. Bei einigen Benutzern treten aufgrund von Einschränkungen durch die Windows-Benutzerkontensteuerung Probleme bei der Verwendung eines Speicherorts innerhalb von C:\Programme (engl. C:\Program Files) auf. Es wird daher empfohlen, die Installation an einem anderen Speicherort vorzunehmen, vorzugsweise im Benutzer-Verzeichnis.

Wenn OpenFOAM mit Administratorrechten unter Verwendung der oben genannten Pakete installiert wird, wird optional auch Microsoft MPI installiert. Ist dies nicht der Fall, muss es manuell von der Microsoft MPI-Downloadseite heruntergeladen und installiert werden. MPI wird für die parallele Ausführung benötigt.

Im Einstellungsfenster das OpenFOAM-Installationsverzeichnis auf das Installationsverzeichnis festlegen, das beim MinGW-Paket auf den Unterordner „vXXXX“ endet (wobei XXXX für die installierte Versionsnummer steht), oder auf das BlueCFD-Installationsverzeichnis. An den Standardinstallationsorten wird es automatisch erkannt.

Es kann jede beliebige Version von ParaView installiert werden, indem man dem obigen Link folgt oder auf die entsprechende Schaltfläche im Fenster Einstellungen klickt. Im Fenster Einstellungen den Installationspfad für ParaView auf die Datei „paraview.exe“ im Unterordner „bin“ der ParaView-Installation festlegen. Wenn das Feld leer gelassen wird, werden die üblichen Standardeinstellungen übernommen.

Ebenso können cfMesh und HiSA über das Fenster „Einstellungen“ installiert werden. Dieses Fenster erst schließen, wenn die Meldung „Installation abgeschlossen“ angezeigt wird. Es muss beachtet werden, dass sich die OpenFOAM-Installation an einem beschreibbaren Speicherort befinden muss, damit cfMesh und HiSA erfolgreich installiert werden können.

Wenn man die Option „Abhängigkeiten prüfen“ auswählt, wird überprüft, ob alle Voraussetzungen erfolgreich installiert wurden.

Linux

AppImages der neuesten Release- oder Entwicklungs- Versionen von FreeCAD können heruntergeladen und direkt ohne Installation ausgeführt werden. Es muss beachtet werden, dass man die Ausführungsberechtigung für die heruntergeladene Datei aktivieren muss, um sie ausführen zu können. Alternativ kann FreeCAD auch aus dem Quellcode auf der FreeCAD-GitHub-Seite kompiliert werden.

Hinweis:

  • Bei der Installation von FreeCAD über Linux-Paketmanager wird die lokale Python-Installation verwendet. Daher müssen möglicherweise zusätzliche Python-Pakete installiert werden, um den vollen Funktionsumfang nutzen zu können. Der Abhängigkeitsprüfer (siehe unten) kann dabei helfen, dies festzustellen.
  • Es muss beachtet werden, dass der über die Paketmanager einiger Distributionen installierte „Snap“-Container problematisch sein kann, da er keinen Zugriff auf Systemverzeichnisse erlaubt und OpenFOAM daher im Home-Verzeichnis des Benutzers installiert werden muss, um von FreeCAD aus ausgeführt werden zu können.

Aus den oben genannten Gründen empfehlen wir AppImage als die stabilste Installationsoption unter Linux.

CfdOF selbst wird über den Addon-Manager in FreeCAD installiert:

  • FreeCAD starten
  • Werkzeuge → Addon-Manager
  • CfdOF in der Liste der Arbeitsbereiche auswählen und auf „Installieren/Aktualisieren“ klicken
  • FreeCAD neu starten
  • Informationen zur Installation der Abhängigkeiten findet man weiter unten

Hinweis: Der Arbeitsbereiche CfdOF kann jederzeit über den Addon-Manager aktualisiert werden.

Installation von Abhängigkeiten

Abhängigkeiten können überprüft und einige davon bequem über das CFD-Einstellungsfenster in FreeCAD installiert werden. Im FreeCAD-Fenster Bearbeiten → Einstellungen und dann CfdOF wählen.

Die Abhängigkeiten können manuell oder als Teil eines Docker-Containers installiert werden (siehe Docker-Container-Installation weiter unten). Die manuelle Installation kann für OpenFOAM (OpenCFD oder Foundation-Versionen), ParaView und Gmsh (optional) über die oben genannten Links oder den Paketmanager der Distribution erfolgen. Es muss jedoch beachtet werden, dass die in einigen Linux-Distributionen enthaltenen OpenFOAM-Pakete möglicherweise veraltet oder unvollständig sind; beispielsweise enthalten die Standardpakete von Debian und Ubuntu nicht den Build-Befehl „wmake“ und können daher nicht mit den optionalen Komponenten „HiSA“ und „cfMesh“ verwendet werden. Wir empfehlen daher die Installation der Pakete, die über die oben genannten offiziellen Websites bereitgestellt werden. Bitte sicherstellen, dass das „Entwicklungs“-Paket installiert wird, sofern verfügbar (in der Regel mit der Endung „-devel“ oder „-dev“), um sicherzustellen, dass die optionalen Komponenten „HiSA“ und „cfMesh“ mit „wmake“ kompiliert werden können.

Das OpenFOAM-Installationsverzeichnis im Einstellungsfenster festlegen – Beispiele für typische Installationsorte sind /usr/lib/openfoam/openfoam2306, /opt/openfoam10 oder /home/user/OpenFOAM/OpenFOAM-10.x (an gängigen Standardinstallationsorten wird es automatisch erkannt). Es muss beachtet werden: Wenn die gewünschte OpenFOAM-Umgebung bereits vor dem Start von FreeCAD geladen hat, sollte das Installationsverzeichnis leer gelassen werden.

cfMesh und HiSA können über das oben beschriebene Einstellungsfenster installiert werden. Falls man dies noch nicht selbst getan hat, können sie auch heruntergeladen und aus dem Quellcode in der OpenFOAM-Installation kompiliert werden. Es muss beachtet werden, dass dies ein langwieriger Vorgang ist.

Wenn man die Option „Abhängigkeiten prüfen“ auswählt, wird überprüft, ob alle Voraussetzungen erfolgreich installiert wurden.

Installation des Docker-Containers

Docker-Container bieten eine bequeme Möglichkeit, vorkompilierte Programmpakete sowohl für Windows als auch für Linux bereitzustellen. Auch macOS wird unterstützt, allerdings ist für die Einrichtung eines Containers Hilfe erforderlich. Bitte hinterlasse eine Nachricht im Forum.

Docker unter Windows

Die bevorzugte Docker-Laufzeitumgebung für Windows ist Podman, da diese derzeit eine schnelle Dateisystemintegration bietet. Docker Desktop kann ebenfalls verwendet werden.

  1. Install podman (or docker desktop).
  2. If using podman, open a cmd window and issue the following commands:
    • podman machine init
    • podman machine start
    • podman machine set --rootful
  3. Edit → Preferences → CfdOF: Press the Install Paraview button.
  4. Edit → Preferences → CfdOF: Select Use docker.
  5. Press the Install Docker Container button. There is no need to install gmsh, cfmesh and HISA as they are included in the docker image.
    • If using podman, fast WSL file system integration can be enabled:
    • Create a new subdirectory (for example cfdof) in the following directory created by podman: \\wsl$\podman-machine-default\home\user
    • In the cfdof preference page, set the default output directory as above: \\wsl$\podman-machine-default\home\user\cfdof
  6. Press the Run dependency checker button.

Docker unter Linux

  1. Install docker using these instructions (or similar).
  2. Install paraview as per the package installation instructions for your distribution (for example sudo apt-get install paraview on debian).
  3. Edit → Preferences → CfdOF: Select Use docker.
  4. Press the Install Docker Container button. There is no need to install gmsh, cfmesh and HISA as they are included in the docker image.
  5. Press the Run dependency checker button.
