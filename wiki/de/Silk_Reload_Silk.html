Description

The Silk Reload_Silk command reloads the Silk workbench (specifically, just its core library) without exiting FreeCAD, after making code changes.

Usage

  1. There are several ways to invoke the command.
    • Press the Reload_Silk button.
    • Select the Silk → Reload_Silk option from the menu.
