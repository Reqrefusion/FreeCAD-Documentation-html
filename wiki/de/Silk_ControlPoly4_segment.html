Beschreibung

Der Befehl Silk ControlPoly4 segment erstellt ein 4-Punkt-Abschnittspolygon, ein ControlPoly4_segment-Objekt, für einen Kurvenabschnitt einer Primärkurve zwischen zwei Punkten auf der Kurve.

Segmentierte ControlPoly4.

Primärkurve → Punkte auf der Kurve hinzugefügt → 3 Abschnittspolygone zwischen den Punkten

Anwendung

  1. In der Baumansicht oder der 3D-Ansicht auswählen:
    1. Eine Primärkurve.
    2. Den ersten Punkt auf der Kurve.
    3. Den zweiten Punkt auf der Kurve.
  2. Es gibt mehrere Möglichkeiten, den Befehl aufzurufen:
    • Die Schaltfläche Silk_ControlPoly4_segment drücken.
    • Den Menüeintrag Silk → Silk_ControlPoly4_segment auswählen.
  3. Ein Abschnittspolygon, ein ControlPoly4_segment-Objekt, wird erstellt.

Hinweise

  • Segmenting (sectioning, cutting) is a core Silk modeling technique, essential for blending. The current workflow uses curve segments as references to cut surfaces. There are plans to cut surfaces by drawing points directly on them, but since the same result is already achievable using curve segments, this convenience is a medium priority.
  • Why so much segmenting in Silk — segmenting curves, then segmenting surfaces, so much time spent aligning segmentation points? Because building off segments/pieces of a single Bezier curve or surface preserves "relatedness" between the parts. They blend well, and sections separated by gaps still feel like part of the same surface. This sense of connectedness is nearly impossible to achieve by trying to "harmonize" two curves or surfaces that were built separately and then merged. The key to blending in Silk is sharing edges between base surfaces (which are not otherwise aligned), and then blending strips of the surfaces near that shared edge. The shared edges and strips produce blends that look decent even before fine-tuning.

Eigenschaften

Siehe auch: Eigenschaften-Ansicht.

Ein Abschnittspolygon, ein ControlPoly4_segment-Objekt, wird von einem Part-Formelement, oder genauer einem Part::FeaturePython-Objekt abgeleitet und übernimmt alle seine Eigenschaften. Es besitzt auch die folgenden zusätzlichen Eigenschaften:

Daten

C1 - Inputs

  • Daten-EigenschaftNL_Curve (Link): Referenzkurve.
  • Daten-EigenschaftPoint_onCurve_0 (Link): Startpunkt des Abschnitts.
  • Daten-EigenschaftPoint_onCurve_1 (Link): Endpunkt des Abschnitts.
  • Daten-Eigenschaftreverse (Bool): Der Standardwert ist False. Kehrt die Parameterrichtung um.

C2 - Outputs

  • Daten-EigenschaftLegs (Part::PropertyGeometryList): Kontrollsegmente.
  • Daten-EigenschaftPoles (VectorList): Pole.
  • Daten-EigenschaftWeights (FloatList): Gewichte.

C3 - Identifiers

  • Daten-EigenschaftinternalName (String): Der dauerhafte interne FreeCAD-Name dieses Objekts.
  • Daten-Eigenschaftobject_type (String): Standardeinstellung ControlPoly4_segment. Die Klasse des Arbeitsbereichs, die zum Erstellen dieses Objekts verwendet wird.
  • Daten-Eigenschaftobject_version (String): Die Version der Klasse dieses Objekts.
