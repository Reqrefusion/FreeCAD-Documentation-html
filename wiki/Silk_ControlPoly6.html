Description

The Silk ControlPoly6 command does ...

A ControlPoly6 generated from a six point line sketch.

Usage

  1. There are several options for a preselection:
    • Select one Sketch in the Tree View or in the 3D View containing a wire of 5 straight line segments.
    • Select two extended "Node sketches" in the Tree View or in the 3D View, each containing a circle, a straight line starting at the circle center, and a second line starting at the endpoint of the first line.
    • Select two CubicCurve_4 objects connected at one end — this produces a G2 blend.
    • Select one CubicCurve_4 object — this produces an exact match in ControlPoly6 format.
  2. There are several ways to invoke the command.
    • Press the ControlPoly6 button.
    • Select the Silk → ControlPoly6 option from the menu.
  3. One of the following objects is created:
    • A ControlPoly6_5L object if the first preselection option was chosen.
    • A ControlPoly6_2N object if the second preselection option was chosen.
    • A ControlPoly6_?? object if the third preselection option was chosen.
    • A ControlPoly4_?? object if the last preselection option was chosen.
  4. Optionally adjust parameters in the Property View.
  5. A ControlPoly6 object, is created.
