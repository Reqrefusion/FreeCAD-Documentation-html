Описание

Командата Кръгов масив (Draft CircularArray) създава масив от избран обект, като поставя копия по концентрични кръгове. Командата може по желание да създаде свързан масив, който е по-ефективен от обикновен масив.

Командата може да се използва на 2D обекти, създадени в Чертожната маса или Работна маса Sketcher, но също така и на много 3D обекти като тези, създадени с Работна маса Част, Дизайн на части или BIM Workbench.

Кръгов масив

Използване

Вижте също: Draft Snap.

  1. По желание изберете един обект.
  2. Има няколко начина да се задейства командата:
    • Натиснете бутон Кръгов масив.
    • Изберете от манюто Модифициране → Array Tools → Кръгов масив.
  3. Отваря се панел на задача Кръгов масив. Вижте Опции за повече информация.
  4. Ако все още не сте избрали обект: изберете един обект.
  5. Въведете необходимите параметри в панела на задачите.
  6. За да завършите командата направете едно от следните неща:
    • Изберете точка в 3D изгледа за Център на ротация.
    • Натиснете Enter.
    • Натиснете бутона Добре.

Опции

  • Въведете Радиално разстояние, за да зададете разстоянието между кръговите слоеве и между центъра и първия кръгъл слой.
  • Въведете Тангенциално разстояние, за да зададете разстоянието между елементите на същия кръгов слой. Трябва да е по-голямо от нулата.
  • Въведете Брой на концентричните кръгове. Елементът в центъра се брои за един кръг. Трябва да е най-малко 2.
  • Въведете стойността Симетрия. Това число определя как се разпределят елементите. Стойност 3, например, води до модел с три сегмента на всеки 120°. По-големите стойности за Симетрия и Тангенциално разстояние водят до по-малко или дори никакви елементи на вътрешните кръгове.
  • Изберете точка в 3D изгледа, имайте предвид, че това също ще завърши командата, или въведете координати за Център на ротация. Оста на въртене на масива ще премине през тази точка. Препоръчително е да преместите показалеца от 3D изгледа, преди да въведете координати.
  • Натиснете бутона Нулиране на точка, за да нулирате Център на ротация до началото на координатната система.
  • Ако квадратчето Обединение е отметнато припокриващите се елементи в масива се обединяват в едно тяло.
  • Ако квадратчето Свързан масив е отметнато се създава свързан масив вместо обикновен масив. Свързаният масив е по-ефективен, тъй като неговите елементи са обекти Връзки.
  • Натиснете Esc или бутона Отказ, за да прекратите командата.

В скриптове

Вижте също: Autogenerated API documentation и FreeCAD Scripting Basics.

За да създадете Draft CircularArray използвайте метод make_array от модул Draft. Методът make_array може да създаде Draft OrthoArrays, Draft PolarArrays и кръгови масиви. За всеки тип масив са на разположение една или повече опаковки.

The main method: 

array = make_array(base_object, arg1, arg2, arg3, arg4=None, arg5=None, arg6=None, use_link=True)

The wrapper for circular arrays is: 

array = make_circular_array(base_object,
                            r_distance=100, tan_distance=50,
                            number=3, symmetry=1,
                            axis=App.Vector(0, 0, 1), center=App.Vector(0, 0, 0),
                            use_link=True)
  • base_object is the object to be arrayed. It can also be the Label (string) of an object in the current document.
  • r_distance and tan_distance are the radial and tangential distances between the elements.
  • number is the number of circular layers in the pattern, the original object counts as the first layer.
  • symmetry is an integer used in some calculations that affect the way the elements are distributed around the circumferences. Usual values are from 1 to 6. Higher values are not recommended and will make the elements in the inner layers disappear.
  • axis and center are vectors that describe the direction of the axis of rotation, and a point through which that axis passes.
  • If use_link is True the created elements are App Links instead of regular copies.
  • array is returned with the created array object.

Example: 

import FreeCAD as App
import Draft

doc = App.newDocument()

tri = Draft.make_polygon(3, 600)

array = Draft.make_circular_array(tri, 1800, 1200, 4, 1)
doc.recompute()
