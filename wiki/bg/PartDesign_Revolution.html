Description

The PartDesign Revolution tool creates a solid in the active Body by revolving a sketch, a 2D object, or one or more faces about a given axis. Its shape is combined with the existing solid if there are previous features.

Above: sketch (A) is revolved 270 degrees counter-clockwise around axis (B); resulting solid (C) is shown right.

Usage

  1. Select a single sketch or similar 2D object, or one or more faces from a single sketch or other object, or from the Body itself.
  2. There are several ways to invoke the tool:
    • Press the Revolve button.
    • Select the Part Design → Additive Features → Revolve option from the menu.
  3. The task panel opens.
  4. Set the parameters, see Options below. introduced in 1.1: If the Show interactive draggers when editing features preference is selected (default), angle parameters can be adjusted with interactive gizmos in the 3D View.
  5. Press the OK button to close the task panel and finish the tool.
  6. A Revolution feature appears under the active Body.

Editing

The Revolution can be edited after its creation in two ways:

  • Double-clicking it in the Tree View, or by right-clicking and selecting Edit Revolution in the context menu; this brings up the task panel and (introduced in 1.1) the interactive gizmos (if enabled).
  • Via the Property View.

Options

The task panel offers the following settings:

Start

introduced in 26.3

Sets the angular starting position of the revolution around the axis. By default the revolution starts at the sketch or face used as its profile.

  • Profile plane (default): the revolution starts directly at the profile's sketch plane or face.
  • Offset: the revolution starts at an angular offset from the profile, entered in the Offset field.
  • Reference: the revolution starts at a face, datum plane, or sketch selected with the Pick Reference button.

Direction

introduced in 26.3

Sets the direction(s) of the revolution:

  • One sided: the revolution extends on one side of the sketch or face.
  • Two sided: the revolution extends on both sides of the sketch or face. Two sub-menus (Side 1 and Side 2) appear to define the revolution for each side.
  • Symmetric: the revolution is symmetrical with respect to the original sketch or face.

Axis

Specifies the axis of the revolution:

  • Vertical sketch axis: selects the vertical sketch axis.
  • Horizontal sketch axis: selects the horizontal sketch axis.
  • Construction line: selects a construction line from the sketch used by the revolution. The dropdown list will contain an entry for each construction line. The first construction line will be labelled Construction line 1.
  • Base (X/Y/Z)-axis: selects the X-, Y- or Z-axis of the Body's origin.
  • Select reference…: allows the selection of a straight edge or a datum line from the Body.

Note that when changing the axis, the Reversed option may be (un)checked automatically.

Type

introduced in 1.0

For Side 1 and Side 2 if applicable.

Offers four ways to specify the angle of the revolution:

  • Angle: enter a numeric value for the Angle of the revolution. With the Direction option Symmetric the revolution will extend half the given angle to either side of the sketch or face.
  • To last: the revolution will extend up to the last face of the support it encounters in its direction. If there is no support, an error message will appear.
  • To first: the revolution will extend up to the first face of the support it encounters in its direction. If there is no support, an error message will appear.
  • Up to face: the revolution will extend up to a face. Press the Face button and select a face or a datum plane from the Body.

Angle

For Side 1 and Side 2 if applicable.

Defines the angle of the revolution. This option is only available if Type (for the same side) is Angle. Angles larger than 360° are not possible.

Project selected axis to profile plane

introduced in 26.3

Projects the selected axis onto the profile plane if the profile is planar (only available for planar profiles). When unchecked (default), the axis is used in its original position and direction.

Reversed

Reverses the direction of the revolution.

Recompute on change

This option should be checked if Show final result or Show preview overlay is checked.

Show final result

If checked the cumulative result of the previous features and the current operation is shown.

Show preview overlay

If checked the result of the current operation is shown as an overlay.
