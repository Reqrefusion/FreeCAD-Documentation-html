Description

The Silk ControlGrid66_4Sub command creates a blended corner grid, a ControlGrid66_4Sub object from 4 corner sub-grids to close a gap surrounded by 4 blended edge grids.

Four SubGrid33 partial grids around a four-sided corner hole, before joining

The finished ControlGrid66_4Sub filling the corner hole

4 selected corner sub-grids → Resulting blended corner grid filling the corner gap

Usage

  1. Select 4 related corner sub-grids in a loop.
  2. There are several ways to invoke the command.
    • Press the ControlGrid66_4Sub button.
    • Select the Silk → ControlGrid66_4Sub option from the menu.
  3. A ControlGrid66_4Sub object, is created.

Properties

See also: Property View.

A blended corner grid, a ControlGrid66_4Sub object, is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional properties:

Data

ControlGrid66_4Sub

  • DataLegs (Part::PropertyGeometryList): Control segments.
  • DataPoles (VectorList): Poles.
  • DataSubGrid_0 (Link): First reference 3X3 sub-grid.
  • DataSubGrid_1 (Link): Second reference 3X3 sub-grid.
  • DataSubGrid_2 (Link): Third reference 3X3 sub-grid.
  • DataSubGrid_3 (Link): Fourth reference 3X3 sub-grid.
  • DataWeights (FloatList): Weights.
