Description

The Silk ControlGrid66 command creates a ControlGrid66 from 4 connected CubicCurve_6.

A ControlGrid66 built from four ControlPoly6 edges

Usage

  1. Select 4 connected ControlPoly6 edges in the 3D View.
  2. There are several ways to invoke the command.
    • Press the ControlGrid66 button.
    • Select the Silk → ControlGrid66 option from the menu.
  3. A ControlGrid66 object, is created.
