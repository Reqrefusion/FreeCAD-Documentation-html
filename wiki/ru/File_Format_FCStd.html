Обзор

Стандартный формат файлов FreeCAD (.FCStd) является основным форматом файлов FreeCAD. Это составной формат, поддерживающий сжатие и встраивание различных типов данных.

Внутренняя структура файлов .FCStd

FCStd — это стандартный zip-файл, содержащий один или несколько файлов с определённой структурой. Как таковой, файл .FCStd можно распаковать обычным инструментом распаковки zip, но при упаковке содержимого файла .FCStd необходимо соблюдать осторожность. FreeCAD содержит утилиту "Project Utility" для переупаковки файлов .FCStd, её использование описано в разделе Изменение исходного файла .FCStd ниже.

Document.xml

Это основной файл .xml, описывающий все объекты внутри документа FreeCAD, то есть только геометрическое и параметрическое определение объектов, а не их визуальное представление. Если FreeCAD запущен в консольном режиме (без графического интерфейса), будет использоваться только этот файл Document.xml.

GuiDocument.xml

Это графический аналог файла Document.xml. Для каждого объекта, описанного в Document.xml, существует один соответствующий объект в GuiDocument.xml, описывающий визуальное представление этого объекта (цвет, толщина линии и т.д.).

Thumbnails/thumbnail.png

Это миниатюра документа размером 128x128 пикселей, представляющая собой снимок 3D-вида в момент сохранения. Миниатюры создаются только в том случае, если соответствующая опция включена в настройках FreeCAD.

*.brep

These are the B-rep shapes of all objects that have a Part shape in the Document.xml. Each object, even if it is parametric, has its shape stored as an individual .brep file, so it can be accessed by components without the need to recalculate the shape.

*.svg

These are the template svg files used in TechDraw pages.

Типичная структура

Structure of a typical .FCStd file. The extension can be changed to .zip to explore it like a normal directory. The Document.xml and GuiDocument.xml are at the root of the archive, together with any number of .brp (BREP) files. One subdirectory may hold the thumbnail, and another the SVG templates used by TechDraw. 

File.FCStd (File.zip)
  |
  |--thumbnails/
  |  |
  |  :--Thumbnail.png
  |
  :--Document.xml
  :--GuiDocument.xml
  :--Shape1.brp
  :--Shape2.brp
  :--MyPage.svg
  :--etc.

Embedding other files

In order to embed other file types inside a FCStd file, you must first create a scripted object from the Python Console, and give it an App::PropertyFileIncluded property.

Затем в Property View можно перейти к добавленному свойству и выбрать файл на компьютере. После сохранения файла FCStd файл, назначенный свойству ДанныеPropertyFileIncluded, будет упакован внутрь .FCStd. При восстановлении документа тот же файл будет восстановлен вместе с свойством ДанныеPropertyFileIncluded. 

custom_obj = App.ActiveDocument.addObject("App::FeaturePython", "CustomObject")
custom_obj.addProperty("App::PropertyFileIncluded", "AttachedFile")
