Введение

Это руководство предназначено для того, чтобы познакомить читателя с основным рабочим процессом PartDesign Workbench. Читатель увидит, как создавать 3D-объекты на основе эскизов, выполнять операции вычитания и как воспроизводить определенные элементы в шаблоне..

Требования

  • FreeCAD версии 0.17 или старше
  • Читатель завершил Basic Sketcher Tutorial

Последовательность действий

Создание 3D геометрии

Цель «PartDesign Workbench» — предоставить пользователю возможность создавать геометрию в трехмерном пространстве. Таким образом, он имеет инструменты для использования эскизов и преобразования их в 3D-объекты.

Для этого существует два инструмента: Pad and Revolution. Наряду с противоположными методами, основанными на удалении ( Pocket and Groove) они составляют большинство необходимых действий, используемых в этом инструменте.

  1. Переключитесь на верстак PartDesign
  2. Выбрав эскиз в Tree View, нажмите PartDesign Body, выберите по умолчанию XY плоскость, и нажмите OK. Эскиз должен появиться внутри тела.
  3. Выберите Pad
  4. Установите значение 5 мм.
  5. Выберите Ok

Ещё один способ создания 3D-геометрии — использование инструмента Revolution.

  1. Создайте новое тело PartDesign Body, а затем эскиз на основе изображения выше.
  2. Эскиз может располагаться на любой плоскости, но должен быть совмещён с горизонтальной осью.
  3. Выберите Revolution.
  4. Установите параметр «Ось» в значение «Горизонтальная ось эскиза».
  5. Установите угол 360°.

Функции вычитания

Начнем с создания формы эскиза, которую хотим вычесть.

  1. Выберите верхнюю плоскую грань тела "Revolution"
  2. Выберите New Sketch
  3. Выберите External Geometry
  4. Подведите курсор к краю выступа (Pad). Должна подсветиться дуга.
  5. Выберите дугу. В эскизе должна появиться дуга другого цвета.
  6. Создайте шестиугольник с центром в той же точке, что и дуга, и установите радиус опорной окружности равным 5 мм.
External Geometry

Когда создан 3D-элемент, в эскизе можно создавать ссылки на него.

  1. Выберите External Geometry.
  2. Подведите курсор к элементу, на который вы хотите сослаться, например, к грани Pad.
  3. Щелкните по нему.
  4. В эскизе в месте расположения нужного элемента должны появиться новые элементы другого цвета.

После этого мы применим функцию Pocket (Карман).

  1. Выберите эскиз
  2. Выберите Pocket
  3. Установите расстояние на Сквозной

Операции с массивами

Вспомните профиль, полученный выдавливанием, который был создан в начале урока.

  1. Выберите верхнюю грань объекта
  2. Создайте новый эскиз
  3. Создайте вспомогательную геометрию, привязанную к верхнему плечу фигуры
  4. Создайте окружность с привязкой к центру вспомогательной дуги
  5. Установите её радиус 3 мм
  6. Выполните Pocket (Карман) сквозь всю заготовку

Вместо создания окружности для каждого отверстия в эскизе мы введём понятие Pattern Features (Операции с массивами). Эти инструменты работают путём копирования уже созданного элемента заготовки, который мы хотим воспроизвести в линейном или круговом порядке. Мы будем использовать одновременно комбинацию операций с массивами Linear (Линейный) и Polar (Круговой), чтобы получить итоговую заготовку.

  1. Выберите элемент Pocket, который мы только что создали в Древе проекта
  2. Выберите MultiTransform

В Combo View теперь нам предлагается задать желаемые Transformations (Преобразования). Обратите внимание, что в меню MultiTransform parameters (Параметры MultiTransform) мы видим, что FreeCAD определил Pocket как Original feature (Исходный элемент), а во втором поле предлагается щелкнуть правой кнопкой мыши для добавления операций с массивами.

  1. Щелкните правой кнопкой мыши по полю
  2. Выберите Add Linear Pattern (Линейный массив)
  3. Установите Direction (Направление) на Vertical Sketch Axis (Вертикальная ось эскиза)
  4. Установите длину 10 мм
  5. Оставьте количество экземпляров равным 2
  6. Нажмите OK
  7. Снова щелкните правой кнопкой мыши по полю, чтобы добавить Polar Pattern (Круговой массив). Обратите внимание, что в 3D View теперь появился линейный массив.
  8. Установите количество экземпляров равным 5
  9. Дважды нажмите OK

После выполнения этого задания вы должны получить следующий результат.

Если нет, повторно отредактируйте операцию MultiTransform, дважды щелкнув по ней в Древе проекта. Проверьте оба элемента массива, чтобы выявить необходимые изменения, такие как Ось и необходимость изменения направления (Direction) на противоположное.

Теперь мы завершили базовый рабочий процесс для верстака PartDesign Workbench.
