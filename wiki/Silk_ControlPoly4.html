Description

The Silk ControlPoly4 command creates a 4 node control polygon, a ControlPoly4 object, from one or two sketches.

A 3D control polygon built from two Node Sketches

This command is the second of three steps to create a parametric Bezier cubic curve:

  1. Create one or two Sketches
  2. Create a Silk ControlPoly4
  3. Create a Silk CubicCurve_4

Sketch → Control polygon → Resulting Bezier curve

Usage

  1. There are several options for a preselection:
    • Select one Sketch in the Tree View or in the 3D View containing a wire of 3 straight line segments.
    • Select two Sketches in the Tree View or in the 3D View, each containing a circle, and a straight line starting at the circle center.
    • Select one Sketch in the Tree View or in the 3D View containing an arbitrary combination of different lines.
  2. There are several ways to invoke the tool.
    • Press the ControlPoly4 button.
    • Select the Silk → ControlPoly4 option from the menu.
  3. One of the following objects is created:
    • A ControlPoly4_3L object if the first preselection option was chosen.
    • A ControlPoly4_2N object if the second preselection option was chosen.
    • A ControlPoly4_FirstElement object if the last preselection option was chosen.
  4. Optionally adjust parameters in the Property View.

Notes

  • 4 of these control polygons are used to create a ControlGrid44.
  • 3 of these control polygons are used to create a ControlGrid44_Rotate.
  • 2 of these control polygons in connection with 2 ControlPoly6 are used to create a ControlGrid64.

Properties

See also: Property View.

All ControlPoly4 objects are derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. They also have the following common additional properties:

Data

C1 - Inputs

  • Datareverse (Bool): Default is False. Reverses the parameter direction.

C2 - Outputs

  • DataLegs (Part::PropertyGeometryList): Control segments.
  • DataPoles (VectorList): Poles.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_version (String): The class version of this object.


A ControlPoly4_3L also has the following individual additional properties:

Data

C1 - Inputs

  • DataSketch (Link): Reference Sketch.
  • DataWeights (FloatList): Weights.
  • Datatolerance (Float): Default is 1e-06. Point-to-point connection tolerance for the 3 lines.

C3 - Identifiers

  • Dataobject_type (String): Default is ControlPoly4_3L. The workbench class used to create this object.


A ControlPoly4_2N object also has the following individual additional properties:

Data

C1 - Inputs

  • DataSketch0 (Link): Reference Sketch.
  • DataSketch1 (Link): Reference Sketch.
  • DataWeights (FloatList): Weights.
  • Datatolerance (Float): Default is 1e-06. Point-to-point connection tolerance for the circle-line in each node.

C3 - Identifiers

  • Dataobject_type (String): Default is ControlPoly4_2N. The workbench class used to create this object.


A ControlPoly4_FirstElement object also has the following individual additional properties:

Data

C1 - Inputs

  • DataSketch (Link): Reference Sketch.
  • Datatolerance (Float): Default is 1e-06. Point-to-point connection tolerance for the 3 lines.

C2 - Outputs

  • DataWeights (FloatList): Weights.

C3 - Identifiers

  • Dataobject_type (String): Default is ControlPoly4_FirstElement. The workbench class used to create this object.
