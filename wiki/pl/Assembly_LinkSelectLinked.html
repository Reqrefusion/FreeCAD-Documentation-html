Description

The Assembly LinkSelectLinked tool opens the source document of a linked assembly.

Usage

  1. Select a linked assembly.
  2. Select the Assembly → Go to Linked Assembly option from the menu.
  3. The source document of the linked assembly is opened and the assembly is selected.
