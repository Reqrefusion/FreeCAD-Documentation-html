Opis

The CfdOF SolverControl command opens a task panel to solve the analysis using OpenFOAM and open the results in Paraview.

Użycie

Solve and View Results

  1. Press the Write Case button.
  2. Press the Run button.
    • A plot will open in a new tab to plot residuals. In a steady-state analysis, the solver will continue until all residuals are below a specified value (0.001 by default), or for a specified number of iterations (2000 by default). In a transient analysis, it continues until a specified end time is reached (1.0 s). These defaults can be changed in the Data Tab of the Property View. The plotted residuals should decrease over time. If they increase (diverge), the results will be inaccurate, but that can sometimes be fixed by improving the mesh quality or changing boundary conditions.
  3. Press the ParaView button.
    • This opens Paraview in a new window for viewing results. ParaView supports color maps, vector fields, and charts. See ParaView Documentation for help.

Opcje

When Solve in Parallel is checked, OpenFOAM will run with multiple CPU cores.

Uwagi

  • OpenFOAM and ParaView must be installed in the locations specified in the CfdOF Preferences Panel. See CfdOF Install.
