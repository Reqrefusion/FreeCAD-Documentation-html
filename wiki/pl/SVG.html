Wprowadzenie

SVG to skrót od Scalable Vector Graphics, wektorowego formatu obrazu dla grafiki dwuwymiarowej.

Formaty wektorowe, takie jak SVG, są bardzo przydatne w programach do rysowania technicznego, takich jak FreeCAD, ponieważ obraz SVG może być skalowany do dowolnego rozmiaru bez utraty jego kształtu lub ilości szczegółów. SVG można przeskalować do dowolnej wymaganej rozdzielczości i konwertować do formatów bitmapowych, takich jak PNG lub JPEG, w celu drukowania.

Obraz SVG jest opisany w języku XML, co oznacza, że w celu dokonania zmian można go otwierać i edytować za pomocą prostego edytora tekstu. Ze względu na swój tekstowy charakter, plik może być również łatwo przeszukiwany, indeksowany i kompresowany. Ten język znaczników SVG jest otwartym standardem opracowanym przez World Wide Web Consortium (W3C) od 1999 roku. Oznacza to, że plik SVG powinien być czytany i interpretowany w ten sam sposób przez zgodne przeglądarki i aplikacje rysunkowe.

Więcej informacji o formacie SVG można uzyskać na stronie: Scalable Vector Graphics.

SVG w programie FreeCAD

FreeCAD jest przede wszystkim aplikacją do modelowania 3D, dlatego nie oferuje wielu narzędzi do rysowania 2D. Z drugiej strony FreeCAD w dużym stopniu opiera się na plikach SVG:

  • Ikony w graficznym interfejsie użytkownika, reprezentujące narzędzia w menu i na paskach narzędzi oraz obiekty i elementy w Widoku drzewa
  • Szablony dla środowiska pracy Rysunek Techniczny, reprezentujące arkusze papieru, które definiują format rysunku i umożliwiają drukowanie w skali. Mogą również zawierać ramki i tabliczkę rysunkową.
  • Symbole, widoki środowiska pracy Rysunek Techniczny osadzające po jednym pliku SVG każdy, służące do umieszczania często używanych graficznych elementów adnotacji.

Ponadto FreeCAD może importować pliki SVG do przestrzeni 3D:

  • Jako płaszczyznę obrazu, którą można pozycjonować za pomocą właściwości Umiejscowienie.
  • Jako oddzielne kształty 2D na płaszczyźnie XY, które mogą być używane jako geometria bazowa do dalszego modelowania.

Wreszcie FreeCAD oferuje narzędzia do eksportowania do formatu SVG:

  • Geometrię 3D można zapisać jako Spłaszczony SVG. W tym przypadku wybrana geometria jest rzutowana na płaszczyznę XY i tylko współrzędne X i Y są wykorzystywane do utworzenia elementów SVG.
  • Środowisko pracy Rysunek Techniczny udostępnia narzędzie do zapisywania bieżącego rysunku.

Import i Eksport obsługują pliki SVG, używają funkcji SVG środowiska Rysunek Roboczy do konwersji geometrii 3D z/do formatu SVG.

Użycie

Tutaj znajdziesz dodatkowe opisy skupione na plikach SVG dla Importu i Eksportu.

Import 3D

  1. Upewnij się, że dokument jest aktywny.
  2. Wybierz z menu opcję Plik → Importuj....
  3. W wyświetlonej przeglądarce plików wykonaj jedną z poniższych czynności:
    • Przy niezmienionych ustawieniach domyślnych:
      1. Wybierz plik i naciśnij przycisk Otwórz.
      2. Pojawi się okno dialogowe Wybierz moduł. W sekcji Otwórz SVG jako wybierz:
        • Formaty obrazów (FreeCAD), aby zaimportować plik SVG jako płaszczyznę obrazu.
        • 'SVG jako geometria (importSVG), aby zaimportować plik SVG jako oddzielne kształty.
      3. Naciśnij przycisk Otwórz, aby zamknąć okno dialogowe i zakończyć działanie narzędzia.
    • Opcjonalnie wybierz filtr SVG jako geometria.
    1. Wybierz żądany plik SVG i naciśnij przycisk Otwórz, aby zakończyć działanie narzędzia.
  4. W zależności od wybranych opcji do dokumentu zostanie dodana płaszczyzna obrazu lub kilka obiektów kształtów i tekstu.

Eksport 3D

Wybierz jeden lub więcej kształtów.

  1. Wybierz z menu opcję Plik → Eksportuj....
  2. W wyświetlonej przeglądarce plików wybierz filtr Spłaszczony SVG.
  3. Wprowadź nazwę pliku.
  4. Wybierz folder, w którym chcesz zapisać plik SVG.
  5. Naciśnij przycisk Zapisz, aby zamknąć przeglądarkę i zakończyć działanie narzędzia.

Import i Eksport 2D

The descriptions of the 2D tools are well focussed on SVG files so that linking the relevant pages is sufficient here.

  • Templates are SVG files required to define drawing sheets (Page objects) in TechDraw.
    • New Page imports the default SVG template file.
    • New Page From Template opens a file browser to select and import an SVG template file.
  • A symbol is a kind of TechDraw view used to add an SVG image for graphical annotation purposes to a TechDraw Page and optionally connect it with another TechDraw feature as its owner.
    • Insert SVG opens a file browser to select and import an SVG symbol file.
  • Optionally, when a drawing is finished the page can be exported as an SVG file.
    • Export Page as SVG
