Description

The Silk CubicCurve 4 command creates a parametric Bezier cubic curve, a CubicCurve_4 object, from a ControlPoly4 or ControlPoly4_segment object.

A 3D Bezier curve built from a ControlPoly4_2N object

This command is the last of three steps to create a parametric Bezier cubic curve:

  1. Create one or two Sketches
  2. Create a Silk ControlPoly4
  3. Create a Silk CubicCurve_4

Sketch → Control polygon → Resulting Bezier curve

Usage

  1. There are several options for a preselection:
    • Select one ControlPoly4 in the Tree View or in the 3D View.
    • Select one ControlPoly4_segment in the Tree View or in the 3D View.
  2. There are several ways to invoke the tool.
    • Press the CubicCurve_4 button.
    • Select the Silk → CubicCurve_4 option from the menu.
  3. A CubicCurve_4 object is created.
  4. Optionally adjust parameters in the Property View.

Properties

See also: Property View.

A CubicCurve_4 is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional properties:

Data

C1 - Inputs

  • DataPoly (Link): Control polygon.
  • Datareverse (Bool): Default is False. Reverses the parameter direction.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is CubicCurve_4. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
