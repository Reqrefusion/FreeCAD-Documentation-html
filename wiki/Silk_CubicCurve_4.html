Description

The Silk CubicCurve 4 command creates a parametric Bézier cubic curve, a CubicCurve_4 object, from a 4 point polygon or a 4 point polygon for segments.

A 3D Bézier curve built from a ControlPoly4_2N object

These curves are used as primary curves to visualize the edges of primary surfaces and as curve segments controlling the layout of sub-surfaces on a primary surface.

4 point polygon → Primary curve → Points on curve added → 3 segment polygons between the points → 3 curve segments


Usage

  1. There are several options for a preselection:
    • Select one 4 point polygon in the Tree View or in the 3D View.
    • Select one Control4 point polygon for segments in the Tree View or in the 3D View.
  2. There are several ways to invoke the tool.
    • Press the CubicCurve_4 button.
    • Select the Silk → CubicCurve_4 option from the menu.
  3. A cubic Bézier curve, a CubicCurve_4 object, is created.
  4. Optionally adjust parameters in the Property View.

Properties

See also: Property View.

A cubic curve, a CubicCurve_4 object, is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional properties:

Data

C1 - Inputs

  • DataPoly (Link): Control polygon.
  • Datareverse (Bool): Default is False. Reverses the parameter direction.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is CubicCurve_4. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
