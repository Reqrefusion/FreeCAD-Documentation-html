Description

The CfdOF MeshRegion command creates an object that holds data to add surface, volume and extrusion refinements to the background mesh. The data can be edited in a task panel.

Usage

Create refinement data object

  1. Select a [GeometryName]_Mesh data object in the Tree View.
  2. There are several ways to invoke the command:
    • Press the Mesh‏‎ refinement button.
    • Select the CfdOF → Mesh‏‎ refinement option from the menu.
  3. A MeshRefinement data object is added to the [GeometryName]_Mesh data object.
  4. The task panel opens. See Options for more information.
  5. Press the OK button to confirm and finish the command.
  6. Optionally repeat the command to add more refinement data objects to the [GeometryName]_Mesh data object.

Edit refinement data object

  1. Double-click a MeshRefinement data object in Tree View.
  2. The task panel opens. See Options for more information.
  3. Press the OK button to confirm and finish the command.

Options

The task panel offers the following settings:

Surface Refinement

Volume Refinement

Extrusion
