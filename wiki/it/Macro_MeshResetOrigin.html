Descrizione

Macro MeshResetOrigin è una macro che consolida le trasformazioni della mesh reimpostando l'origine di ciascuna mesh selezionata sull'origine del documento (origine globale), senza spostare la geometria. È pensata per essere utilizzata dopo un'operazione di allineamento (ad es. Modifica → Allinea a… sugli oggetti Mesh), per incorporare l'allineamento ottenuto direttamente nelle coordinate della mesh, anziché mantenerlo come offset di Posizionamento o dipendere da un contenitore genitore.

Ogni Mesh::Feature selezionata viene elaborata come segue:

  1. Legge la sua posizione attuale (la trasformazione che la posiziona nello spazio).
  2. Applica la matrice di posizionamento a una copia della mesh, in modo che ogni vertice si sposti nella posizione che occupa attualmente nello spazio.
  3. Riassegna la mesh trasformata e reimposta la proprietà Posizionamento su identità (0,0,0 / 0°).

La mesh non si sposta sullo schermo; semplicemente la sua origine ora coincide con l'origine globale, dato che la trasformazione è incorporata nella geometria della mesh anziché nella proprietà Placement. L'intera operazione è racchiusa in un'unica transazione di annullamento, pertanto un singolo comando Annulla ripristina la situazione precedente.

Gli oggetti che non sono mesh e le mesh contenute in un contenitore genitore (ad es. App::Part) vengono ignorati, con la visualizzazione di un avviso nella Vista Report. Le mesh che si trovano già nell'origine rimangono invariate.

Posizione

Ambiente Mesh (macro esterna/opzionale).

Utilizzo

  1. Selezionare uno o più oggetti Mesh nella vista ad albero o nella vista 3D.
  2. Eseguire la macro.
  3. L'origine di ogni mesh viene reimpostata sull'origine globale; la geometria non si sposta.
  4. Controllare la vista Report per visualizzare il riepilogo per ogni mesh (reimpostata / già all'origine / saltata).

Se una mesh si trova all'interno di un App::Part, trascinarla fuori dal contenitore prima di eseguire la macro.

Esempio

Un flusso di lavoro tipico consiste nell'allineare la mesh di una scansione 3D agli assi globali per facilitarne la lavorazione:

  1. Import a 3D scan mesh.
  2. Create (or reuse) a reference geometry to align the mesh on, for example a plane.
  3. Select both the reference object and the mesh, then go to Edit → Align To….
  4. Pick at least 3 points on the face of the mesh to flatten, then at least 3 points on the reference face to align with, then click Align.
  5. The mesh is now aligned, but the Placement/transform is no longer trivial to work with.
  6. Run MeshResetOrigin on the mesh: it does not move, but its origin is now aligned with the world.
  7. Iterate as needed to refine the alignment — particularly useful when working with 3D-scan meshes or 3D-printer STL files.

A step-by-step illustrated walkthrough is available on the GitHub repository.

Note

  • Requires FreeCAD 1.1.1 or newer (not tested on earlier versions).
  • Meshes with a parent App::Part container are skipped; remove them from the container first.
