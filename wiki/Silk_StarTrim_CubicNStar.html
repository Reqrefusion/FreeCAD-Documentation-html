Description

The Silk StarTrim_CubicNStar command creates a StarTrim_CubicNStar object from a CubicNStarSurface_NStar66 object.

Usage

  1. Select a CubicNStarSurface_NStar66
  2. There are several ways to invoke the command.
    • Press the StarTrim_CubicNStar button.
    • Select the Silk → StarTrim_CubicNStar option from the menu.
  3. A StarTrim_CubicNStar object, is created.

Properties

See also: Property View.
