Description

The Silk ControlGrid64_Surf44 command creates a ControlGrid64 from a CubicSurface_44.

A CubicSurface_44 and its underlying ControlGrid44 → The same CubicSurface_44 and the resulting dependent ControlGrid64

Usage

  1. Select a CubicSurface_44
  2. There are several ways to invoke the command.
    • Press the ControlGrid64_Surf44 button.
    • Select the Silk → ControlGrid64_Surf44 option from the menu.
  3. A ControlGrid64_Surf44 object, is created.

Properties

See also: Property View.

A ControlGrid64_Surf44 is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional property:

Data

ControlGrid64_Surf44

  • DataInput_Surf44 (Link): Reference 4X4 Surface.
  • Datadirection_to_raise (String): Default is v. parameter direction to raise (u or v).

ControlGrid64_normal

  • DataLegs (Part::PropertyGeometryList): Control segments.
  • DataPoles (VectorList): Poles.
  • DataWeights (FloatList): Weights.
