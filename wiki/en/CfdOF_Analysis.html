Description

The CfdOF Analysis command creates an Analysis container to hold all objects of a Computational Fluid Dynamic Analysis. This container is mandatory. A document can contain multiple Analysis containers.

Usage

  1. There are several ways to invoke the command:
    • Press the Analysis container‏‎ button.
    • Select the CfdOF → Analysis container‏‎ option from the menu.
    • Use the keyboard shortcut: N then C.
  2. A CfdAnalysis container is created and set to active.
  3. The following objects are automatically created inside the container:
    • PhysicsModel
    • FluidProperties
    • InitialiseFields
    • CfdSolver
  4. Several commands can add objects to the container.

Notes

  • An Analysis container can be activated by double-clicking it in the Tree View.
