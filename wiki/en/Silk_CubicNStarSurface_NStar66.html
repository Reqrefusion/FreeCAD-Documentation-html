Description

The Silk CubicNStarSurface_NStar66 command creates a blended multi corner surface, a CubicNStarSurface_NStar66 object, from a blended multi corner grid.

The finished N-star surface filling a multi-sided corner


An N6 blended corner grid → Resulting N6 blended corner surface

Usage

  1. Select a blended multi corner grid.
  2. There are several ways to invoke the command.
    • Press the CubicNStarSurface_NStar66 button.
    • Select the Silk → CubicNStarSurface_NStar66 option from the menu.
  3. A blended multi corner surface, a CubicNStarSurface_NStar66 object, is created.

Notes

  • This tool is intended to fill a corner gap surrounded by several blended edge surfaces.
  • If eliminating pinching in poor corner geometry is required, the Silk_StarTrim CubicNStar tool may be helpful.

Properties

See also: Property View.

A blended multi corner surface, a CubicNStarSurface_NStar66 object is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional property:

Data

CubicNStarSurface_NStar66

  • DataNStarGrid (Link): Control grid star.
  • DataNSurf (Part::PropertyGeometryList): N Cubic Surfaces.
