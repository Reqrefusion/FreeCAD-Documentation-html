Description

The Silk ControlGrid44_Rotate command creates a 4x4 rotate grid, a ControlGrid44 object, from 3 connected 4 point polygons.

A rotate grid merging three poly edges to a point

A loop of 3 connected 4 point polygons → Resulting 4x4 rotate grid

Usage

  1. Select a loop of 3 connected ControlPoly4 sequentially in counter-clockwise direction (looking from the "outer side" of the surface to be created) in the 3D View.
  2. There are several ways to invoke the command.
    • Press the ControlGrid44_Rotate button.
    • Select the Silk → ControlGrid44_Rotate option from the menu.
  3. A 4x4 rotate grid, a ControlGrid44_3_Rotate object, is created.

Notes

  • This tool produces a "triangle" surface that "rotates" from the first edge selected to the third, following along the second edge. Order is "left, bottom, right," with the rotational pivot at the "top" corner.
  • Typical use is to merge a set of surfaces to a point (such as closing a tube). Also used to interface with spheres and ellipsoids.
  • This is a degenerate grid (one edge collapsed to a point) that results in a "revolve"-like surface. Produces true spheres from arc polys, true ellipsoids from ellipse-arc polys, but also accepts non-arc polys.
  • Surface tangency across multiple grids can be achieved automatically from well-prepared arcs of circles and ellipses, but using general curves as input does not have an easily predictable outcome, and additional blending may be required.
  • Although degenerate, this grid is the correct way to interface with spheres, since it does not introduce additional collapsed edges — in this particular case, the NURBS degeneracy is not a flaw at all, but a standard CAD construct.
  • A four-sided version able to create true tori (and sphere strips) is planned, but not yet ready.

Properties

See also: Property View.

A 4x4 rotate grid, a ControlGrid44_3_Rotate object, is derived from a Part feature, or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional properties:

Data

C1 - Inputs

  • DataPoly0 (Link): First control polygon.
  • DataPoly1 (Link): Second control polygon.
  • DataPoly2 (Link): Third control polygon.
  • Datareverse (Bool): Default is False. Reverses the parameter direction.
  • Datatolerance (Float): Default is 1e-06. Point-to-point connection tolerance for the 3 corners.

C2 - Outputs

  • DataLegs (Part::PropertyGeometryList): Control segments.
  • DataPoles (VectorList): Poles.
  • DataWeights (FloatList): Weights.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is ControlGrid44_3_Rotate. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
