Description

La commande Silk CubicCurve_6 permet de créer une courbe NURBS cubique, un objet CubicCurve_6, à partir d'un polygone de contrôle à 6 points.

Un CubicCurve_6 affichant un aperçu d'une courbe cubique.

Il est principalement destiné à fusionner des courbes de Bézier existantes ou des segments de courbe.

2 selected adjacent curve segments → Blend polygon → Resulting blend curve

Utilisation

  1. Sélectionnez un ControlPoly6
  2. Il existe plusieurs façons de lancer la commande.
    • Cliquez sur le bouton CubicCurve_6.
    • Sélectionnez l'option Silk → CubicCurve_6 du menu.
  3. Un objet CubicCurve_6 est créé.

Notes

  • A 6-control-point cubic NURBS curve. G2 continuous throughout; G3 continuous throughout except at two points along the curve, where it is G2 only.
  • The practical use of this curve is to preview blends on curves before doing the full work of blending surfaces.
  • This is currently an endpoint in the Silk design workflow.
  • The input ControlPoly6 can be used to build grids and surfaces; alternatively, this curve can be used with the rest of FreeCAD — extruded, revolved, etc. — if curve design is all that is needed from Silk.
