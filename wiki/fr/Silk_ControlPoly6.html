Description

La commande Silk ControlPoly6 crée un polygone de contrôle à 6 points, un objet ControlPoly6, et, en fonction des éléments d'entrée sélectionnés, un sous-type spécifique est automatiquement choisi pour extraire les informations requises à partir d'un ou deux esquisses, ou à partir d’un ou deux polygones de contrôle à 4 points.

Ce polygone est destiné à contrôler une courbe cubique (et quatre d'entre eux la grille de contrôle d’une surface cubique).

Un ControlPoly6 généré à partir d'une esquisse de ligne à six points.

Il est principalement destiné à fusionner des courbes de Bézier existantes ou des segments de courbe.

2 segments de courbe adjacents sélectionnés → Polygone de fusion obtenu → Courbe de fusion souhaitée

Utilisation

  1. Cet outil permet de créer différents objets dotés de propriétés et de modes de calcul propres, en fonction des éléments d'entrée sélectionnés :
    • Mode 5L : sélectionnez une esquisse dans l'arborescence ou dans la vue 3D contenant une polyligne composée de 5 segments de droite.
    • Mode 2N: sélectionnez deux esquisses de nœuds étendues dans l'arborescence ou dans la vue 3D, chacune contenant un cercle, une ligne droite partant du centre du cercle et une deuxième ligne partant de l'extrémité de la première ligne.
    • Mode FirstElement : sélectionnez une esquisse dans l'arborescence ou dans la vue 3D contenant une combinaison arbitraire de différentes lignes. Seul le premier arc détecté dans l'esquisse est pris en compte, ou la première ligne droite s'il n'y a pas d'arc dans l'esquisse.
    • Mode Bezier : sélectionnez un objet ControlPoly4 dans l’arborescence ou dans la vue 3D. Cela produit une correspondance exacte au format ControlPoly6.
    • Mode FilletBezier : sélectionnez deux objets ControlPoly4, reliés à une extrémité, dans l’arborescence ou dans la vue 3D. Cela produit un raccord G2.
  2. Il existe plusieurs façons de lancer la commande.
    • Appuyez sur le bouton ControlPoly6.
    • Sélectionnez l'option Silk → ControlPoly6 du menu.
  3. Selon le mode, l'un des objets suivants est créé :
    • ControlPoly6_5L.
    • ControlPoly6_2N.
    • ControlPoly6_FirstElement.
    • ControlPoly6_Bezier.
    • ControlPoly4_FilletBezier.
  4. Vous pouvez modifier les paramètres dans l'éditeur de propriétés.

Remarques

  • Les polygones de contrôle à 6 points sont des objets de saisie obligatoires pour plusieurs autres objets Silk :
    • L'un d'entre eux sert à créer une CubicCurve_6.
    • Quatre d'entre eux servent à créer un ControlGrid66.
    • 2 de ces polygones de contrôle, associés à 2 objets ControlPoly4, sont utilisés pour créer un ControlGrid64.
  • Ce polygone de contrôle sert à générer des courbes et/ou des surfaces cubiques non Bézier (nombre de points de contrôle supérieur au degré + 1). Il ne garantit en interne que le G2. Son avantage réside dans le fait qu’il permet de contrôler la courbure aux points de jonction/arêtes avec des courbes/surfaces de Bézier cubiques, c’est pourquoi il est principalement destiné à l’interpolation de courbes/segments de courbes de Bézier existants.
    • Il s’agit ici d’une fusion de courbes de Bézier, le cas d’utilisation principal, qui offre un bon aperçu du fonctionnement de la fusion de grilles/surfaces. L’angle vif entre les deux courbes de Bézier disparaît, et le début et la fin du polygone correspondent aux courbes d’origine jusqu’au niveau G2.
    • Si vous choisissez de créer manuellement des objets ControlPoly6, ControlGrid64 et ControlGrid66, il vous arrivera sans doute parfois de vous retrouver avec un ControlPoly4 ou un CubicCurve_4 à un endroit où un ControlPoly6 serait préférable. Silk peut toujours convertir un CubicCurve_4 en ControlPoly6 de manière exacte ; l'inverse n'est pas vrai. Toutes les courbes de Bézier ont un ControlPoly6 correspondant exactement, mais un ControlPoly6 aléatoire n’a généralement pas de courbe de Bézier correspondante.
    • Les courbes/surfaces cubiques à 6 points sont destinées à être générées automatiquement par d’autres outils, en raison de leurs propriétés de connexion G2. Même lorsqu’il est généré automatiquement, ce polygone n’est généralement pas recommandé pour une utilisation directe dans la construction de grilles/surfaces (bien que cela soit autorisé). Le seul cas d’utilisation véritablement utile, dans le cadre du flux de travail officiel, consiste à étudier un ensemble de courbes de Bézier et leurs transitions en 2D avant de construire les surfaces en 3D — ce qui est très utile, par exemple, sur le plan de symétrie d’une conception lorsqu’on ne sait pas encore avec certitude combien de courbes de Bézier et de transitions la conception nécessite.

Propriétés

Voir aussi : Éditeur de propriétés

Tous les objets ControlPoly6 sont dérivés de Part feature, ou plus précisément d’un objet Part::FeaturePython, et héritent de toutes ses propriétés. Ils possèdent également les propriétés supplémentaires communes suivantes :

Données

C1 - Inputs

  • DonnéesWeights (FloatList) : poids.
  • Donnéesreverse (Bool) : par défaut False. Inverse le paramètre direction.

C2 - Outputs

  • DonnéesLegs (Part::PropertyGeometryList) : segments de contrôle.
  • DonnéesPoles (VectorList) : pôles.

C3 - Identifiers

  • DonnéesinternalName (String) : nom interne permanent de cet objet dans FreeCAD.
  • Donnéesobject_version (String) : version de la classe de cet objet.


Un objet ControlPoly6_5L possède également les propriétés supplémentaires suivantes :

Données

C1 - Inputs

  • DonnéesSketch (Link) : esquisse de référence.
  • Donnéestolerance (Float) : par défaut 1e-06. Tolérance de connexion point à point pour les 5 lignes.

C3 - Identifiers

  • Donnéesobject_type (String) : par défaut ControlPoly6_5L. Classe de l'atelier utilisée pour créer cet objet.


Un objet ControlPoly6_2N possède également les propriétés supplémentaires suivantes :

Données

C1 - Inputs

  • DonnéesSketch0 (Link) : esquisse de référence.
  • DonnéesSketch1 (Link) : esquisse de référence.
  • Donnéestolerance (Float) : par défaut 1e-06. Tolérance de connexion point à point pour la ligne circulaire au niveau de chaque nœud.

C3 - Identifiers

  • Donnéesobject_type (String) : par défaut ControlPoly6_2N. Classe de l'atelier utilisée pour créer cet objet.
