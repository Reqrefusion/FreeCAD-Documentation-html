Description

The PartDesign CircularPattern tool duplicates selected features or the active body in concentric circular patterns.

Usage

  1. Optionally activate the correct Body.
  2. Optionally select one or more features in the Tree View or the 3D View.
  3. There are several ways to invoke the tool:
    • Press the Circular Pattern button.
    • Select the Part Design → Transformation Features → Circular Pattern option from the menu.
  4. If there is no active Body, and there are two or more Bodies in the document, the Active Body Required dialog will open and prompt you to activate one. If there is a single Body it will be activated automatically.
  5. The Circular Pattern Parameters task panel opens. See Options for more information.
  6. Press the OK button to finish.
