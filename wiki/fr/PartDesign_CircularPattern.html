Description

L'outil PartDesign Répétition circulaire permet de dupliquer les fonctions sélectionnées ou le corps actif selon des répétitions circulaires concentriques. Cet outil permet de désactiver certains éléments de la répétition.

Élément de base rectangulaire existant avec une fonction additive de forme CP → Mode aperçu « Répétition circulaire » avec les éléments situés tout en bas désactivés (les symboles rouges x désactivent les éléments, les symboles verts + les réactivent) → Solide obtenu (une fonction CircularPattern)

Utilisation

  1. Vous pouvez activer le corps souhaité.
  2. Vous pouvez sélectionner une ou plusieurs entités dans l'arborescence ou la vue 3D.
  3. Il existe plusieurs façons de lancer l'outil :
    • Appuyez sur le bouton Répétition circulaire.
    • Sélectionnez l'option Part Design → Appliquer une transformation → Répétition circulaire du menu.
  4. S'il n'y a pas de corps actif et que le document contient au moins deux corps, la boîte de dialogue Corps actif requis s'ouvre et vous invite à en activer un. S'il n'y a qu'un seul corps, celui-ci est activé automatiquement.
  5. Le panneau des tâches Paramètres de la répétition circulaire s'ouvre. Voir Options pour plus d'informations.
  6. Cliquez sur le bouton OK pour terminer.

Propriétés

Données

Base

  • DonnéesOriginals (LinkList) : liste des fonctions sélectionnéees. Elle sera ignorée si la propriété DonnéesTransform Mode est définie sur Whole shape.
  • DonnéesTransform Mode (Enumeration) :
  • : Features (par défaut)
  • : Whole shape.

CircularPattern

  • DonnéesAxis (LinkSub): The axis and center of the circular pattern..
  • DonnéesRadial Distance (Length): Default is 50.0 mm. Distance between consecutive concentric circles.
  • DonnéesTangential Distance (Length): Default is 25.0 mm. Approximate distance between consecutive elements on the same circle.
  • DonnéesNumber Circles (IntegerConstraint): Default is 3. Number of concentric circles, including the original element.
  • DonnéesSymmetry (IntegerConstraint): Default is 1. Number of symmetry divisions used to round each circle's element count.

Part Design

  • DonnéesRefine (Bool): Default is True. Refine shape (clean up redundant edges) after operations.
  • DonnéesFuzzy Tolerance (FloatConstraint): Default is -1.0. Fuzzy tolerance:
    If value > 0: use the value
    If value = 0: leave default value
    If value < 0: determine value

Transformation

  • DonnéesSuppressed Indices (IntegerList): Indices of pattern instances that are suppressed.
