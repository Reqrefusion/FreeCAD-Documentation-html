Atelier CfdOF

Plateformes prises en charge

Linux

Tout système sur lequel il est possible d'installer FreeCAD et les prérequis énumérés ci-dessous.

Windows

Windows 7 à 11 ; la version 64 bits est requise.

macOS

Cette méthode n'a pas fait l'objet de nombreux tests, mais des cas de réussite ont été signalés. Voir ce message sur le forum pour obtenir des instructions.

Prérequis

L'atelier CfdOF nécessite les logiciels externes suivants, dont certains peuvent être installés automatiquement (voir ci-dessous pour les instructions).

  1. Dernière version stable de FreeCAD (au moins la version 0.20.0 / commit Git 29177) ou dernière version de développement (pré-lancement).
  2. OpenFOAM Foundation versions 9-10 ou ESI-OpenCFD versions 2006-2306.
  3. Paraview.
  4. cfMesh (version personnalisée mise à jour pour se compiler avec les dernières versions d'OpenFOAM).
  5. HiSA (High Speed Aerodynamic Solver).
  6. Gmsh (version 2.13 ou ultérieure) - facultatif, pour la génération de maillages tétraédriques.

Configuration de l'atelier CfdOF

Windows

Les dernières versions (version stable) ou (version de développement) de FreeCAD peuvent être obtenues et installées respectivement en exécutant le programme d'installation ou en extrayant l'archive .7z dans un répertoire <FreeCAD-directory>. Dans ce dernier cas, FreeCAD peut être lancé directement depuis cet emplacement (<FreeCAD-directory>\bin\FreeCAD.exe).

CfdOF s'installe dans FreeCAD via le gestionnaire des extensions :

  • Lancez FreeCAD
  • Sélectionnez Outils | Gestionnaire des extensions...
  • Sélectionnez CfdOF dans la liste des environnements de travail, puis cliquez sur « Installer/mettre à jour »
  • Redémarrez FreeCAD
  • Pour l'installation des dépendances, voir ci-dessous

Remarque : l'atelier CfdOF peut être mis à jour à tout moment via le gestionnaire des extensions.

Installation des dépendances

Les dépendances peuvent être vérifiées et installées facilement depuis le panneau « Préférences » de CfdOF dans FreeCAD. Dans la fenêtre FreeCAD, sélectionnez Édition → Préférences puis choisissez « CfdOF ». Les dépendances peuvent être installées en tant que composants individuels ou dans le cadre d’un conteneur Docker (voir la section Installation de conteneurs Docker ci-dessous).

L'installation d'OpenFOAM s'effectue via le package OpenCFD MinGW, et le portage d'OpenFOAM appelé BlueCFD Core est également pris en charge.

OpenFOAM peut être installé manuellement à l'aide des liens ci-dessus, ou en cliquant sur le bouton correspondant dans le panneau « Préférences » décrit plus haut. Si vous rencontrez des problèmes lors de l'exécution d'OpenFOAM dans CfdOF, assurez vous que l'installation fonctionne correctement en suivant les instructions fournies sur les sites Web concernés.

Pour fonctionner correctement avec l'installation d'OpenFOAM, CfdOF doit pouvoir écrire dans son répertoire d'installation. Certains utilisateurs rencontrent des problèmes lorsqu'ils utilisent un emplacement situé dans le répertoire C:\Program Files en raison des restrictions imposées par le Contrôle de compte d'utilisateur de Windows. Il est donc recommandé de procéder à l'installation dans un autre emplacement, de préférence dans votre répertoire personnel.

Si OpenFOAM est installé avec des droits d'administrateur à l'aide des paquets mentionnés ci-dessus, Microsoft MPI sera également installé (en option). Dans le cas contraire, il faudra le télécharger et l'installer manuellement à partir de la page de téléchargement de Microsoft MPI. MPI est nécessaire pour exécuter des calculs en parallèle.

Dans le panneau des préférences, définissez le répertoire d'installation d'OpenFOAM sur le répertoire d'installation se terminant par le sous-dossier « vXXXX » (où XXXX correspond au numéro de version installée) pour le package MinGW, ou sur le répertoire d'installation de BlueCFD. Il sera automatiquement détecté dans les emplacements d'installation par défaut.

Vous pouvez installer n'importe quelle version de ParaView en suivant le lien ci-dessus ou en cliquant sur le bouton correspondant dans le panneau « Préférences ». Dans le panneau « Préférences », indiquez comme chemin d'installation de ParaView le fichier « paraview.exe » situé dans le sous-dossier « bin » de l'installation de ParaView. Si ce champ est laissé vide, les paramètres par défaut seront détectés.

De même, cfMesh et HiSA peuvent être installés à partir du panneau « Préférences ». Ne le fermez pas avant que le message « Install completed » ne s'affiche. Notez que l'installation d'OpenFOAM doit se trouver dans un répertoire accessible en écriture pour que l'installation de cfMesh et HiSA puisse s'effectuer correctement.

En sélectionnant l'option « Check dependencies », vous vous assurez que tous les prérequis ont bien été installés.

Linux

Les fichiers AppImages des dernières versions (version stable) ou (version de développement) de FreeCAD peuvent être téléchargés et exécutés directement, sans installation. Notez que vous devrez activer les droits d'exécution sur le fichier téléchargé pour pouvoir l'exécuter. Sinon, FreeCAD peut être compilé à partir du code source disponible sur la page GitHub de FreeCAD.

Remarque :

  • Les installations de FreeCAD via les gestionnaires de paquets Linux utilisent votre installation locale de Python. Vous devrez donc peut-être installer des paquets Python supplémentaires pour bénéficier de toutes les fonctionnalités. L'outil de vérification des dépendances (voir ci-dessous) peut vous aider à diagnostiquer ce problème.
  • Notez que le conteneur « Snap » installé via les gestionnaires de paquets de certaines distributions peut poser problème, car il ne permet pas d'accéder aux répertoires système ; OpenFOAM doit donc être installé dans le répertoire personnel de l'utilisateur pour pouvoir être exécuté depuis FreeCAD.

Pour les raisons évoquées ci-dessus, nous recommandons l'AppImage comme option d'installation la plus fiable sous Linux.

CfdOF s'installe dans FreeCAD via le gestionnaire des extensions :

  • Lancez FreeCAD
  • Sélectionnez Outils → Gestionnaire des extensions
  • Sélectionnez CfdOF dans la liste des environnements de travail, puis cliquez sur « Installer/mettre à jour »
  • Redémarrez FreeCAD
  • Pour l'installation des dépendances, voir ci-dessous

Remarque : l'atelier CfdOF peut être mis à jour à tout moment via le gestionnaire des extensions.

Installation des dépendances

Il est possible de vérifier les dépendances et d'en installer certaines très facilement depuis le panneau « Préférences CFD » de FreeCAD. Dans la fenêtre FreeCAD, sélectionnez Édition → Préférences puis choisissez « CfdOF ».

Les dépendances peuvent être installées manuellement ou dans le cadre d'un conteneur Docker (voir Installation de conteneurs Docker ci-dessous). L'installation manuelle peut être effectuée pour OpenFOAM (versions OpenCFD ou Foundation), ParaView et Gmsh (facultatif) à l'aide des liens ci-dessus ou du gestionnaire de paquets de votre distribution. Notez toutefois que les paquets OpenFOAM fournis avec certaines distributions Linux peuvent être obsolètes ou incomplets ; par exemple, les paquets standard de Debian et d’Ubuntu n’incluent pas la commande de compilation « wmake » et ne peuvent donc pas être utilisés avec les composants optionnels « HiSA » et « cfMesh ». Nous recommandons donc d’installer les paquets fournis via les sites web officiels mentionnés ci-dessus. Veillez à installer le paquet « de développement » lorsqu'il est disponible (généralement désigné par le suffixe « -devel » ou « -dev ») afin de vous assurer que les composants optionnels « HiSA » et « cfMesh » puissent être compilés avec « wmake ».

Définissez le répertoire d'installation d'OpenFOAM dans le panneau des préférences. Voici quelques exemples d'emplacements d'installation courants : /usr/lib/openfoam/openfoam2306, /opt/openfoam10 ou /home/user/OpenFOAM/OpenFOAM-10.x (il sera automatiquement détecté dans les emplacements d'installation par défaut courants). Notez que si vous avez déjà chargé l'environnement OpenFOAM souhaité avant de démarrer FreeCAD, le champ du répertoire d'installation doit être laissé vide.

cfMesh et HiSA peuvent être installés à l'aide du panneau « Préférences » décrit ci-dessus. Vous pouvez également les télécharger et les compiler à partir de leur code source dans votre installation OpenFOAM si vous ne l'avez pas déjà fait vous-même. Notez que cette opération peut prendre un certain temps.

En sélectionnant l'option « Check dependencies », vous vous assurez que tous les prérequis ont bien été installés.

Installation de conteneurs Docker

Les conteneurs Docker constituent un moyen pratique de fournir des paquets de programmes précompilés pour Windows et Linux. macOS est également pris en charge, mais vous aurez besoin d'aide pour configurer un conteneur. Laissez un message sur le forum.

Docker sous Windows

L'environnement d'exécution Docker recommandé pour Windows est Podman, car il offre actuellement une intégration rapide du système de fichiers. Docker Desktop peut également être utilisé.

  1. Installez podman (ou Docker Desktop).
  2. Si vous utilisez Podman, ouvrez une fenêtre d'invite de commandes et exécutez les commandes suivantes :
    • podman machine init
    • podman machine start
    • podman machine set --rootful
  3. Édition → Préférences → CfdOF : cliquez sur le bouton « Installer Paraview ».
  4. Édition → Préférences → CfdOF : sélectionnez « Utiliser Docker ».
  5. Cliquez sur le bouton « Installer le conteneur Docker ». Il n’est pas nécessaire d’installer gmsh, cfmesh et HISA, car ils sont inclus dans l’image Docker.
    • Si vous utilisez Podman, vous pouvez activer l’intégration rapide du système de fichiers WSL :
    • Créez un nouveau sous-répertoire (par exemple cfdof) dans le répertoire suivant créé par Podman : \\wsl$\podman-machine-default\home\user
    • Dans la page des préférences de cfdof, définissez le répertoire de sortie par défaut comme ci-dessus : \\wsl$\podman-machine-default\home\user\cfdof
  6. Cliquez sur le bouton « Exécuter le vérificateur de dépendances ».

Docker sous Linux

  1. Install docker using these instructions (or similar).
  2. Install paraview as per the package installation instructions for your distribution (for example sudo apt-get install paraview on debian).
  3. Edit → Preferences → CfdOF: Select Use docker.
  4. Press the Install Docker Container button. There is no need to install gmsh, cfmesh and HISA as they are included in the docker image.
  5. Press the Run dependency checker button.
