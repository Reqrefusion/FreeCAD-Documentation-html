Description

La commande CfdOF Maillage à partir d'une forme crée un objet contenant les données nécessaires à la génération d'un maillage à partir d'une géométrie. Ces données peuvent être modifiées dans un panneau de tâches.

Utilisation

Créer un objet de données d'un maillage

  1. Si nécessaire : activez le conteneur d'analyse approprié en double-cliquant dessus dans l'arborescence.
  2. Sélectionnez la géométrie à mailler.
  3. Il existe plusieurs façons de lancer la commande :
    • Cliquez sur le bouton CFD mesh.
    • Sélectionnez l'option CfdOF → CFD mesh du menu.
  4. Un objet de données [GeometryName]_Mesh est ajouté au conteneur.
  5. Le panneau des tâches s'ouvre. Voir Options pour plus d'informations.
  6. Cliquez sur le bouton Fermer pour terminer la commande.

Modifier un objet de données d'un maillage

  1. Procédez de l'une des manières suivantes :
    • Suivez les étapes 1 et 3 décrites ci-dessus.
    • Double-cliquez sur un objet de données [GeometryName]_Mesh dans l'arborescence.
  2. Le panneau de tâches s'ouvre. Voir Options pour plus d'informations.
  3. Appuyez sur le bouton Fermer pour terminer la commande.

Options

Le panneau des tâches propose les paramètres suivants :

Paramètres du maillage

La liste déroulante Mesh Utility propose les options suivantes :

  • cfMesh
cfMesh est une bibliothèque open source et extensible destinée à la génération automatique de maillages. cfMesh prend en charge les maillages 3D et 2D et permet de générer :
  • des maillages 3D à prédominance hexagonale
  • des maillages 2D à prédominance quadrangulaire
  • des maillages 3D à dominance tétraédrique
  • des maillages 3D à dominance polyédrique
  • gmsh (tetrahedral)
  • gmsh (polyhedral)
Gmsh est un générateur de maillages d'éléments finis 3D open source.
  • snappyHexMesh
snappyHexMesh est un logiciel de maillage hexagonal à division automatique qui densifie le maillage et s'aligne sur la surface. Il génère des maillages 3D contenant des hexaèdres et des hexaèdres divisés à partir d'une géométrie de surface triangulée au format STL (Stereolithography). snappyHexMesh est utilisé pour les géométries complexes.

Champ de saisie Base element size

Le maillage de base, ou maillage d'arrière-plan, est le maillage initial, sans densification. Si cette valeur est laissée à 0, elle sera définie par défaut à 2 % de la longueur caractéristique du parallélépipède englobant. Par exemple, un cube de 10 mm de côté aura les caractéristiques suivantes pour son parallélépipède englobant : (102 + 102 + 102)0.5 dont 2 % correspondent à 0,35 mm.

Paramètres de snappyHexMesh

Les paramètres suivants ne sont disponibles que lorsque l'utilitaire de maillage snappyHexMesh a été sélectionné.

Point in mesh

Saisissez un vecteur de position à l'intérieur de la région à mailler, sous la forme x, y, z. Cela permet de déterminer si la géométrie doit être maillée à l'extérieur, comme dans le cas d'un fluide s'écoulant sur un tuyau, ou à l'intérieur, comme dans le cas d'un fluide s'écoulant à l'intérieur d'un tuyau. Le bouton Rechercher tentera de localiser une position dans la région à mailler.

No. of cells between levels & Relative edge refinement

La taille de l'élément de basea déjà été définie ci-dessus. La densification volume ou de la surface s'effectue en divisant les cellules de base en 4 quadrilatères pour les modèles 2D ou en 8 hexagones pour les modèles 3D. La figure ci-dessous montre la cellule de base divisée en 4 quadrilatères lors de la première division (n = 1), puis chaque nouvelle cellule divisée à nouveau en 4 quadrilatères lors de la deuxième division (n = 2).
Le champ de saisie Relative edge refinement accepte des valeurs comprises entre 0.001 et 1. Il définit la taille du maillage par rapport au maillage de base initial. La division peut être calculée par 1/(2^n-1). Par exemple, pour n = 2, la valeur de densification relative des arêtes est de 0.5.
Pour obtenir une transition fluide entre les mailles divisées, veillez à ce qu'il y ait un certain nombre de mailles entre deux niveaux de densification consécutifs. Le champ de saisie No. of cells between levels accepte des valeurs entières supérieures ou égales à 1, la valeur par défaut étant 3.

Edge detection

  • Implicit snaps to automatically detected surface geometric feature edges.
  • Explicit snaps to manually generated feature edges.

Meshing

Write mesh case button

Clicking on the Write mesh case creates the mesh files with the progress being displayed in the Status box.

Edit button

The Edit button opens the directory where the OpenFOAM case files are stored, including the mesh files, generated above, in the constant directory. For more information about these files and directories please visit the UNDER THE HOOD PAGE.

Run mesher button

Clicking on the Run mesher button starts the selected mesher process, with the progress being displayed in the Status box.

Stop button

Used to stop either the Write mesh case or Run mesher processes.

Visualisation

Paraview button

ParaView is an open-source, multi-platform data analysis and visualization application. Clicking on the Paraview button opens the mesher, to allow the mesh to be inspected.

Check Mesh button

Clicking on the Check Mesh button runs the OpenFOAM checkMesh utility. This checks the validity of a mesh and outputs it’s result in the reports view area in FreeCAD. It’s possible to enlarge this box, by dragging the top of the reports panel up the screen.

Load surface mesh button

Clicking on Load surface mesh displays the mesh on the geometry within FreeCad. It only the displays the mesh on the surface of the geometry and not the internals. For a more detailed inspection of the mesh use ParaView.
Warning! If the message in the Status reads:
"Triangulated representation of the surface mesh is shown - Please use Paraview for full mesh visualisation."
The Load surface mesh image displayed is not fully representative of the mesh and you should view the mesh in ParaView.

Clear button

The Clear button removes the mesh on the geometry within FreeCad.

Status output box

When clicking Write mesh case or Run mesher, the progress is displayed in the Status output box, together with any error messages.
  • When Write mesh case has finished, the last message in the Status output box will be 'Mesh case written successfully'.
  • When Run mesher has finished, the last message in the Status output box will be 'Meshing completed'.
