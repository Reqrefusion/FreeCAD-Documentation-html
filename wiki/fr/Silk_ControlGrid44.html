Description

La commande Silk ControlGrid44 crée un ControlGrid44 à partir de quatre arêtes ControlPoly4 reliées entre elles.

Un ControlGrid44 constitué de quatre arêtes ControlPoly4

Quatre arêtes de ControlPoly4 reliées → ControlGrid44 obtenu

Utilisation

  1. Présélectionnez 4 arêtes connectées ControlPoly4 dans la vue 3D.
  2. Il existe plusieurs façons de lancer la commande.
    • Appuyez sur le bouton ControlGrid44.
    • Sélectionnez l'option Silk → ControlGrid44 du menu.
  3. Un objet ControlGrid44_4 est créé.

Notes

  • Silk performs its first useful task beyond using existing FreeCAD functions and forcing a particular input format: it generates the inner control points of the grid based on the polys. This is not the only way to generate the inner control points, but it is a solid default starting point. The user provides 12 points through the polys, and Silk provides 4 more. 4 out of 12 doesn't seem like much, but it snowballs from here — the rest of the tools will generate tens and hundreds of useful control points with less and less input required from the user at each step.

Tangency Rules

  • If adjacent CubicSurface_44 objects are not going to be segmented and blended, their ControlGrid44 objects must follow strict rules to achieve tangency (G1) across the shared edge (picture two grids/surfaces side by side, left and right):
    • There must be a shared edge (G0) in the middle — the entire edge. This is done by selecting the same poly for that edge in both grid creations. Do not trace, approximate, copy, or link the poly — use the same object in both grid creations.
    • The legs of the polys that meet on the shared edge must be collinear (aligned/parallel).
    • The ratio of the lengths of the poly legs that meet on the shared edge must be equal. For example, if the top poly on the left grid has a last leg of length 3, meeting a leg of length 1 on the top of the right grid, the tangency ratio is 3:1 from left to right. If the bottom poly on the left grid then has a last leg of length 5, the connecting poly on the right grid must have a first leg of length 2 (keeping the 3:1 ratio). This ratio rule does not apply if all poly legs are parallel across the shared edge.
    • Users do not need to do anything beyond preparing the polys correctly — if the polys follow these rules, the generated adjacent grids will always be G1, since Silk calculates all of the surface's internal control points (the ones not on edges).
  • Following tangency rules (G1) forces changes to the polys, which changes the entire surface. When a surface should not be modified, it is blended instead of aligned. G1 alignment is useful for patching small holes, or for connecting to planes, cylinders, and spheres.

Optional — flawed, use with caution

  • Selecting 3 connected ControlPoly4 edges produces a "triangle" grid, which yields a lower-quality surface. The "triangle" has a degenerate (collapsed) edge between the first and third selected polys, because internally this grid still has as many points and lines as a four-sided grid; the collapsed lines and points cause visible defects in the surface, and make further operations with this grid (or surfaces built from it) difficult or even impossible. This "triangle" does respect tangency rules and will connect cleanly to other grids despite its inner flaw. In fact, conforming to G1 on the edges makes it particularly flawed and ugly on the inside. Removing this option is being considered, but it remains for now, since some users want it despite the warnings.

Propriétés

Voir aussi : Éditeur de propriétés

ControlGrid44_4 est dérivé de Part feature, ou plus précisément d’un objet Part::FeaturePython, et hérite de toutes ses propriétés. Il possède également les propriétés supplémentaires communes suivantes :

Données

C1 - Inputs

  • DonnéesPoly0 (Link) : premier polygone de contrôle.
  • DonnéesPoly1 (Link) : deuxième polygone de contrôle.
  • DonnéesPoly2 (Link) : troisième polygone de contrôle.
  • DonnéesPoly3 (Link) : quatrième polygone de contrôle.
  • Donnéesreverse (Bool) : par défaut False. Inverse le sens du paramètre.
  • Donnéestolerance (Float) : par défaut 1e-06. Tolérance de connexion point à point pour les 4 coins.

C2 - Outputs

  • DonnéesLegs (Part::PropertyGeometryList) : segments de contrôle.
  • DonnéesPoles (VectorList) : pôles.
  • DonnéesWeights (FloatList) : poids.

C3 - Identifiers

  • DonnéesinternalName (String) : nom interne permanent de cet objet dans FreeCAD.
  • Donnéesobject_type (String) : par défaut ControlGrid44_4. Classe de l'atelier utilisée pour créer cet objet.
  • Donnéesobject_version (String) : version de la classe de cet objet.
