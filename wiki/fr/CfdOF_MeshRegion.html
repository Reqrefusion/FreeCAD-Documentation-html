CfdOF Maillage à partir d'une forme

Description

La commande CfdOF Densification du maillage crée un objet contenant les données nécessaires pour ajouter des densifications de surface, de volume et d'extrusion à un maillage de référence. Ces données peuvent être modifiées dans un panneau de tâches.

Utilisation

Créer un objet de données de densification

  1. Sélectionnez un objet de données [GeometryName]_Mesh dans l'arborescence.
  2. Il existe plusieurs façons de lancer la commande :
    • Cliquez sur le bouton Mesh‏‎ refinement.
    • Sélectionnez l'option CfdOF → Mesh‏‎ refinement du menu.
  3. Un objet de données MeshRefinement est ajouté à l'objet de données [GeometryName]_Mesh.
  4. Le panneau des tâches s'ouvre. Voir Options pour plus d'informations.
  5. Cliquez sur le bouton OK pour confirmer et terminer la commande.
  6. Vous pouvez répéter la commande pour ajouter d'autres objets de données de raffinement à l'objet de données [GeometryName]_Mesh.

Modifier un objet de données de densification

  1. Double-cliquez sur un objet de données MeshRefinement dans l'arborescence.
  2. Le panneau de tâches s'ouvre. Consultez la section Options pour plus d'informations.
  3. Cliquez sur le bouton OK pour confirmer et terminer la commande.

Options

Le panneau des tâches propose les paramètres suivants :

Surface Refinement

Volume Refinement

Extrusion
