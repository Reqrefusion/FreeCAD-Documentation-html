FreeCAD 27.1 est en cours de développement, il n'y a pas encore de date de sortie prévue.

Il manque des fonctions ? Signalez-les dans le fil de discussion du forum Release notes for v27.1.
Consultez l'aide de FreeCAD pour savoir comment contribuer à FreeCAD.

Toutes les images de cette page doivent utiliser le suffixe _relnotes_27.1
