Description

La commande Silk ControlPoly4 segmentcrée un polygone à 4 sommets, un objet ControlPoly4_segment, pour un segment de courbe d'une courbe primaire entre deux points situés sur la courbe.

ControlPoly4 segmentés

Courbe principale → Points sur la courbe ajoutés → Polygones à 3 segments entre les points

Utilisation

  1. Présélection dans l'arborescence :
    1. Une courbe ControlPoly4.
    2. Le premier point sur la courbe.
    3. Le deuxième point sur la courbe.
  2. Il existe plusieurs façons de lancer l'outil.
    • Appuyez sur le bouton ControlPoly4_segment.
    • Sélectionnez l'option Silk → ControlPoly4_segment du menu.
  3. Un objet ControlPoly4_segment est créé.

Notes

  • Segmenting (sectioning, cutting) is a core Silk modeling technique, essential for blending. The current workflow uses curve segments as references to cut surfaces. There are plans to cut surfaces by drawing points directly on them, but since the same result is already achievable using curve segments, this convenience is a medium priority.
  • Why so much segmenting in Silk — segmenting curves, then segmenting surfaces, so much time spent aligning segmentation points? Because building off segments/pieces of a single Bezier curve or surface preserves "relatedness" between the parts. They blend well, and sections separated by gaps still feel like part of the same surface. This sense of connectedness is nearly impossible to achieve by trying to "harmonize" two curves or surfaces that were built separately and then merged. The key to blending in Silk is sharing edges between base surfaces (which are not otherwise aligned), and then blending strips of the surfaces near that shared edge. The shared edges and strips produce blends that look decent even before fine-tuning.

Propriétés

Voir aussi : Éditeur de propriétés

ControlPoly4_segment est dérivé de Part feature, ou plus précisément d’un objet Part::FeaturePython, et hérite de toutes ses propriétés. Il possède également les propriétés supplémentaires communes suivantes :

Données

C1 - Inputs

  • DonnéesNL_Curve (Link) : courbe de référence.
  • DonnéesPoint_onCurve_0 (Link) : point de départ du segment.
  • DonnéesPoint_onCurve_1 (Link) : point d'arrivée du segment.
  • Donnéesreverse (Bool) : par défaut False. Inverse le sens du paramètre.

C2 - Outputs

  • DonnéesLegs (Part::PropertyGeometryList) : segments de contrôle.
  • DonnéesPoles (VectorList) : pôles.
  • DonnéesWeights (FloatList) : poids.

C3 - Identifiers

  • DonnéesinternalName (String) : nom interne permanent de cet objet dans FreeCAD.
  • Donnéesobject_type (String) : par défaut ControlPoly4_segment. Classe de l'atelier utilisée pour créer cet objet.
  • Donnéesobject_version (String) : version de la classe de cet objet.
