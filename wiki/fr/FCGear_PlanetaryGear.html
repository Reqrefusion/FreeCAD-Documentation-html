Description

La commande FCGear Engrenage planétaire permet de calculer et de créer un ensemble d'engrenages planétaires. Un aperçu en temps réel aide à trouver les paramètres valides.

Aperçu en direct dans la vue 3D → Ensemble d'engrenages planétaires terminé (couleurs ajoutées pour plus de clarté)

Utilisation

  1. Il existe plusieurs façons de lancer la commande :
    • Cliquez sur le bouton Engrenage planétaire dans la barre d'outils.
    • Sélectionnez l'option Gear → Engrenage planétaire du menu.
  2. Le panneau de tâches Assemblage d'engrenages planétaires s'ouvre.
  3. Ajustez les paramètres et cliquez sur OK pour terminer la configuration et fermer le panneau de tâches.
  4. Un assemblage, un objet PlanetaryGear, est créé.
