Introduction

SVG est l'abréviation de « Scalable Vector Graphics », un format d'image vectoriel destiné aux graphiques en deux dimensions.

Les formats vectoriels tels que SVG sont très utiles dans les programmes de dessin technique, tels que FreeCAD, car une image SVG peut être redimensionnée à n’importe quelle taille sans perte de forme ou de la quantité des détails. Le fichier au format SVG peut être adapté à toute résolution requise et converti au format bitmap tel que PNG ou JPEG pour l’impression.

L'image SVG est décrite dans un langage de type XML, ce qui signifie que le fichier peut être ouvert et modifié avec un simple éditeur de texte pour y apporter des modifications. En raison de sa nature textuelle, le fichier peut également être recherché, indexé et facilement compressé. Ce langage de balisage SVG est un standard ouvert développé par le World Wide Web Consortium (W3C) depuis 1999. Cela signifie qu'un fichier SVG doit être lu et interprété de la même manière par les visualiseurs conformes et les applications de dessin.

Pour plus d'informations sur le format SVG, voir Scalable Vector Graphics.

Le format SVG dans FreeCAD

FreeCAD est avant tout un logiciel de modélisation 3D et ne dispose donc pas de nombreux outils de dessin 2D. En revanche, FreeCAD s'appuie sur des fichiers SVG :

  • Les icônes de l'interface graphique, qui représentent les outils dans les menus et les barres d'outils, ou les objets et les fonctions dans l'arborescence
  • Les modèles pour l'atelier TechDraw, représentant des feuilles de papier, qui définissent le format d'un dessin et permettent l'impression à l'échelle. Ils peuvent également fournir des cadres et un cartouche.
  • Les symboles, vues de TechDraw intégrant chacune un fichier SVG unique, afin de fournir des éléments d'annotation graphique fréquemment utilisés.

De plus, FreeCAD permet d'importer des fichiers SVG dans l'espace 3D :

  • Sous la forme d'un plan d'image pouvant être positionné à l'aide de sa propriété « Placement ».
  • Sous la forme de figures 2D distinctes sur le plan XY, pouvant servir de géométrie de base pour la suite de la modélisation.

FreeCAD dispose enfin d'outils permettant d'exporter au format SVG :

  • La géométrie 3D peut être enregistrée au format Flattened SVG. Dans ce cas, la géométrie sélectionnée est projetée sur le plan XY et seules les coordonnées X et Y sont utilisées pour générer les éléments SVG.
  • TechDraw propose un outil permettant d'enregistrer le dessin en cours.

Std Importer et Std Exporter gèrent les tâches d'importation et d'exportation 3D liées au format SVG ; elles utilisent la fonction Draft SVG du module Draft pour convertir la géométrie 3D depuis et vers le format SVG.

Utilisation

Here we have additional descriptions focussed on SVG files for Std Import and Std Export.

3D Import

  1. Make there is an activate document.
  2. Select the File → Import... option from the menu.
  3. In the file browser that appears do one of the following:
    • With the default settings unchanged:
      1. Select a file and press the Open button.
      2. The Select Module dialog appears. From Open svg as select:
        • Image formats (FreeCAD) to import the SVG file as an image plane.
        • SVG as geometry (importSVG) to import the SVG file as separate shapes.
      3. Press the Open button to close the dialog and finish the tool.
    • Optionally select the SVG as geometry filter option.
    1. Select the desired SVG file and press the Open button to finish the tool.
  4. Depending on the selected options an image plane or several shape and text objects are added to the document.

3D Export

Select one or more shapes.

  1. Select the File → Export... option from the menu.
  2. In the file browser that appears select the Flattened SVG filter option.
  3. Enter a filename.
  4. Select a folder to save the SVG file.
  5. Press the Save button to close the browser and finish the tool.

2D Import and Export

The descriptions of the 2D tools are well focussed on SVG files so that linking the relevant pages is sufficient here.

  • Templates are SVG files required to define drawing sheets (Page objects) in TechDraw.
    • New Page imports the default SVG template file.
    • New Page From Template opens a file browser to select and import an SVG template file.
  • A symbol is a kind of TechDraw view used to add an SVG image for graphical annotation purposes to a TechDraw Page and optionally connect it with another TechDraw feature as its owner.
    • Insert SVG opens a file browser to select and import an SVG symbol file.
  • Optionally, when a drawing is finished the page can be exported as an SVG file.
    • Export Page as SVG
