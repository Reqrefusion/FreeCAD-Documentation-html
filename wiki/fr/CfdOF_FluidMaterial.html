Description

La commande CfdOF Propriétés des fluides ouvre un panneau de tâches permettant de modifier un objet « Fluid Properties ». Cet objet contient les propriétés d’un fluide utilisé dans une simulation. Celles-ci peuvent être saisies manuellement ou sélectionnées dans une bibliothèque de fluides. Un objet « Fluid Properties » est automatiquement ajouté lors de la création d'un conteneur d'analyse. Dans le cas d'un modèle physique multiphase, des fluides supplémentaires peuvent être définis en ajoutant d'autres objets « Fluid Properties ».

Utilisation

Créer un objet de données fluide supplémentaire (multiphase)

  1. Si nécessaire : activez le conteneur d'analyse approprié en double-cliquant dessus dans la vue arborescente.
  2. Assurez-vous que la propriété DonnéesPhase du modèle physique dans le conteneur est définie sur FreeSurface.
  3. Il existe plusieurs façons de lancer la commande :
    • Appuyez sur le bouton Add fluid properties.
    • Sélectionnez l'option CfdOF → Add fluid properties du menu.
  4. Un objet de données FluidProperties est ajouté au conteneur.
  5. Le panneau des tâches s'ouvre. Voir Options pour plus d'informations.
  6. Cliquez sur le bouton OK pour confirmer et terminer la commande.

Modifier un objet de données d'un fluide

  1. Procédez de l'une des manières suivantes :
    • Pour la simulation monophasique uniquement : suivez les étapes 1 et 3 décrites ci-dessus.
    • Pour les systèmes monophasés et multiphasés : double-cliquez sur un objet de données FluidProperties dans l'arborescence.
  2. Le panneau de tâches s'ouvre. Voir Options pour plus d'informations.
  3. Appuyez sur le bouton OK pour confirmer et terminer la commande.

Options

Les options sélectionnées dans le modèle physique déterminent les données à saisir dans le panneau de tâches « Fluid Properties ». L'image ci-dessous présente le panneau de tâches « Fluid Properties » pour une simulation non isotherme.

Nom du matériau

Le champ de saisie permet de saisir le nom du fluide. Un fluide sélectionné dans la bibliothèque de fluides prédéfinis sera automatiquement renseigné dans ce champ, mais il est possible de le remplacer. Le nom saisi apparaîtra dans l'arborescence du conteneur d'analyse.

Propriétés du fluide

  • Fluides isothermes
Les propriétés physiques d'un fluide isotherme ne changent pas au cours de la simulation ; par conséquent, seules les données correspondant à un seul point de température sont nécessaires.
  • Champ de saisie Cp.
Chaleur spécifique à pression constante.
Cette valeur est requise lors de la simulation d’un fluide monophasique en régime permanent et non isothermique. Cp correspond à la quantité d’énergie nécessaire pour élever la température de 1 kg de fluide d’un degré Kelvin, dans un processus isobare. Comme il s’agit d’un régime permanent, un seul point de données est requis aux conditions dans lesquelles la simulation se déroule.
  • Champ de saisie Density.
Masse par unité de volume d'un matériau ou d'un fluide.
  • Champ de saisie DynamicViscosity.
Mesure de la résistance d'un fluide à la déformation à une vitesse donnée, parfois appelée « viscosité absolue ». La viscosité dynamique divisée par la densité du fluide donne la viscosité cinématique.
  • Non isotherme
  • Vous pouvez, si vous le souhaitez, sélectionner Compressible.
Lorsqu'une simulation non isotherme est sélectionnée, dans le modèle physique, la case à cocher Compressible devient visible. Si elle n'est pas cochée, il est possible de simuler des fluides incompressibles à l'aide d'un solveur compressible, à condition que la compressibilité ne joue pas un rôle significatif.
  • Champ de saisie Molar Mass.
La masse molaire ou poids moléculaire du fluide.
  • Polynomials
Temperature-polynomials are used when simulating non-isothermal, incompressible fluids. The simulation occurs over a temperature range and the fluid property data must be determined over the range.
The Polynomial provides a means of inputting coefficients for a temperature-polynomial, in the format:
Temperature-polynomial = a + b × T + c × T2 + d × T 3
where a, b, c and d are coefficients and T is Temperature. The polynomials will accept up to 8 coefficients. Enter each coefficient, separated by a space, for the temperature-polynomial, starting with the constant followed by the higher powers.
e.g. Cp = 9850.69 -48.6714xT +0.13736T2 -0.000127063xT3
would be entered as:
9850.69 -48.6714 0.13736 -0.000127063
  • Input box CpPolynomial.
Temperature-polynomial for Specific Heat Capacity at constant pressure.
  • Input box DensityPolynomial.
Temperature-polynomial for Density.
  • Input box DynamicViscosityPolynomial.
Temperature-polynomial for Dynamic Viscosity.
  • Input box ThermalConductivityPolynomial.
Temperature-polynomial for Thermal Conductivity.
  • Sutherland
The Sutherland formula is used when simulating non-isothermal, compressible fluids. It is used for approximating the viscosity of gases, at different temperatures. It is used for single-component gases at low pressure, however can also be used for Air, as the main components of Nitrogen and Oxygen have very similar properties.
  • Input box SutherlandRefTemperature.
The temperature, T0, at which the SutherlandRefViscosity was determined.
  • Input box SutherlandRefViscosity.
The empirical reference viscosity, μ0, determined at the SutherlandRefTemperature.
  • Input box SutherlandTemperature.
Sometimes referred to as the Sutherland constant, S, is an effective temperature, which is characteristic of the gas.

Predefined fluid library

  • Drop-down box
The fluid properties for a number of components exist within the Predefined fluid library. Selecting a fluid from the drop-down, will automatically populate the Fluid properties input boxes above
  • Reference data
Below the drop-down, the reference conditions for the fluid selected are given. e.g. for incompressible Seawater it states "Sea water (30%) 20 Degrees Celsius 1 atm".

Notes

  • The input boxes and options available in the Fluid Properties task panel are dependent on the options selected in the Physics Model task panel. To assist with workflow, we recommend that you complete the Physics Model task panel before completing this task panel.
