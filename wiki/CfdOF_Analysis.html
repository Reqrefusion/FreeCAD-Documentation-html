Description

The Analysis container holds all objects of a Computational Fluid Dynamic Analysis. This container is mandatory.

Usage

  1. There are several ways to invoke the command:
    • Press the Analysis container‏‎ button.
    • Select the CfdOF → Analysis container‏‎ option from the menu.
    • Use the keyboard shortcut: N then C.
  2. A new CfdAnalysis container is created and set to active.
  3. The following objects are automatically created inside the container:
    • PhysicsModel
    • FluidProperties
    • InitialiseFields
    • CfdSolver
  4. Additional objects can be added to the container by pressing a CfdOF button or selecting from the CfdOF menu.
