Description

The Silk CubicCurve_6 command creates a cubic NURBS curve, CubicCurve_6 object, from a 6 point control polygon.

A CubicCurve_6 previewing a cubic curve.

It is mostly intended for blending existing Bézier curves or curve segments.

2 selected adjacent curve segments → Blend polygon → Resulting blend curve

Usage

  1. Select a 6 point control polygon in the Tree View or in the 3D View.
  2. There are several ways to invoke the command.
    • Press the CubicCurve_6 button.
    • Select the Silk → CubicCurve_6 option from the menu.
  3. A cubic curve, a CubicCurve_6 object, is created.

Notes

  • A 6-control-point cubic NURBS curve. G2 continuous throughout; G3 continuous throughout except at two points along the curve, where it is G2 only.
  • The practical use of this curve is to preview blends on curves before doing the full work of blending surfaces.
  • This is currently an endpoint in the Silk design workflow.
  • The input ControlPoly6 can be used to build grids and surfaces; alternatively, this curve can be used with the rest of FreeCAD — extruded, revolved, etc. — if curve design is all that is needed from Silk.

Properties

See also: Property View.

A CubicCurve_6 object is derived from a [[[Part_Feature|Part feature]], or more precise a Part::FeaturePython object, and inherits all its properties. It also has the following additional properties:

Data

C1 - Inputs

  • DataPoly (Link): Control polygon.
  • Datareverse (Bool): Default is False. Reverses the parameter direction.

C3 - Identifiers

  • DatainternalName (String): The permanent internal FreeCAD name for this object.
  • Dataobject_type (String): Default is CubicCurve_6. The workbench class used to create this object.
  • Dataobject_version (String): The class version of this object.
