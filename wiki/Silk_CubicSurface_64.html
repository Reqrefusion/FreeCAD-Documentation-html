Description

The Silk CubicSurface_64 command creates a CubicSurface_64 from a ControlGrid64.

A CubicSurface_64 blend between two CubicSurface_44 objects

Usage

  1. Select a ControlGrid64
  2. There are several ways to invoke the command.
    • Press the CubicSurface_64 button.
    • Select the Silk → CubicSurface_64 option from the menu.
  3. A CubicSurface_64 object, is created.

Properties

See also: Property View.
