The images are indeed old but this is not really an issue as the user experience shown there has not changed.
activeDocument() and ActiveDocument are not attributes of the document, but of App and Gui. This seems to be a misunderstanding on your part.
When adding the Part box a recompute is required to show it in the 3D View. But indeed, the object is added to the Tree View immediately. For the mesh object the recompute is indeed redundant.
Return values of code have probably intentionally been left out as the code is intended to be copy-pasted line for line.
