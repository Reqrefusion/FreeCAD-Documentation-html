Part Defeaturing

Description

The Defeaturing tool is a parametric dress-up feature that removes one or more selected faces from a PartDesign Feature and heals the resulting gap by extending the adjacent faces. Unlike the non-parametric Part Defeaturing tool, this feature stays linked to the base feature and updates automatically when it changes.

This is useful for simplifying imported or heavily featured models, for example removing fillets, chamfers, holes, bosses, or other local details that are not needed for a given purpose, such as FEM analysis, 3D printing, or sharing a simplified model.

Usage

  1. Select one or more faces of a PartDesign Feature to remove.
  2. There are several ways to invoke the tool:
    • Press the Defeaturing button.
    • Select the Part Design → Defeaturing option from the menu.
  3. The Defeaturing Parameters task panel opens, listing the selected faces.
  4. Optionally press the Select toggle button to add more faces to the list, or select one or more entries and press Delete (or use the context menu) to remove them.
  5. A live preview highlights the changed geometry: material removed from the base shape (e.g. filling in a defeatured hole) and material added compared to the base shape (e.g. the filled volume of a removed fillet) are shown together.
  6. Press the OK button to confirm.

Properties

Data

Dress-up

  • DataBase (LinkSub): the faces selected to be removed from the base feature.

Part Design

  • DataRefine (Bool): true or false. Cleans up residual edges left after the operation. This property is initially set according to the user's settings (found in Preferences → Part Design → General → Model settings).

Limitations

  • If no faces are selected, an empty Defeaturing feature is created and a warning is printed to the Report view.
  • If the removed faces cannot be healed into a single solid by extending adjacent faces, the operation fails with an error.
  • Like other dress-up features, Defeaturing depends on the topological naming of the referenced faces; renaming or restructuring earlier features may require reselecting the faces.
