The macro Spreadsheet Dependency Inspector displays, for a selection of cells, properties or objects, all dependencies between spreadsheet cells and even between a cell and object properties or between properties. Everything is shown as an expandable tree that displays the cell name, its alias, its formula, and its value. It displays recursively:

  • What each item uses
  • What uses each item

The macro also helps you find and diagnose errors in your document. Run it on the whole document and check only Errors: you see at once every cell, property or constraint in error, the one where the error starts (bold red), and the value that causes it (orange), for example a cell containing a text where a number is expected. When the cause is unknown (division by zero, pad of length zero...), the values used by the faulty line are shown in orange italic, to check. See Error detection.

The macro is multilingual, currently supporting English and French. The language used is the one you selected in your FreeCAD preferences.

As a complement to this macro you may also want to check Macro Sketch Constraint From Spreadsheet.

Examples of use

  • Get an overall view of the dependencies between cells, and between cells and object properties.
  • See the consequences of deleting a cell.
  • Check whether a cell is unused.
  • Verify and edit expressions.
  • Assign aliases or labels.
  • Verify and edit labels.
  • Locate in the sketch a constraint that is linked to a spreadsheet cell.
  • Find the errors in the document, where they start and what causes them.
  • …

Usage

Select the starting point, then run the macro:

  • one or several cells in an open spreadsheet;
  • a property in the property view (e.g. Length of a Pad);
  • one or several objects in the tree or the 3D view (Body, Sketch, Pad...): their properties and cells that have an expression, are used or are in error, including the content of a Body, Part or group;
  • the document, at the top of the tree, to analyse the whole project.

The refresh button re-runs the analysis, for example after you modify a cell. It starts again from what you selected last (cells, property, objects or document).

The expand/collapse buttons and the level counter expand or collapse the whole tree. You can also do it branch by branch by clicking on the ▶ or ▼ symbols. Checking or unchecking a box keeps the level shown.

Choose the information you want to display:

  • Uses / Used by: the two branches of each line.
  • Cells, Constraints, Others: the kinds of lines shown.
  • Errors: when checked, the lines in error are always shown, with what they use. When unchecked, it does not prevent the lines in error from being shown. With Errors alone, you only see the errors and their causes.
  • Columns: Label/alias, Expression, Result and constraint Type can be shown or hidden.

Error detection in the FreeCAD document

  • Red: the cell or property is in error (cell error, expression that fails, value refused by FreeCAD, invalid object, sketch constraint refused by the solver).
  • Bold red: the error starts here; a red line without bold gets its error from another line (shown in its tooltip).
  • Orange: next to a line in error, the value that causes it, e.g. a cell containing the text a where a number is expected. The cell itself is not in error, so it is orange only next to that line.
  • Orange italic: next to a line in error whose cause is unknown (division by zero, pad of length zero...), the values it uses, to check.

The tooltip of each line explains its state.

In the tree

With a simple click, you can directly modify the labels or aliases and the content (expression).

A double‑click on a row opens the cell, the property or the constraint. For a constraint, the sketch containing it is opened and the constraint is selected to highlight it. In the Expression column, a double-click selects the terms of the expression.
