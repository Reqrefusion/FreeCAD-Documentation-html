背景

このページは、Fusion 360からFreeCADへの移行に関心があるユーザーを対象としています。

まず行うべきこと

  1. 最初に行うべきことは、独自の（プロプライエタリな）ファイルフォーマットとクラウドストレージからファイルを取り出すことです。
    • まずは、モデルをクラウドからローカルマシンにエクスポートすることから始めます。一般的な方法として、Fusion 360にPythonスクリプトを追加してすべてのモデルをエクスポートする手法があります。以下のスクリプトがGithubで利用可能です：
      • Fusion360 total exporter script: 2026年6月現在、このスクリプトはIGESフォーマットでエクスポートを行うため、「非商用利用（Not for Commercial Use）」のアカウントでは機能しません。
      • A different version of the Fusion 360 total exporter script (別バージョンのエクスポートスクリプト): このバージョンでは、ユーザーがSTEP、STL、IGESファイルのどれをエクスポートするかを選択できます（スクリプトの15〜17行目を変更することで設定可能）。ダウンロードする際は、READMEファイルのリンクを確認してください。2026年6月現在、上記のオリジナルバージョンにリンクされている場合があります。
      • Fusion 360 Exporter script: エクスポートの際は、STEPフォーマットの使用を推奨します。

用語集

基本的にはGlossary（用語集）ページを参照していただきたいですが、ここではFusion 360ユーザーにとって特に役立つと思われる用語の短いリストを紹介します

  • 正接拘束 (Tangent constraint) - FreeCADにおける同一線上拘束（Collinear Constraint）の形式。Sketcher ConstrainTangentを参照してください。
  • 押し出し (Pad) - FreeCADにおける「押し出し（Extrude）」機能。詳細については PartDesign Padのドキュメントをお読みください。

FAQ

  1. What formats do you support in FreeCAD?
    • The native file format in FreeCAD is BREP, boundary representation, provided by the internal OpenCASCADE (OCCT) geometry kernel.
    • FreeCAD supports all formats that OCCT supports, so STEP and IGES at least.
  2. What formats should I use to migrate to FreeCAD?
    • STEP is the best format because it is a solid Shape format, as opposed to a Mesh (STL, OBJ, DAE). Example, Importing Step with Colors.
    • Importing an STL is possible, but this mesh format will be difficult to modify further. We recommend converting imported meshes to solid Shapes using Part ShapeFromMesh. Remodelling the object in FreeCAD, while using the mesh as reference, is the best advice.

Tips

  • @MPetrika (twitter) recommends installing HakanSeven12's ModernUI Workbench
  • Export scripts may hang indefinitely while exporting certain files. The only solution is to alter the Python script to exclude these files and then rerun.
