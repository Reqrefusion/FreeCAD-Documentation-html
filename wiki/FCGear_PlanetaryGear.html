Description

The FCGear PlanetaryGear command calculates and creates a planetary gear assembly. A live preview helps to find valid settings.

Live preview in the 3D View → Finished planetary gear assembly (colors added for clarity)

Usage

  1. There are several ways to invoke the command:
    • Press the Planetary Gear Assembly button in the toolbar.
    • Select the Gear → Planetary Gear Assembly option from the menu.
  2. The Planetary Gear Assembly Task Panel opens.
  3. Adjust the parameters and press OK To finish configuration and close the Task Panel
  4. An assembly, a PlanetaryGear object, is created.

Properties

See also: Property View.

An FCGear PlanetaryGear object is derived from an Assembly::AssemblyObject object and inherits all its properties. It also has the following additional properties:

Data

Part

  • Data_Part_ShapeCache (ShapeCache):


An FCGear PlanetaryGear_Configuration object is derived from an App::FeaturePython object and inherits all its properties. It also has the following additional properties:

Data

accuracy

  • Datanumpoints (Integer): Number of points used per involute flank
  • Datasimple (Bool): Draw simplified cylinders instead of real teeth

assembly

  • Dataassembly (Link): Assembly container
  • Datacarrier (Link): Planet carrier
  • Datause_assembly (Bool): Insert gears into an Assembly container and ground the ring gear

computed

  • Dataratio_ring_fixed (Float): Ratio (carrier / sun) with ring fixed
  • Datasun_planet_distance (Length): Sun-planet centre distance
  • Datavalidation_message (String): Validation messages
  • Dataz_ring (Integer): Ring gear teeth

fillets

  • Datahead_fillet (Float): Fillet radius at the tooth tip, as a fraction of the module
  • Dataroot_fillet (Float): Fillet radius at the tooth root, as a fraction of the module

gears

  • Dataplanet_gears (LinkList): Planet gears
  • Dataring_gear (Link): Ring gear
  • Datasun_gear (Link): Sun gear

helical

  • Datadouble_helix (Bool): Make every gear a herringbone gear
  • Datahelix_angle (Angle): Helix angle of every gear

hole

  • Datahole_planets (Length): Bore diameter of the planet gears (0 for no bore)
  • Datahole_sun (Length): Bore diameter of the sun gear (0 for no bore)

kinematics

  • Datacarrier_angle (Angle): Carrier rotation angle

parameters

  • Dataheight (Length): Gear height
  • Datamodule (Length): Module
  • Datanum_planets (Integer): Number of planet gears
  • Datapressure_angle (Angle): Pressure angle
  • Dataring_thickness (Length): Wall thickness of the ring gear rim
  • Datashift_planet (Float): Planet profile shift
  • Datashift_ring (Float): Ring profile shift
  • Datashift_sun (Float): Sun profile shift
  • Dataz_planet (Integer): Planet gear teeth
  • Dataz_sun (Integer): Sun gear teeth

tolerance

  • Databacklash (Length): Backlash of every mesh
  • Dataclearance (Float): Clearance between tooth tip and root
  • Datahead (Float): Addendum factor of sun and planet gears
  • Datahead_ring (Float): Addendum factor of the ring gear

version

  • Dataversion (String): freecad.gears-version.


For RingGear object properties see Internal Involute Gear, and for SunGear and PlanetGear object properties see Involute Gear.

Notes

This tool does not work properly with the Assembly version in xwzCAD 2.1-pre yet. Objects seem to build correct but the positioning fails.
